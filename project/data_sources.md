# 공공 데이터 출처 및 수집 파이프라인 스펙 (data_sources.md)

## 1. 개요

본 문서는 `local-open-spaces` 서비스에서 활용하는 공공/제휴 API 출처와 데이터 유형별 수집 파이프라인 구조를 정의한다. 아래 7대 공공 API는 **구현 완료**된 메인 데이터 소스이며, Decision 008에 따라 80%(공식/공공 API) + 20%(보완 크롤링/제휴 API, 커머스 핫딜 포함) 구조로 소스가 확장된다 (`docs/spec.md` 3.1, 2절의 "2. 신규 계획 소스" 참고 — 신규 소스는 미착수).

모든 데이터 수집 및 정제 작업은 **Zero-Cost 인프라 원칙(Decision 001)**을 준수하며, 수집된 비정형 데이터는 AI 자동 분류 파이프라인(Decision 005, Decision 008)을 거쳐 PostGIS 공간 DB에 동기화된다. 크롤링/스크래핑 기반 보완 소스는 오류 시 전체 파이프라인을 중단하지 않는 **Fail-Safe Skip** 규칙을 적용한다 (`docs/spec.md` 3.1).

## 2. 7대 공공 API 출처 및 데이터 유형별 수집 사양

### 2.1. 공간형 데이터 (Open Spaces - 총 3종)
시설, 공원, 장소 등 위치 기반의 고정된 공간 정보로, 변동 주기가 길어 **월 1회 동기화**한다.

| 번호 | 데이터셋/API명 | 제공기관 | 주요 수집 항목 | 수집 주기 |
| :--- | :--- | :--- | :--- | :--- |
| **01** | 전국 도시공원 정보 | 행정안전부/지자체 | 공원명, 공원구분, 위경도, 주요시설 | 매월 1일 03:00 |
| **02** | 전국 공공체육시설 현황 | 문화체육관광부 | 시설명, 체육시설종류, 위경도, 이용안내 | 매월 1일 03:30 |
| **03** | LocalData 전국 문화기반시설 현황 | 지자체/문화체육관광부 | 도서관/미술관/박물관/공연장 위치 및 공간 정보 | 매월 1일 04:00 |

### 2.2. 행사·이벤트형 데이터 (Events & Popups - 총 4종)
공간 내에서 열리는 전시, 축제, 팝업, 예약형 행사 등 시한성 정보로, 일정 및 예약 마감일 실시간 반영을 위해 **매일 1회 수집**한다.

| 번호 | 데이터셋/API명 | 제공기관 | 주요 수집 항목 | 수집 주기 |
| :--- | :--- | :--- | :--- | :--- |
| **04** | 서울시 공공서비스예약 (공간/시설) | 서울특별시 | 공간명, 위경도, 이용요금, **예약접수 기간(시작/마감일)**, 예약 URL | 매일 03:00 KST |
| **05** | 서울시 문화행사 정보 | 서울특별시 | 행사명, 장소, 시작/종료일, 카테고리, 대표 이미지 | 매일 03:30 KST |
| **06** | 한국관광공사 국문 관광정보 (TourAPI 4.0 행사) | 한국관광공사 | 전국 축제/행사명, 좌표(EPSG:4326), 개요, 주소 | 매일 04:00 KST |
| **07** | 서울시 야외 행사 & 팝업 정보 | 서울특별시 | 행사장소, 운영시간, **예약 필수 여부 및 마감일**, 이벤트 여부 | 매일 04:30 KST |

### 2.3. 신규 계획 소스 (Decision 008, 미착수)
`docs/spec.md` 3.1의 80/20 수집 전략에 따라 아래 소스를 추가할 계획이다. 아직 수집 스크립트/워크플로가 구현되지 않았다.

| 구분 | 소스 | 용도 |
| :--- | :--- | :--- |
| 메인(공식 API) | 산림청 API | 야외·자연 카테고리 보강 |
| 메인(공식 API) | 네이버 Local API | 장소 정보 보강 |
| 메인(제휴 API) | 쿠팡 파트너스 API | 특가·핫딜 서브탭 데이터 |
| 메인(제휴 API) | 네이버 쇼핑 API | 특가·핫딜 서브탭 데이터 |
| 보완(크롤링) | 마트 문화센터 1일 특강 게시판 | 체험·클래스 카테고리 보강 (Fail-Safe Skip 적용 대상) |
| 보완(크롤링) | 지자체 광장 행사 게시판 | 공연·축제 카테고리 보강 (Fail-Safe Skip 적용 대상) |

## 3. 데이터 수집 & 저장 파이프라인 아키텍처

```text
[7대 공공 API]
       │
       ▼ (GitHub Actions Workflow - Cron Schedule)
[1. Raw Data Fetcher Node Script]
       │
       ▼
[2. AI Data Cleaner & Tagger (Decision 005)]
   - 비정형 텍스트 정제 및 카테고리 태깅
   - 예약 접수 마감일(Reservation Due Date) 파싱 표준화
   - WGS84 (Lat, Lng) 좌표 정규화
       │
       ▼
[3. Supabase RPC / Stored Procedure]
   - ST_SetSRID(ST_MakePoint(lng, lat), 4326)
   - Upsert (external_id 기준 중복 방지)
       │
       ▼
[4. Supabase PostGIS DB (public.open_spaces / public.events)]
