# 문화센터 클래스 상세 바텀시트

## 구현 대상
사용자 지적(2026-10-03): "왜 눌렀을때 반응이 없어? 누르면 상세페이지가
바텀시트로 나와야 하는거 아니야? 목록리스트에서 그다음 단계가는게
없어...어 그리고 찜하기 아직 안보이네 목록리스트에.." + 실제 이마트
상세 화면 캡처(`reference/emart culture club detail.png`) 제공, 구조
설명: 이미지 크게(좌)+정보 크게(우), "클래스 담기"/"클래스 신청하기"
버튼, 하단에 강사정보/FAQ(접힌 상태로).

## 사전 확인 — 찜 버튼이 "안 보인다"는 지적
코드 자체는 정상이다: `BookmarkButton`은 로그인 + 열심맘(active) 이상일
때만 렌더링되는 기존 설계(스팟/이벤트 찜과 동일 기준)다. 비로그인
상태이거나 열심맘 미만 계정으로 확인했다면 의도된 동작이다 — 별도로
버그를 수정하지 않았다(사용자에게 계정 상태 확인 요청).

## 변경 사항 — `src/components/home/culture-club-tab-view.tsx`
### 1. 카드 클릭 → 상세 시트
- `ClassCard`의 루트를 `<button>`에서 `role="button"` `<div>`로 변경했다
  — 카드 안에 찜 버튼(`<BookmarkButton>`, 실제로는 `<button>`)이 중첩되는데
  버튼 안에 버튼을 넣는 건 유효한 HTML이 아니라서(브라우저가 중첩을
  파싱하며 레이아웃이 깨질 수 있음), 이번에 실제로 클릭 가능하게 만들면서
  이 문제를 바로잡았다.
- 찜 버튼을 감싸는 `<span onClick={e => e.stopPropagation()}>`을 추가해
  찜 버튼 클릭이 카드 클릭(상세 열기)으로 전파되지 않게 했다.
- `CultureClubTabView`에 `selectedItem` state 추가, 카드 클릭 시
  `CultureClubDetailSheet`를 렌더링.

### 2. `CultureClubDetailSheet`(신규 컴포넌트, 같은 파일)
참고 화면 구조를 그대로 따랐다: 이미지(좌, 모바일은 위, 상태 뱃지 유지)
+ 정보(우, 모바일은 아래 — 카테고리/제목/가격+재료비/구분선/일정/
접수기간/접수가능지점(지점명 — 목록 카드와 달리 상세에서는 다시 보여줌,
참고 화면의 "접수가능지점"에 대응)/정원). 액션 2개: 찜(BookmarkButton,
참고 화면의 "클래스 담기"에 대응 — 사용자도 "찜기능인가?"로 추정)와
"클래스 신청하러 가기"(실제 신청은 이마트 사이트에서 처리하므로 새 탭
외부 링크). 그 아래 "클래스소개" 접이식 섹션(기본 펼침) — 실제 수집된
`class_detail_content`를 그대로 보여준다.

### 3. 강사정보/FAQ — 이번 범위 제외
참고 화면엔 있지만 현재 수집 파이프라인(`emart-culture-club-detail.mjs`)
의 GraphQL 쿼리가 `classDetail.classDetailInfo`(클래스소개 텍스트)와
`mainImage`만 가져온다 — 강사정보/FAQ에 해당하는 필드를 전혀 요청한 적이
없다. GraphQL 인트로스펙션을 시도했으나 프로덕션에서 막혀 있었고
(`Field 'types' in type '__Schema' is undefined`), 필드명을 추측으로
질의해보는 것도 유효한 필드 목록을 알려주지 않아(에러가 "undefined"라고만
함) 실측으로 알아낼 방법이 없었다. 사용자가 실제 상세 페이지 로드 시
호출되는 GraphQL 쿼리(강사정보/FAQ 포함)를 DevTools에서 확인해주면
추가할 수 있다 — 추측으로 필드명을 지어내 쿼리하지 않았다(제3장 제5조).

### 4. "클래스 신청하러 가기" 링크 — 강좌별 딥링크 미확인
클래스별 상세 페이지 URL 패턴(예: `/enrolment/{classId}`)을 확인하지
못해, 우선 검색 화면인 `https://www.cultureclub.emart.com/enrolment`로
연결한다. 사용자가 실제 클래스 클릭 시 브라우저 주소창/DevTools에 뜨는
URL을 확인해주면 `class_id`를 넣어 바로 그 강좌로 연결할 수 있다.

- `src/components/home/culture-club-tab-view.test.tsx`(5개 추가): 카드
  클릭 시 상세 시트가 열리고 지점/신청버튼/클래스소개가 보이는지, 신청

  확인 — 실제 로그인+열심맘 계정으로 버튼이 렌더링되게 만든 뒤 테스트),
  닫기(✕) 버튼으로 시트가 닫히는지.
- `npx tsc --noEmit` / `npm run test`(263개 파일 2,749개) / `npm run build`
  전부 통과.
