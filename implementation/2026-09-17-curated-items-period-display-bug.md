# [운영 기간 목록 표시 버그 수정 — 겹친 물결표]

## 구현 대상
사용자 지시(2026-09-17): "마잉리얼트립 상품검색에서 운영 종료일 이거 9월 30일로
설정하고 등록해도 왜 다시열어보면 설정 안한것처럼 보여? 실제로도 설정 안된거야?"

## 구현 일시
2026-09-17

## 진단
DB(`curated_items.operation_end_date`)와 관리자 수정 폼(`CuratedItemFormModal`의
날짜 input) 둘 다 실측으로 재확인한 결과 값은 정확히 저장·재로딩되고 있었다 —
실제 데이터 손실은 없었다. 문제는 `curated-items-panel.tsx` 목록 테이블의 "운영/
예약 가능 기간" 칸이었다: 시작일이 없을 때 `row.operation_start_date ?? '~'`로
placeholder를 "~"로 채워, 종료일만 있는 상품이 `"~ ~ 2026-09-30"`처럼 물결표가
두 번 겹쳐 보였다 — 이게 마치 "아무 값도 안 들어간 것"처럼 보인 원인이었다.

## 변경 사항
`src/components/admin/curated-items-panel.tsx`: 운영 기간 칸 렌더링을 4분기로
정리 — 둘 다 있으면 `start ~ end`, 시작일만 있으면 `start ~`, 종료일만 있으면
`~ end`, 둘 다 없으면 `상시`. 한쪽만 있을 때 없는 쪽을 "~"로 채우지 않는다.

## 검증
- `npx tsc --noEmit`/`npm run test`(전체 1852개, 신규 2개 포함)/`npm run build`
  모두 통과.
- 실측(Playwright, 실제 DB의 "[제주] 스누피가든 입장권" 행): 수정 폼 재오픈 시
  운영 종료일 input이 "2026-09-30"으로 정확히 채워짐을 확인(데이터 자체는 문제
  없었음 재확인). 목록 칸 텍스트가 수정 전 `"~ ~ 2026-09-30"` → 수정 후
  `"~ 2026-09-30"`으로 바뀌는 것 확인.
