## 구현 일시

## 1. PersonalizedBanner(맞춤 환영 문구) 제거
"성남시 분당구에 사는 3살 3살 아이와 이번 주말 여기 어때요? 👀" 배너는
`personalized-banner.tsx`(2026-09-02, 프로필의 지역/출생년도 기반 생성 문구)였다.
지금까지 이어진 "맘스픽화면은 맘스픽 컨텐츠만"이라는 방향과 같은 맥락의 질문으로
받아들여 `mom-pick-view.tsx`에서 렌더링을 제거했다. 컴포넌트 파일 자체는
지우지 않고 남겨뒀다(다른 화면에서 필요해지면 바로 재사용 가능).

## 2. 프리뷰 카드(`DashboardPostCard`) 초압축
기존에도 한 차례 줄였지만(직전 커밋), 이번엔 아예 "미리보기 전용" 카드로
재정의했다:
- 제목(스팟명) + 작성자 닉네임/등급 한 줄(유지).
- 태그 최대 3개 + "+N개"(유지).
- 자유글 미리보기를 `line-clamp-2` → **`line-clamp-1`**로 줄임.
- **완전히 제거**: 날짜, 좋아요(❤️) 개수, "📷 사진 N장 보기" 버튼 — 전부
  프리뷰에서 뺐다.
- 카드 전체가 `<button>`이 되어, 어디를 눌러도 상세 모달이 열린다.

## 3. 상세 카드(`PostDetailModal`, 신규) — 프리뷰에서 뺀 정보를 전부 이곳으로
"프리뷰 카드 누르면 상세카드가 보이게 되는 구조" 요청대로 새 컴포넌트를
만들었다. 마이페이지의 기존 "내가 쓴 후기" 상세 모달
(`my-reviews-section.tsx`의 `ReviewDetailModal`)과 같은 관례(필드별 레이블
붙여 나열)를 따르되, 다른 사람 글도 봐야 해서 작성자 닉네임/등급을 추가하고
좋아요 기능을 새로 붙였다:
- 헤더: 스팟명 + 작성자 닉네임 · 등급 · **날짜**.
- survey_review: 연령대/방문환경/만족포인트/체류시간뿐 아니라 프리뷰에서
  아예 안 보여주던 **날씨 추천/인프라/동반 형태**(카드 컴팩트화 이전부터
  "상세 화면에서만 전부 보여준다"고 예정돼 있던 필드들)까지 전부 라벨과
  함께 나열, 전체 내용(줄바꿈 유지).
- **사진**: 썸네일 그리드로 보여주고, 탭하면 그 사진부터 시작하는
  `PostPhotoModal`(기존 좌우 화살표 전체화면 뷰어, `initialIndex` prop 추가)이
  열린다.
- **찜(좋아요)**: "찜기능은 상세 카드쪽에서 찜 줄 수 있도록" — 기존에 죽어있던
  `MomPickFeed`(Decision 020 이전 컴포넌트, 지금 어디서도 안 쓰임)가 이미
  갖고 있던 `toggleLike`/`getMyLikedPostIds`(`@/lib/community/posts.ts`)를
  그대로 재사용했다(제5장 제4조 — 새로 만들지 않음). Decision 019 규칙
  ("좋아요 UI는 열심맘(active) 이상에게만 노출")도 그대로 지킨다 — 모달을
  열 때 조회한 내 프로필 등급으로 `canSeeLikeReactions`를 판정해, 비로그인/
  새싹맘이면 좋아요 버튼 자체가 안 보인다.

    임포트하지 않으므로) — 기존 11건 전부 그대로 통과.
- `npm run build`: 성공.

## 특이 사항
- `full-list-view.tsx`("전체보기" 페이지)도 같은 `DashboardPostCard`를 쓰므로
  이 초압축+클릭 상세 구조가 자동으로 그대로 적용된다(별도 분기 없음 — 어디서
  보든 프리뷰는 프리뷰, 상세는 같은 모달).
- `personalized-banner.tsx` 파일은 삭제하지 않고 남겨뒀다 — 완전 삭제 확정
  요청이 아니라 "왜 뜨지?"라는 질문형 지적이었기 때문에(제3장 제5조 추측 금지),
  필요하면 다른 화면에서 다시 쓰거나 완전히 지워달라고 요청할 수 있다.
