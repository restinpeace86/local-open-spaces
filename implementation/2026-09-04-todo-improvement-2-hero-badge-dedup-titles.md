## 변경 사항

### 1. Hero 뱃지 복구
실측 확인 결과, `getDateBannerBadge()`(오늘 한정/오늘 마감 판정) 자체의 로직은 멀쩡했고
뱃지도 실제로 렌더링되고 있었다 — 문제는 스타일이었다: `HeroCarousel`은 이 뱃지를
무료/유료 뱃지와 같은 `flex gap-1` 줄에 작은 알약(`rounded-full`, `z-index` 없음)으로
욱여넣어 눈에 잘 안 띄었다. 반면 `EventCard`(카드 목록)는 같은 데이터를 이미지 상단
전체 폭을 가로지르는 스트립(`left-0 right-0`, `z-10`, `text-center`)으로 보여줘
훨씬 선명하다. `EventCard`의 이 패턴을 그대로 재사용해(제5장 제4조 기존 구조 우선)
Hero 카드에도 적용했다 — 날짜 배너는 독립된 전체 폭 스트립으로, 무료/유료 뱃지는
그 아래(`top-8`)로 내려 겹치지 않게 했다.

### 2. Hero-"오늘 가능" 중복 제거
실측 확인: Hero(`getTodayEvents`)는 `end_date = 오늘`인 행사를 뽑고, "현재 이용 가능"
(`getCurrentlyOngoingEvents`)은 "오늘이 start_date~end_date 진행 기간 안"인 행사를
뽑는다 — `end_date=오늘`이면 사실상 항상 `start_date<=오늘<=end_date`도 함께 만족해
Hero에 뜬 행사가 바로 아래 목록에도 그대로 다시 떴다(두 쿼리 사이에 id 교집합 배제
로직이 전혀 없었음을 코드 전체 검색으로 확인). `getHomeFeed()`(`src/lib/home/get-
home-feed.ts`)가 두 결과를 모두 받은 뒤, `heroEvents`의 id 집합으로 `currentlyOngoingEvents`
를 한 번 걸러내도록 했다 — 두 쿼리 다 이미 이 함수 안에서 `Promise.all`로 나란히
실행되고 있어 자연스러운 위치였다. "예약 가능" 목록은 지시 범위(제목이 명시한
"'오늘 가능' 영역"만)에 없어 손대지 않았다.

### 3. 영역 타이틀 변경
`home-view.tsx`의 두 섹션 제목을 지시문 그대로 바꿨다:
- "✅ 현재 이용 가능" → "지금 이 순간 함께하기 좋은 알찬 픽"
- "📋 예약 가능" → "놓치면 후회하는 인기 만점 예약 픽"

이모지는 새 제목에 포함돼 있지 않아 그대로 뺐다 — 바로 위 "베스트 나들이 픽" 섹션도
이미 이모지 없이 텍스트만 쓰는 기존 관례가 있어 일관된다. `<section aria-label>`과
로딩 스켈레톤의 `aria-label`(스크린 리더 안내 문구)까지 전부 새 제목으로 통일했다 —
화면 텍스트만 바뀌고 스크린 리더 사용자에게는 옛 이름이 들리는 불일치를 피하기 위함.
"전체보기"를 눌렀을 때 뜨는 바텀시트(`EventBrowseSheet`)의 제목도 같은 이유로 함께
맞췄다(목록 제목과 눌러서 연 시트 제목이 서로 다르면 혼란을 준다).
