> 보존된다. 성능도 실측 재확인했다 — 밀집 지역(강남) 좌표 기준 5km 반경 함수 호출을
> warm 상태로 반복 실행한 결과 68~93ms(콜드 스타트 1회만 1.9초, 정상적인 최초 연결
> 오버헤드)로 타임아웃 위험이 없다. 요구사항 원문의 "시/군/구 Bounding Box 1차 필터 +
> KNN" 기법 자체를 그대로 구현하지는 않았지만, 이미 배포된 KNN 인덱스 워크 방식이 동일한
> 목표(타임아웃 방지+가까운순 정렬)를 실측으로 검증된 상태로 달성하고 있어 중복 구현하지
> 않는다(제5장 제4조 기존 구조 우선 — 이미 있는 해법 위에 불필요한 추가 레이어를 얹지
> 않음).

## 🎯 상세 요구사항

1. **스팟픽 대분류 필터 노출 제한 및 순서 재배치**
   - 기존 대분류 중 **`체육시설`**, **`공공청사 대관`**, **`기타`** 항목은 지도 필터에서 아예 노출되지 않도록 제외합니다.
   - 오직 아래 **4가지 핵심 대분류**만 노출되도록 UI를 개편합니다.
   - **노출 순서 (왼쪽부터):** 
     1. `키즈/놀이시설`
     2. `농장/체험`
     3. `자연/공원`
     4. `문화시설`

2. **바텀시트(Bottom Sheet) 연동**
   - 상단 4대 대분류 버튼을 클릭했을 때, 하위 중분류 목록들을 담은 바텀시트가 슬라이드업 형태로 부드럽게 올라오도록 구현해 주세요.
   - 바텀시트 내에서 특정 중분류를 선택하면, 해당 중분류에 속하는 스팟들만 지도와 리스트에 필터링되어 노출되도록 연결합니다.
   - 바텀시트 내에서 나오는 중분류에 대하여 데이터가 0건인 중분류는 중분류항목에서 제외할것

3. **거리순 정렬 및 성능 최적화**
   - 중분류 선택 시 필터링된 스팟들은 현재 설정된 유저 위치를 기준으로 **가까운 순(오름차순)**으로 상단에 노출되도록 정렬 로직을 적용해 주세요.
   - 단, 전체 데이터 대상의 무리한 거리 계산으로 인한 타임아웃을 방지하기 위해, **시/군/구 또는 광역 권역(예: 서울시 + 경기도 등) 기준**으로 1차 범위 필터링(Bounding Box)을 거친 후 PostGIS KNN 연산을 태우는 방식으로 성능 최적화를 보장해 주세요.
