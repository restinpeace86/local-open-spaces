[개선사항 1] # [프로젝트 맥락]
현재 개발 중인 '문화센터 통합 플랫폼'에서 사용자 맞춤형 검색 및 필터링 기능을 구현하려고 합니다. 지금 구현된 다음의 3가지 핵심 요구사항에 맞춰 백엔드 로직과 프론트엔드 UI를 구현해주세요.

# [핵심 요구사항]

### 1. 위치 기반 성능 최적화 (Branch-First 패턴 + 거리 변경 필터)
- **배경:** 수만 건에 달하는 강좌 데이터 전체를 대상으로 거리 계산을 하거나 필터를 걸면 성능이 심각하게 떨어집니다.
- **방식:** 
  1. 사용자가 앱 내에서 반경(예: 5km, 10km, 20km 등)을 직접 변경할 수 있는 **거리 선택 필터 컴포넌트와 로직**을 제공합니다. (기본값 10km)
  2. 사용자가 설정한 현재 위치에 기반하여 선택된 반경 내에 있는 지점(Branch)들만 먼저 선별합니다. (지점 데이터는 개수가 적어 연산이 즉시 끝납니다. -> 이 때 거리 계산도 진행합니다.)
  3. 그 후, 선별된 지점들에 소속된 강좌들만 대상으로 데이터를 조회하여 성능을 극대화합니다.
  4. 거리 선택 필터 컴포넌트의 위치는 검색창 위쪽에 위치하도록 합니다.

### 2. 온보딩 아이 개월 수 정밀 매칭
- **배경:** 마트 원문에 대충 적힌 연령 표기(예: "3~5세")에 의존하지 않고 정확한 매칭이 필요합니다.
- **방식:** 
  1. 우리 앱은 유저 온보딩 프로필에  아이의 이름과 몇년 몇월생인지의 정보를 필수적으로 받도록 되어 있습니다. 해당 정보를 바탕으로 **현재 기준 정확한 개월 수**를 계산합니다.
  2. 강좌 데이터에 미리 정형화된 개월 수 범위(최소 개월 수 ~ 최대 개월 수)와 비교하여, **내 아이가 정확히 참여할 수 있는 연령대의 수업만** 추려내서 보여줍니다.
  3. 아이에 대한 정보 (이름 및 몇년 몇월생)에 대한 정보를 문화센터 탭 최상위에 보여주며, 아이가 여러명일때는 여러명을 나열하여 사용자가 어떤 아이 기준으로 문화센터 데이터를 볼지를 선택할수 있도록 합니다. selectBox (ex. ㅇ[하윤 / 23개월]  ㅇ[하린 / 36개월] )

위의 내용에 대한 시나리오는 현재 위치 설정과 내가 기입한 아이의 출생년도와 출생월을 통하여 적합한 문화센터 강의를 1차적으로 자동으로 추출하고자 함이다.

### 3. 계층형 지점 선택 UI/UX (필터 구조)
- **기본 화면:** 브랜드(이마트, 롯데마트 등) 구분 없이 한데 섞여서 거리순으로 보이는 '통합 피드'를 기본값으로 합니다. 수강신청 목록리스트에 이마트 xx점 10km와 같은 정보가 나오기에 어느 지점꺼인지 바로 알수 있기에 통합으로 보여줘도 문제없음.
- **필터 UI 구조:**
  - **1단계 (대분류):** `전체`, `이마트 컬쳐클럽`, `롯데마트 문화센터` 같은 브랜드 이름을 상단에 배치합니다.
  - **2단계 (중분류):** 대분류를 누르면 펼쳐지는데, 이때 **전체 지점이 나오는 게 아니라 사용자가 설정한 거리 반경 내로 필터링된 지점들만** 뱃지형태로  나열되도록 합니다. (ex. 이마트의 경우, (안성점) (경산점) (명지점) / 롯데마트의 경우 (거제점) (검단점) (계양점) 등)
  - 나열된 지점들에 대하여 누르면 해당 지점이 선택되며, 해당 지점에 대한 강의들로 필터링됩니다. 선택된 지점을 한번 더 누르면, 지점 선택이 취소됩니다. 해당 지점들에 대하여 다중 선택이 가능하도록 합니다.
  - 아무 지점도 선택하지 않았을때는 전체 지점 선택과 동일하다고 보면 됩니다.

### 4. 요일 선택
  - 요일에 대하여 월 화 수 목 금 토 일 선택할 수 있도록 합니다.
    
위 4가지 요구사항이 매끄럽게 연결되도록 구현을 도와주세요.
