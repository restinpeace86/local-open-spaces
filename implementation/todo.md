### 1. 연령카테고리 분류 규칙
- **OTHER 분류:** 텍스트에 "단체", "여성" 또는 "장애인" 키워드가 포함된 경우 (예: `유아단체` -> `OTHER`)
- **TEEN 분류:** 텍스트에 "초등학교고학년" 또는 "초등학교4학년이상" 키워드가 포함된 경우 (`TEEN` 범위: 초등학교 4학년 ~ 고등학생)
- **빈값 유지:** 위 조건에 해당하지 않고 기존 연령카테고리가 비어있는 경우 빈값 유지

### 2. 데이터 전처리 및 중복 제거(DISTINCT) 규칙 (613개 리스트 기준)
1. **공백 제거:** 문자열 내의 모든 띄워쓰기(공백)를 우선 모두 제거합니다.
2. **중복 병합 (DISTINCT):** 공백 제거 후 완전히 중복되는 항목들은 하나로 병합합니다.
3. **병합 시 충돌 해결 규칙:**
   - 병합하려는 항목 중 한쪽만 연령카테고리가 있다면 **값이 있는 것**을 사용합니다.
   - **둘 다 값이 있는데 서로 다를 경우, 가장 위에 있는(먼저 등장한) 값을 우선 사용**합니다.
