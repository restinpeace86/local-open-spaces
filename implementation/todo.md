## 🛠️ [개선사항 2] AI 챗봇 지역 선택 UX 및 로직 개선

1. **'지역 목록에서 선택' 버튼 상시 노출 (승격)**
   - 기존에는 GPS가 실패했을 때만 간헐적으로 노출되던 "🗺️ 지역 목록에서 선택" 버튼을, 지역 설정 단계에서 **항상 상시 노출(Promote)**되도록 UI를 수정해 주세요.

2. **'다른 지역' 목록 로딩 및 동작 오류 수정**
   - 현재 챗봇 플로우에서 "다른 지역"을 선택하여 목록을 불러오고 챗봇 세션에 적용하는 과정에서 제대로 작동하지 않는 버그나 누락된 핸들러 로직을 찾아 수정해 주세요.

3. **시/군/구 광역 단위 선택지 확장**
   - 너무 세부적이거나 모호했던 선택지 대신, 사용자가 직관적으로 고를 수 있는 **[시/도] + [시/군/구] 광역 단위** (예: `서울특별시 광진구`, `경기도 성남시`, `경기도 용인시`, `서울특별시 마포구` 등)의 명확하고 넓은 선택지 리스트를 구성하고 모달/셀렉트에 연동해 주세요.
   - 해당 선택으로 지정된 지역은 **현재 챗봇 세션(session)에만 적용**되어야 합니다.

## 🛠️ [개선사항 3] 이벤트픽 대분류-중분류 바텀시트 및 카드 필터링 연동 수정

1. **대분류 클릭 시 바텀시트 동작**
   - 이벤트픽 화면 하단에 위치한 대분류 버튼을 누를 때, 하위 중분류 목록을 담은 바텀시트(Bottom Sheet)가 정상적으로 슬라이드되어 올라오는지 확인하고 수정해 주세요.

2. **중분류 선택 시 이벤트 카드 필터링**
   - 바텀시트 내부에서 특정 **중분류를 선택했을 때**, 바텀시트가 닫히면서 **해당 중분류(또는 대분류+중분류)에 해당하는 이벤트 카드들이 이벤트픽 화면에 실시간으로 필터링되어 렌더링**되도록 연동해 주세요.
   - 현재 선택된 카테고리 상태(State)가 이벤트 카드 목록 조회 쿼리나 상태 필터에 제대로 반영되지 않고 있거나 엉뚱한 곳에서 렌더링되는 문제를 해결해 주세요.

## 🛠️ [개선사항 4] open_spaces 캠핑장 데이터의 이벤트픽 연동

1. **대상 데이터 식별 (`open_spaces` ➔ 이벤트픽)**
   - 현재 `open_spaces` 테이블(또는 관련 공간시설 대여 데이터)에서 **중분류가 '캠핑장'**으로 분류되어 있는 항목들(예: 제천 서울캠핑장, 상주 서울캠핑장 및 팜핑 체험 등 공간/시설 대여·예약 성격의 캠핑장 데이터)이 이벤트픽 화면에서도 노출될 수 있도록 데이터 연동 구조를 확장해 주세요.

2. **이벤트픽 내 카테고리 매핑**
   - 위 캠핑장 관련 `open_spaces` 데이터가 이벤트픽의 대분류 **"자연/캠핑"**, 중분류 **"캠핑장"** 필터 영역에 정확히 포함되어, 사용자가 이벤트픽에서 해당 카테고리를 골랐을 때 목록으로 나타나고 예약/상세로 진입할 수 있도록 반영해 주세요.
