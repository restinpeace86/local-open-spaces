[개선사항 2] 이마트 컬처클럽과 롯데마트 문화센터의 강좌 데이터에서 연령 정보를 파싱하여, 데이터베이스에 정형화된 숫자 컬럼인 `minAge`(최소 연령/개월)와 `maxAge`(최대 연령/개월)에 '개월 수' 단위로 적재하는 파싱 함수 및 데이터 처리 로직을 구현해줘.

[데이터 특징 및 입력 포맷 예시]
1. 이마트 컬처클럽 (제목 텍스트 속에 연령 정보가 혼재됨):
   - 형태 A: "(37~55개월/c)" -> 개월 수 그대로 추출 (min: 37, max: 55)
   - 형태 B: "2020~23년생" 또는 "(17~22년생A)" -> 출생 연도 데이터를 현재 연도(또는 강좌 연도) 기준으로 개월 수 범위로 환산 필요
   - 형태 C: "(45개월~2021년생)" -> 개월 수와 출생 연도가 섞인 형태 등 예외 패턴 대응 필요

2. 롯데마트 문화센터 (별도 연령 필드 존재):
   - 형태 A: "13~26개월" -> 개월 수 그대로 추출 (min: 13, max: 26)
   - 형태 B: "7~8세" -> 연령(세) 단위를 개월 수로 환산 필요

[변환 및 환산 규칙 (Rule of Thumb)]
- 모든 최종 저장 값은 "개월 수(Months)" 정수형으로 통일할 것 (`minAge`, `maxAge`)
- '세' 단위 환산 기준:
  * 예: "3~5세"인 경우, 3세의 시작점인 36개월을 `minAge`로, 5세의 끝자락인 71개월을 `maxAge`로 환산 (사용자 정의 기준 반영)
  * 1세 = 0~12개월, 2세 = 12~24개월, 3세 = 24~48개월, 4세 = 36~60개월, 5세 = 48~72개월 등의 기준을 체계적으로 적용할 수 있는 정규식 및 파싱 유틸 함수 작성
- '년생' 표기(예: 2020~23년생)의 경우, 출생 연도를 기준으로 현재 시점 또는 해당 강좌 시즌 기준의 개월 수 범위로 안전하게 변환하는 로직 포함

1. 이마트용 파서와 롯데마트용 파서를 각각 분리하거나, 다양한 텍스트 패턴을 유연하게 잡아내는 정규식(Regex) 기반의 통합 파싱 유틸리티 함수(TypeScript/JavaScript 또는 Python 중 선택 가능하도록 작성)를 구현해줘.
2. 파싱 실패 시(연령 정보가 아예 없거나 예외적인 경우) 에러를 내지 않고 `null` 또는 기본값으로 처리하는 방어 코드 포함.
