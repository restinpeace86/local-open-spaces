### 🛡️ 2. 핵심: 기존 관리자 수동 검수 데이터 보호 (Upsert Guard) - [매우 중요]
현재 DB에는 **이미 관리자가 수동으로 검수·입력해 둔 `exposure_category` (노출 중분류) 데이터들이 이미 존재**합니다. 따라서 새로운 공공데이터 배치가 돌아서 기존 `open_spaces` 스팟과 매칭되어 갱신(Upsert)될 때 다음 규칙을 철저히 엄수해 줘:
- **노출 중분류(`exposure_category`) 절대 불변:** 이미 값이 들어가 있거나 존재하는 레코드의 경우, 공공데이터 싱크로 인해 **절대 덮어씌워지거나 초기화(NULL 처리)되지 않고 기존 값을 100% 그대로 보존(Preserve)**해야 함. (관리자의 명시적인 수동 정정이 없는 한 기존 노출 중분류 값은 절대 건드리지 말 것)
- **뱃지(`badges`) 보호:** 이미 저장된 뱃지 데이터 역시 업서트 시 덮어씌워지지 않도록 함께 보호할 것.
- **업서트 허용 범위:** 공공데이터 싱크 시 갱신되는 대상은 오직 원천 메타데이터(주소, 연락처 등), 원천 소스 기반의 표준 대/중분류, 그리고 속성 태그들로만 엄격히 한정할 것.

위 요구사항을 모두 반영하여 `open_spaces` 도메인의 백엔드 데이터 모델, 파싱/매핑 로직, 그리고 Upsert 쿼리/코드를 작성해 줘.

### 1. 스마트 검색 쿼리 조합 및 자가 치유(Self-Healing) 리트라이 로직
- **1차 스마트 검색:** 네이버 블로그 API 검색 시, 단순 상호명만 던지지 말고 DB에 저장된 주소 체계를 활용하여 `[상호명] + [지점명 또는 동/읍/면]` 조합으로 1차 검색 쿼리를 생성할 것.
- **실시간 적합성 검증(Validation):** 가져온 블로그 본문 텍스트 내에 해당 스팟의 핵심 키워드(지역명, 지점명 등)가 포함되어 있는지 실시간으로 검사할 것.
- **자가 치유(Auto-Refetch):** 미스매치(타 지역 지점 혼입 등)나 정보 부족으로 불합격한 블로그 개수(N개)를 파악하고, 상위 행정구역명을 결합한 확장형 스마트 쿼리로 자동 변환하여 **부족한 개수(N개)만큼만 API를 정밀 재호출 및 교체**하는 자동 리트라이 파이프라인을 구축할 것.
- **재시도 횟수 제한 (Max Retry Cap):** 무한 루프 및 API 쿼터 낭비를 방지하기 위해 스마트 재검색(Auto-Refetch)은 **최대 1회(또는 최대 2회)**로 엄격히 제한할 것.
- **단계적 쿼리 확장:** 
  - 1차 시도: `[상호명] + [동/읍/면]` 조합 예) 쿠우쿠우 명월점의 경우 쿠우쿠우 명월로 검색 .. .. 명월동에 있어서 명월점이지만 명월점으로 검색할 경우 안나오고 명월로 검색하면 나오는 case도 있음. 동/읍/면에 대하여 명월동 혹은 명월점이 아닌 명월로만 검색키워드 가져가는게 검색 성공율이 높음
  - 2차 시도(최종): 실패 시, 더 넓은 상위 행정구역인 `[상호명] + [시/군/구]` 조합으로 확장하여 재시도 ex) 쿠우쿠우 중구 라던가... 
- **최종 Fallback 처리:** 최대 재시도 횟수를 초과했음에도 정상 블로그를 확보하지 못한 경우, API 호출을 중단하고 해당 슬롯에 `[⚠️ 자동 매칭 실패 - 수동 확인 필요]` 경고 배지를 고정 노출하여 관리자 검수 큐로 안전하게 이관할 것.

### 2. 공백 무시 및 유의어 확장 텍스트 정규화 엔진
- **공백 무시 매칭:** 뱃지 키워드(예: '주차', '아기의자' 등) 매칭 및 하이라이팅 시, 모든 공백을 무시(Whitespace-Insensitive)하여 처리할 것 (예: "아기의자", "아기 의자", "아 기 의 자" 모두 동일 매칭).
- **유의어 확장 사전 적용:** 대표 키워드에 딸린 변형 표현들(예: `아기의자` ↔ `유아용 의자`, `유아 의자` / `주차` ↔ `주차장`, `차댈곳`)을 유의어 세트로 묶어 함께 인식되도록 할 것.

### 3. 지역/지점명 및 뱃지 키워드 동시 하이라이팅 & 워닝 UI
- **동시 하이라이팅:** 관리자 워크벤치 UI 및 텍스트 파서에서 타겟 뱃지 키워드뿐만 아니라 **해당 스팟의 고유 지역/지점명 키워드(예: '명월', '분당' 등)도 블로그 본문에서 찾아내어 노란색 배경(<mark> 등)으로 함께 하이라이팅** 처리할 것.
- **워닝 배지 표시:** 자가 치유 과정에서 걸러지지 못했거나 지역명이 불일치하는 블로그 슬롯에는 워닝 배지(Warning Badge)를 노출하여 관리자가 직관적으로 식별할 수 있게 할 것.
