### 2. 백엔드 로직 (그룹핑 및 일괄 저장)
1. **주소 표준화 및 좌표 기반 그룹핑 API:**
   - 아직 정제되지 않은(중분류가 미매핑된) `open_spaces` 데이터들을 대상으로, 주소 문자열을 정규화(`normalized_address`: 공백, '번지', '층', '호', 특수문자 제거)한 값이 일치하거나 위도/경도가 근접한 스팟들을 동적으로 묶어 **'중복 의심 그룹'** 리스트로 반환해줘.
2. **그룹 일괄 저장 (Bulk Save) 로직:**
   - 관리자가 특정 그룹에 대해 표준 정보를 입력하고 저장할 때, **해당 그룹에 속한 각각의 모든 원천 데이터 행(예: 3개 데이터 각각에)** 아래 값들이 **동일하게 각각 저장(업데이트)**되도록 해줘:
     - `standard_name` (관리자가 수정/입력한 표준 시설명)
     - `service_category_id`
     - `blog_url`
     - `age_group`
     - `feature_tag`
   - 동시에 이 그룹핑 정보와 처리 완료 상태가 DB에 이력으로 적재되어야 함.

### 3. 관리자 UI / UX 요구사항 (새로운 탭 페이지)
관리자 페이지에 별도의 **[중복 스팟 검수 및 매핑]** 탭을 만들고 다음 요소를 구현해줘:

1. **노출 중분류 관리 영역:**
   - 관리자가 새로운 서비스용 중분류를 입력하고 생성할 수 있는 간단한 폼과 목록.
2. **좌표/주소 기반 그룹 리스트:**
   - 시스템이 주소/좌표 기준으로 묶어준 그룹 목록을 보여줌 (예: "경기도 성남시... 외 2건").
3. **그룹 상세 및 매핑 입력 폼:**
   - 그룹을 클릭하면 묶인 원천 데이터들의 상세 내용(상호명, 원본 중분류, 주소 등)이 나란히 비교 표시됨.
   - 하단에 다음 입력 폼 제공:
     - **표준 시설명 입력란:** 원본 이름을 참고해 관리자가 직접 깔끔한 이름으로 수정/입력할 수 있는 텍스트 박스.
     - **중분류 콤보박스 (Select):** 관리자가 생성해 둔 노출 중분류 선택.
     - **블로그 URL 입력란:** 텍스트 입력 (선택).
     - **연령대 선택:** `미취학` / `취학` / `성인(비노출용)`/ `기타 (비노출용)` / `선택 안 함(Null)`.
     - **특징 입력란:** 텍스트 입력 (예: "바닥분수 / 놀이터").
   - **[저장 및 일괄 적용] 버튼:** 클릭 시 이 그룹에 속한 모든 원천 데이터 행에 위 내용이 각각 깔끔하게 반영되고, 처리 완료 상태로 바뀜.
