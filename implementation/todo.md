2. **LLM 호출 최적화 및 스킵 조건 (Skip Condition - 매우 중요)**
   - 매일 배치 스크립트가 돌 때, 아래 조건 중 하나라도 만족하는 데이터는 **실내/실외 LLM API를 절대 호출하지 않고 대상에서 제외(Skip)**하도록 쿼리 또는 조건문을 구현해 주세요.
     - **조건 A:** 이미 `environment_type`이 `INDOOR`, `OUTDOOR`, `BOTH` 등으로 확실히 분류되어 빈값이 아닌 경우.
     - **조건 B:** 선행 배치 1([개선사항 1])을 통해 **`연령카테고리`가 빈값이 아니고 값이 채워진 경우(`OTHER`, `TEEN`, `ADULT`, `SENIOR`, `YOUTH` 등)**.

3. **LLM 분류 및 구조화된 JSON 파싱**

     ```json
     {
       "classification": "INDOOR" | "OUTDOOR" | "BOTH" | "UNKNOWN",
       "confidence": "high" | "medium" | "low",
       "reason": "판단 이유"
     }
     ```
   - LLM이 반환한 `classification` 결과를 DB의 `environment_type` 컬럼에 업데이트합니다.
