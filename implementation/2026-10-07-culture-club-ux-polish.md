# 문화센터 UX 다듬기 — CTA 문구, 찜 빈 박스, 반응형 그리드, 카테고리/연령 뱃지

## 구현 대상
사용자 피드백 4건:
1. "접수중하러 가기가 뭐야 접수페이지 가기 하던가" — 상세 시트 CTA 버튼
   문구가 어색함.
2. "찜은 왜 안떠? 찜 어디갔어" — 상세 시트에서 찜 버튼 자리가 빈 테두리
   박스로만 보임.
3. "PC에서 보면 문센은 한줄에 3개... 우리도 그렇게 안되나" — 카드 목록이
   화면 크기와 무관하게 항상 1열.
4. "Kids & Children(event)라던가 4세~5세 연령... 제목 아래 있는것들 눈에
   잘 안띄네.. 뱃지처럼" — 카테고리/연령 표시가 흐린 텍스트라 눈에 안 띔.

## 구현 일시
2026-10-07

## 변경 사항
1. **CTA 문구 고정화**: `{statusLabel(item)}하러 가기` → `접수 페이지로
   가기`(고정 문구)로 변경. "접수중"/"정원마감" 같은 상태 명사에 "~하러
   가기"를 붙이면 문법적으로 어색했다(이미 상태는 뱃지로 따로 보이므로
   버튼 문구에서 반복할 필요가 없었다).
2. **찜 버튼 빈 박스 제거**: 상세 시트에서 `BookmarkButton`을 감싸던
   `border border-gray-300` 래퍼 div를 없앴다. 열심맘 미달/비로그인이면
   `BookmarkButton`이 `null`을 반환하는데(Decision 019, 기존 설계 — 찜은
   열심맘 이상만 가능), 테두리 박스는 항상 그려졌어서 그 안이 비어
   보이는 게 "찜이 사라진 것"처럼 보였다. 참고로 이 등급 제한 자체는
   변경하지 않았다 — 비로그인/새싹맘 계정에서는 여전히 찜 버튼이 안
   보이는 게 의도된 동작이다.
3. **반응형 그리드**: 카드 목록 컨테이너를 `flex flex-col`에서 `grid
   grid-cols-1 md:grid-cols-2 lg:grid-cols-3`로 바꿔 모바일 1열, 중간
   화면 2열, PC 3열로 자동 전환되게 했다.
4. **카테고리/연령 뱃지화**: 기존 흐린 회색 텍스트 한 줄을 할인/마감임박/
   신설 뱃지와 같은 줄의 pill 뱃지로 바꿨다(카테고리는 회색, 연령은
   인디고색으로 구분). 여러 뱃지가 한 줄에 모여 여백도 줄었다.
