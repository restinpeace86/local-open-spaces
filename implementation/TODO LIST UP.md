# 표준 뱃지 기준
1. #신발벗는 온돌·마루방 : 신발을 벗고 들어가 영유아를 케어하거나 편하게 앉을 수 있는 온돌/마루/유아방 공간 여부
2. #영유아 전용 자료실 분리 : 초등학생 이상과 공간이 분리되어 영유아 전용으로 운영되는 자료실 여부
3. #소곤소곤 대화 가능 : 엄숙한 정숙 분위기가 아니라 아이에게 조근조근 책을 읽어주거나 작은 대화가 허용되는 유아 구역 여부
4. #주말 독서·체험 프로그램 : 주말 어린이 독서교실, 인형극, 만들기 등 프로그램 편성 여부
5. #영어 그림책 전문 : 영어 도서 소장 비중이 높거나 영어 프로그램 특화 여부
6. #만화·웹툰 특화 : 만화책, 그래픽노블, 웹툰 전용 서가나 공간 특화 여부
7. #주차 편리 (또는 주차 가능) : 자체 주차장 보유 또는 주말 주차 수월 여부
