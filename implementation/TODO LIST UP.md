[요청 1] events(이벤트픽) 전용 7대 대분류 및 중분류 매핑 체계 문서화

🎯 [핵심 전제 - 절대주의]
1. 본 중분류 및 7대 대분류 체계는 오직 events(이벤트픽) 테이블 전용이다. 
   open_spaces(스팟픽) 테이블은 장소/공간 특성이 달라 본 체계와 완전히 별개로 취급하며, 이번 작업 및 문서화 범위에서 완전히 제외/분리한다.
2. 대표가 직접 정의한 7대 대분류 구조를 마스터 골격으로 삼아 중분류를 1:N으로 매핑한다.

---

### 📌 1순위 작업 내용: 7대 대분류 - 중분류 매핑 체계 (events 전용)

1. **대표 확정 7대 대분류(category_maj) 및 중분류(category_min) 매핑**:
   - **자연 / 캠핑**: 캠핑장, 산림여가, 공원탐방
   - **공공 키즈카페**: 공공키즈카페(서울형키즈카페/경기아이사랑놀이터 등), 어린이실내놀이터
   - **체험 / 농장**: 농장체험, 도시농업(가족텃밭/주말농부), 자연/과학
   - **축제 / 이벤트**: 지역축제/페스티벌, 문화행사, 광장
   - **문화 / 전시**: 공연장, 전시실, 전시/관람, 미술제작, 공예/취미, 역사
   - **배움 / 클래스**: 교육체험, 교양/어학, 교육시설
   - **스포츠 대여**: 테니스장, 풋살장, 축구장, 체육관, 골프장, 농구장, 족구장, 야구장, 다목적경기장, 배드민턴장, 탁구장, 배구장, 수영장, 운동장, 피클볼장, 스포츠

2. **소스 확장 규칙**:
   - 서울시(`SEOUL_YEYAK`) 이벤트성 중분류 37종을 포함하여, 경기도(`gg_public`), TourAPI 등 전 소스의 events 데이터에 대해 위 7대 대분류 - 중분류 체계를 확장 적용한다.
   - 단체봉사, 청년정보, 녹화장소, 민원 등 불필요 행정 중분류는 노출 대상에서 배제한다.

### 📋 작업 지시
[요청 2] target_audience 정제 파이프라인 사전 영향도 분석 및 OCR 대상 최소화 데이터 파악 요청

🎯 [핵심 지침 - 절대주의]
1. 실제 DB 수정 및 정제 작업은 절대 수행하지 마라. (Read-Only 상태 유지)
2. 현재 DB에 수집되어 있는 events 전용 데이터 전체를 대상으로 아래 정제 알고리즘 시뮬레이션을 실행하여 [각 단계별 적용 건수 및 최종 OCR 필요 건수]를 분석 보고하라.
3. OCR 대상을 극단적으로 줄이기 위해 0~2단계에 추가할 만한 정밀 키워드 아이디어를 수집 데이터 패턴 기반으로 제안하라.

---

### 📌 분석 시뮬레이션 대상 알고리즘 (3단계 파이프라인)

* **전체 대상**: `events` 테이블 전체 데이터 (open_spaces 완벽 제외)

1. **서울시(SEOUL_YEYAK) 원천 1차 정형화 (OCR 100% 제외)**:
   - `USETGTINFO` 텍스트 괄호/사족 제거 후 표준 5대 태그(`CHILD`, `FAMILY`, `YOUTH`, `SENIOR`, `ALL`) 1:1 매핑 대상 건수 파악.

2. **경기도 및 타지역 미분류 데이터 3단계 시뮬레이션**:
   - **[0단계: 역방향 소거 최우선 적용 - Negative Override]**
     - 제목/설명 내 아래 소거 키워드 포함 건수 파악:
       - 학술/행정: `학술대회`, `세미나`, `학술`, `포럼`, `심포지엄`, `간담회`, `설명회`, `공청회`, `봉사활동`, `민원`
       - 전시/전람회: `개인전`, `정기전`, `회원전`, `초대전`, `교류전`, `학위청구전`, `졸업전시`, `동문전`, `동호회전`
       - 음악/공연: `독주회`, `독창회`, `리사이틀`, `귀국 연주회`, `정기 연주회`, `동문 음악회`
       - 부모/학부모: `학부모`, `부모교육`, `부모교실`, `부모특강`, `양육`, `성교육`, `지도자`, `지도법`, `자녀교육`, `아동학대예방`
       - 자격증/직무: `자격증`, `강사`, `전문가`, `재테크`, `부동산`, `창업`, `취업`, `역량강화`, `실무`, `직무교육`, `마케팅`
       - 어르신/주민: `주민`, `시민`, `성인`, `어르신`, `시니어`, `실버`, `은퇴`, `청년`

   - **[1단계: 키즈/가족 특화 자동 확정]**
     - 0단계를 통과한 데이터 중 중분류/원천분류가 아래 키워드인 자동 확정 건수 파악:
       - CHILD: `공공키즈카페`, `어린이실내놀이터`, `어린이/체험프로그램`, `아이사랑놀이터`, `장난감도서관`, `장난감대여`, `유아숲체험`, `어린이도서관`
       - FAMILY: `농장체험`, `도시농업(가족텃밭)`, `가족극`, `가족극장`, `가족뮤지컬`, `가족캠핑`, `가족야영장`, `가족체험`, `가족클래스`, `어린이/가족`

   - **[2단계: 명확 텍스트 파싱]**
     - 0·1 단계를 거친 잔여 데이터 중 제목/설명에 `어린이`, `유아`, `초등`, `가족동반` 포함 건수 파악.

   - **[3단계: 최종 OCR 대상 잔여건수 파악]**
     - 0, 1, 2단계를 모두 거치고도 여전히 `target_audience`가 NULL로 남게 되는 **최종 핀포인트 OCR 대상 데이터 건수 산출**.

### 📋 제출 및 보고 요청 사항
1. **[시뮬레이션 통계 보고]**:
   - 전체 events 건수 ➔ 서울시 1차 정형화 건수 ➔ 0단계 소거 건수 ➔ 1단계 자동 확정 건수 ➔ 2단계 텍스트 파싱 건수 ➔ **[🔥 최종 3단계 OCR 필요 건수]**를 수치화된 표 형태로 제시하라.
2. **[OCR 최소화 추가 키워드 제안]**:
   - 현재 3단계 OCR 대상(NULL)으로 분류된 잔여 데이터의 주요 패턴을 분석하여, **0단계(역방향 소거) 및 1·2단계(자동 확정)에 추가하여 OCR 대상을 더 줄일 수 있는 고효율 키워드 리스트를 제안**하라.
3. 분석 결과를 `docs/target-audience-analysis-report.md` 파일로 작성하여 제출하고 대표 승인을 요청하라.
