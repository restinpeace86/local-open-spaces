# [개발 요청] "현재 이용 가능"/"예약 가능" 카드 내부 이미지·텍스트 영역 비율 불일치 수정

## 구현 일시
2026-08-30

## 요구사항
"현재 이용 가능"/"예약 가능" 영역의 카드들은 크기(래퍼)가 모두 같은데, 카드 내부의
이미지 영역과 텍스트 영역 크기가 카드마다 제각각인 원인을 확인하고 수정.

## 원인
두 섹션 모두 `ReservationOpenSlider`(`w-40 h-64` 고정 래퍼)를 공유하고, 그 안의
실제 카드는 `EventCard`(`src/components/cards/event-card.tsx`)다. `EventCard`는
이미지:텍스트 영역을 `flex-[4]`/`flex-[6]`로 나눠 카드 높이를 정확히 40:60으로
분할하도록 이미 설계되어 있었다(2026-08-29 작업).

문제는 `getDateBannerBadge`(`src/lib/spaces/event-status.ts`)가 반환하는
"⚡ 오늘 한정"/"⏰ 오늘 마감" 배너였다 — **오늘 종료되는 이벤트에만** 뜨는 배너가
`flex flex-col` 버튼의 **별도 행**으로 이미지 영역 위에 얹혀 있었다. 그 결과:
- 배너가 있는 카드: `버튼 전체 높이(h-64) - 배너 높이`만 4:6으로 나뉨 → 이미지/텍스트
  모두 배너 없는 카드보다 작아짐.
- 배너가 없는 카드: 전체 높이(h-64)를 그대로 4:6으로 나눔 → 더 큼.

같은 h-64 래퍼 안에서도 카드마다 "오늘 마감인지 아닌지"에 따라 내부 비율이 달라진
것이다. 실제 라이브 데이터로 확인한 결과 "현재 이용 가능" 20건 중 7건, "예약 가능"
20건 중 5건이 오늘 마감이라 배너가 붙어 있었다 — 실제로 매 새로고침마다 눈에 띄게
발생하는 문제였다.

## 조치
`src/components/cards/event-card.tsx`: dateBanner를 `flex-col`의 별도 행에서
이미지 영역(`flex-[4]`) 내부의 **절대 위치 오버레이**로 옮겼다. 이제 배너는
레이아웃 흐름에 전혀 참여하지 않으므로, 배너 유무와 무관하게 버튼의 최상위 자식은
항상 이미지 영역/텍스트 영역 둘뿐이고 4:6 분할도 항상 동일하다. 배너와 겹치지 않도록
기존 중분류/상태 뱃지(`top-2`)는 배너가 있을 때만 `top-8`로 한 칸 내려 배치했다.

이 컴포넌트는 그리드/검색/무료 피드 등 여러 화면에서 공유되지만(제5장 제4조 기존
구조 우선), 높이가 `h-full`(부모가 고정 높이를 줄 때만 의미가 있고 그 외엔
`auto`와 동일)이라 이번 변경은 다른 화면의 시각적 결과에 영향을 주지 않는다 — 오히려
배너가 있는 카드가 그리드에서 형제 카드보다 미세하게 더 커 보이던 부수적 불일치도
함께 해소된다.

## 정정(2026-08-30, 사용자 재확인 이후) — 진짜 원인은 dateBanner가 아니었음

위 조치를 배포한 뒤 사용자가 "여전히 비율이 깨진다"고 재확인했다. jsdom 기반
유닛 테스트만으로는 실제 브라우저 레이아웃(flex 계산)을 검증할 수 없다는 한계를
인지하고, Playwright(이미 `@playwright/test`로 이 프로젝트에 설치되어 있음)로
실제 로컬 개발 서버 페이지를 렌더링해 카드별 이미지/텍스트 영역의 **실제 렌더링
픽셀 높이**를 직접 측정했다.

**측정 결과**: dateBanner 오버레이 수정 이후에도 "현재 이용 가능" 카드 8장의
이미지 영역 높이가 92, 92, 223, 197, 223, 224, 158, 198(px)로 완전히 제각각이었고,
dateBanner 유무와도 상관관계가 없었다 — 1차 수정의 원인 진단(dateBanner) 자체가
틀렸다는 뜻이다.

**진짜 원인**: 이미지 영역 div(`flex-[4]`)에 `min-h-0`이 빠져 있었다. flex
아이템의 기본값 `min-height: auto`는 내용물의 min-content 크기 밑으로는 줄어들지
않으려 하는데, `<img>`(교체 요소)의 min-content 크기는 **그 이미지의 실제 원본
가로세로 비율을 고정폭(w-full, 카드 폭 w-40 기준)에 대입한 높이**다. 즉 이미지
영역은 flex-[4]가 지정한 40%가 아니라 "각 썸네일의 실제 원본 비율이 요구하는
높이"로 늘어나 버렸고, 텍스트 영역(flex-[6], 이쪽은 이미 `min-h-0`이 있어 정상
동작)은 남은 공간만큼만 줄어들었다 — 카드 전체 높이(h-64=256px)는 항상 같아도
내부 이미지:텍스트 분할은 썸네일 이미지의 원본 비율에 따라 카드마다 완전히
달랐던 것이다.

**수정**: 이미지 영역 div에도 `min-h-0`을 추가했다. 이는 텍스트 영역에 이미
적용되어 있던 것과 정확히 동일한 원리다 — 두 flex 아이템 모두 `min-h-0`이 있어야
`flex-[4]`/`flex-[6]`이 내용물(이미지 원본 비율이든, 뱃지+제목 텍스트 양이든)과
무관하게 항상 지켜진다.

### 재검증(Playwright, 실제 렌더링 픽셀 측정)
동일한 측정 스크립트를 다시 실행한 결과 "현재 이용 가능"/"예약 가능" 두 섹션
합계 16장 전부(배너 유무와 무관하게) 이미지 영역 92px : 텍스트 영역 162px로

개선(배너가 레이아웃에 영향을 주지 않는 것이 맞다)이라 되돌리지 않고 유지했다.
