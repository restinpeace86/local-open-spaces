# 사용자 제공 CSV(batch6) 기반 어린이도서관 뱃지 일괄 반영

## 구현 대상
사용자 지시(2026-09-29): "children_libraries_analysis_batch6.csv 여기있는
것들에 대하여 주소랑 제목 비교해서 우리쪽 노출중분류 '어린이도서관'에
적합한것들에 대하여 뱃지채워줘" — 2026-09-28-apply-children-library-csv-
badges.mjs(batch1)와 동일한 절차를 batch6(59행)에 적용.

## 처리 과정
1. CSV가 CP949로 인코딩돼 있어 UTF-8로 변환 후 파싱.
2. category_min='어린이도서관'의 대표 행(128건, 2026-09-29 중복 병합
   4쌍 반영 후 갱신된 수치) 조회.
3. 이름(공백 무시) 매칭 후 CSV "지역" 열과 DB 주소의 시/도 일치까지 확인
   (batch1과 동일한 동명이인 방지 절차).

## 결과
- **안전 반영 49건**: 이름+지역 명확히 일치.
- **판단 필요 후보 2곳 — 개별 검토**:
  - **서울특별시교육청어린이도서관**(서울 종로구): DB에 후보가 **3개**로
    늘어 있었다(이 spot의 raw `name` 필드가 이전 세션에서 "노출이름에
    있다"는 사용자 제보로 처음 발견된 fc529917 포함). 이 중 주소가 정확히
    일치하는 f5759c7f/4ecb04fc 쌍(종로구 **사직로9길 7**)만 같은 실제
    장소로 보고 반영했다. fc529917(종로구 **사직로 89**, 사직공원 인근)은
    주소 문자열이 명확히 다르고 실제로 같은 기관인지 확인할 근거가 없어
    반영하지 않았다(제3장 제5조 추측 금지).
  - **글마루한옥어린이도서관**(서울 구로구): batch1과 동일하게 후보 2개 중
    원문 소개글로 확인된 aac0f845만 반영(이미 batch1에서 반영돼 있어 이번
    실행은 멱등하게 동일한 값으로 재기록됨).
- **미반영 8건 — 지역 불일치**(추측으로 반영하지 않음): 비봉어린이도서관
  (CSV: 경기 화성시 / DB: 경남 진주시), 동구어린이영어도서관(대구 동구 /
  부산 동구), 별똥별어린이도서관(서울 도봉구 / 인천 계양구), 꿈꾸는어린이
  도서관(경기 오산시 / 서울 강서구 "강서꿈꾸는어린이도서관"), 산성어린이
  도서관(경기 성남시 / 대전 중구), 이랑어린이도서관(부산 부산진구 / 인천
  미추홀구), 꿈키어린이도서관(경기 / 부산 동래구), 서구어린이도서관(인천
  서구 — DB 후보가 대구/대전뿐, batch1과 동일하게 반영 보류).
