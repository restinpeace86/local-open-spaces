# [큐레이션/제휴 상품 탭: 신규 등록 진입점을 마이리얼트립 검색으로 전환]

## 구현 대상
사용자 지시(2026-09-16): "이제 기존 큐레이션/제휴 상품 탭은 폐기하고
마이리얼트립 상품 검색을 사용하자" — 확인 질문에 대한 답: "등록/관리 기능은
그대로 남기고, 검색만 마이리얼트립으로 전환(권장)".

## 구현 일시
2026-09-16

## 변경 사항
### `src/components/admin/curated-items-panel.tsx`
빈 폼에 URL/제목/이미지를 직접 타이핑해 등록하던 "+ 신규 상품 등록" 버튼을
제거하고, "🔍 마이리얼트립 상품 검색" 탭으로 안내하는 문구로 대체했다. 이미
등록된 상품의 **목록 조회/수정/삭제/노출 on-off는 그대로 유지**했다 — 사용자가
명시적으로 "등록/관리 기능은 그대로 남기고"라고 확인했다.

## 검증
- `npx tsc --noEmit`, `npm run test`(전체 1828개), `npm run build` 모두 통과.
- 기존에 "+ 신규 상품 등록" 버튼 클릭 흐름을 검증하던 테스트는 이제 유효하지
  않은 시나리오라 제거하고, 대신 "버튼이 안 보이고 안내 문구가 뜬다"는 테스트로
  교체 — 등록 자체의 회귀 검증은 이미 존재하는 `myrealtrip-search-panel.test.tsx`
  (검색→상세→마이링크 생성→등록 폼) 쪽이 담당한다.
