# EventCard 이미지:텍스트 비율 4:6 → 5:5 조정

## 구현 일시
2026-09-03

## 배경
직전 작업(카드 뱃지 정리)에서 무료/유료·실내야외 뱃지를 텍스트 영역에서 이미지
오버레이로 옮겨 텍스트 영역이 필요로 하는 공간이 줄어들었다 — "뱃지를 이미지 쪽으로
옮겼으니 비율도 5:5로 바꿔달라"는 후속 지시.

## 구현 내용
`EventCard`의 이미지 영역(`flex-[4]`)/텍스트 영역(`flex-[6]`)을 각각 `flex-[5]`로
맞춰 정확히 50:50으로 조정했다. 두 영역 모두 `min-h-0`을 그대로 유지해(2026-08-30에
고친 "이미지 실제 비율이 flex 비율을 무시하는" 버그 방지 장치) 비율이 항상 정확히
지켜지도록 했다. dateBanner(오늘 마감/오늘 한정) 오버레이는 여전히 이미지 영역
안에만 존재해, 배너 유무와 무관하게 5:5 분할이 항상 동일하게 유지된다(기존 검증된
구조 그대로).

## 검증
`npx tsc --noEmit`/`npm run test`(97파일 996건 — event-card.test.tsx의 비율 관련
단언을 flex-[5]/flex-[5]로 갱신)/`npm run build` 통과. 빌드 산출물(`.next/static/
chunks/*.js`)에 `flex-[5]` 클래스가 실제로 포함됐음을 확인.
