# [EventCard 이미지:텍스트 4:6 포션 고정]

## 요구사항
1. 이벤트픽 홈 슬라이드/바텀시트에 쓰이는 `EventCard`의 고정 높이(h-64) 안에서, 이미지
   영역과 텍스트 영역을 세로 플렉스로 나누고 비율을 `flex-[4]`/`flex-[6]`로 명시적으로
   고정한다. 이미지는 `w-full h-full object-cover`로 찌그러짐 방지, 텍스트 영역은 뱃지/
   제목/날짜가 정돈되게, 제목은 `line-clamp-2`.
2. 검증 후 커밋/푸시.

## 구현 일시
2026-08-29

## 1. 사전 확인 및 설계 판단(AskUserQuestion)

지시서의 "하단 텍스트 영역: 카테고리 뱃지, 제목, 날짜 등이 깔끔하게 배치"라는 문구가, 현재
이미지 위 오버레이로 떠 있는 중분류 태그·상태 라벨·마감임박 배너를 텍스트 영역으로
옮기라는 뜻인지, 아니면 기존 배치는 그대로 두고 두 컨테이너의 세로 비율만 명시적으로
4:6으로 고정하라는 뜻인지 모호했다(제3장 제5조 추측 금지) — 셋 다 옮기면 텍스트 영역(60%,
약 150px)에 뱃지 3종+제목 2줄+장소+날짜+예약태그+부가뱃지까지 들어가 하단이 잘릴 위험이
있어 실제 결과물이 크게 달라지는 판단이었다. AskUserQuestion으로 확인한 결과 "이미지 위
오버레이 유지(권장)"로 확정 — 중분류 태그/상태 라벨/마감임박 배너는 기존 위치 그대로 두고,
이미지·텍스트 두 컨테이너의 flex-basis만 바꾸는 가장 보수적인 변경으로 진행했다.

## 2. 구현 (`event-card.tsx`)

- 이미지 컨테이너: `relative aspect-[16/9] bg-gray-100` → `relative flex-[4] bg-gray-100`.
  기존에는 이미지 자체의 가로세로 비율로 높이가 정해져 카드 실제 높이(h-64 등)와 무관하게
  움직였는데, 이제 카드 전체 높이의 40%로 고정된다. `<img>`/플레이스홀더는 이미 `w-full
  h-full object-cover`였으므로 그대로 유지(요구사항 그대로 충족).
- 텍스트 컨테이너: `p-3 flex-1 flex flex-col gap-1.5` → `p-3 flex-[6] min-h-0
  overflow-hidden flex flex-col gap-1.5`. `min-h-0`을 추가한 이유: flex 아이템의 기본값
  (`min-height: auto`)은 내용물(뱃지+제목+장소+날짜 등)이 요구하는 최소 높이보다 작게
  줄어들지 않으려 하는데, 이걸 그대로 두면 콘텐츠가 많은 카드에서 텍스트 영역이 60%를
  넘겨버려 카드 전체 높이가 h-64보다 커질 수 있다 — `min-h-0`으로 강제 축소를 허용하고
  `overflow-hidden`으로 넘치는 내용은 잘라내, 어떤 카드든 정확히 4:6 비율의 h-64 안에
  들어가도록 보장한다.
- 제목(`line-clamp-2`)은 기존에 이미 적용돼 있었다(Step 61에서 추가) — 그대로 유지.
- `dateBanner`(오늘 마감/오늘 한정 상단 바)는 이미지/텍스트 두 영역 밖의 별도 형제
  요소로, 지금까지와 동일하게 유지했다(위 AskUserQuestion 결정에 따라 이동하지 않음) —
  이 배너가 있는 카드는 이미지+텍스트가 h-64 전체가 아니라 배너 높이를 뺀 나머지를 4:6으로
  나눈다는 점은 기존과 동일한 특성이다.

## 특이 사항
- 이 변경은 `EventCard`를 재사용하는 모든 화면(홈 슬라이드, `EventBrowseSheet` 바텀시트,
  "오늘 전체보기" 그리드, 카테고리별 행사 그리드 등)에 공통 적용된다 — 지시서가 "홈 슬라이드
  및 바텀시트"만 언급했지만, 컴포넌트가 공유되는 구조라(제5장 제4조) 화면별로 분기하지
  않았다. 그리드처럼 부모가 높이를 지정하지 않는 화면에서는 `h-full`이 `height: auto`와
  동일하게 동작하므로(Step 61 관례) 4:6 비율은 부모가 실제 높이를 고정해 주는 화면
  (슬라이더의 `h-64`)에서만 시각적으로 드러난다.
