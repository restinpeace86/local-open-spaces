# 상세페이지 바텀시트(80%) → 풀페이지(100%) 전환 + 상단 고정 헤더

## 구현 대상
`todo.md` 개선사항 2 중 가장 큰 항목: "상세페이지 현재는 바텀시트 업으로
해서 상세페이지가 전체의 약 80%? 이 정도만 보이는데 그게아니고 전체의
100% 다 차지하도록" + "원페이지에서 내릴때 각 영역에 대하여 위에는
상단 고정이 되도록 하자" + "모바일 퍼스트 기준의 UX로써 보여지게 점검".

## 구현 일시
2026-10-20

## 변경 사항
`src/components/map/detail-modal.tsx` (EVENT/SPACE 두 분기 모두):

1. **풀페이지 전환**: 외곽 컨테이너를 `max-h-[85vh] md:max-h-[80vh]`
   (+ 모바일 `rounded-t-2xl`)에서 `h-[100dvh] md:h-auto md:max-h-[80vh]`
   (모바일은 둥근 모서리 없이 화면 전체, 데스크톱은 기존 중앙 모달
   그대로 유지)로 바꿨다. 이미지/플레이스홀더의 자체 `rounded-t-2xl`도
   모바일에서는 제거(md:만 유지) — 풀페이지에서 모서리만 따로 둥글면
   어색해서다.
2. **상단 고정 헤더**: 스크롤 영역의 첫 자식으로 `sticky top-0` 바를
   추가해 지금 보고 있는 스팟/이벤트 이름을 항상 보여준다
   (`env(safe-area-inset-top)`로 노치 기기 고려). **해석 선택**: "각
   영역에 대하여" 상단 고정을 영역마다 각기 다른 레이블이 붙는 다단
   그룹 헤더(연락처 앱 스타일)로도 읽을 수 있었으나, 실제 서비스들의
   표준 패턴(스크롤 시 제목바 고정 — Airbnb/구글맵 장소 상세 등)과
   동일하게 **페이지 전체에 하나의 지속적인 식별 바**로 단순화했다 —
   detail-modal.tsx 자체가 이미 1,480줄 넘는 8단 구조라, 영역마다 별도
   헤더를 끼워 넣는 건 훨씬 큰 재구성이 필요하고 회귀 위험도 크다.
   영역별 개별 헤더를 원하면 구체적으로 어떤 영역에 어떤 레이블을
   원하는지 확인 후 별도로 진행하는 게 안전하다고 판단했다.
3. **기존 닫기 버튼 유지**: EVENT는 원래도 절대 위치 닫기 버튼이 스크롤
   영역 밖에 있어 이미 상시 노출됐다(그대로 유지, safe-area만 보정).
   SPACE는 원래 닫기 버튼이 뱃지 줄 안에 있어 스크롤하면 사라졌는데,
   이번에 추가한 상단 고정 바에도 닫기 버튼을 넣을지 고민했으나 범위를
   "이름이 항상 보이게"로 좁히고 기존 닫기 버튼은 그대로 남겨뒀다(완전
   제거하면 중복 닫기 버튼 2개가 되어 오히려 혼란 — 필요하면 후속으로
   스크롤 중 닫기 버튼까지 상단 바에 추가 가능).

- **실제 화면 확인(Playwright, 모바일 뷰포트 390×500)**: 개발 서버
  기동 후 이벤트픽 홈에서 카드 클릭 → 상세 모달이 화면 전체를 차지
  (둥근 모서리 없음) 확인, 모달 내부를 스크롤해 상단 바가 그 자리에
  고정된 채 아래 콘텐츠만 스크롤되는 것을 스크린샷으로 직접 확인,
  콘솔 에러 0건. SPACE 분기는 홈 피드/`/region` 양쪽에서 실데이터로
  열어보려 했으나 홈 피드엔 노출된 스팟 카드가 없고 `/region`은 로컬
  개발 DB의 사전 존재하는(이번 변경과 무관한) 쿼리 타임아웃으로 막혀
  실측 스크린샷은 못 남겼다 — 대신 SPACE 전용 단위 테스트(h-[100dvh]/
  sticky 클래스)로 구조를 직접 검증했고, EVENT와 동일한 CSS 패턴(오히려
  SPACE 쪽이 래퍼 중첩이 더 단순)이라 추가 위험은 낮다고 판단.

## 특이 사항
- 데스크톱(md 이상)은 기존 중앙 모달(최대 80vh)을 그대로 유지했다 —
  "80%만 보인다"는 불만은 모바일 바텀시트에 대한 것이었고 데스크톱
  중앙 모달은 그 문제가 없었다고 판단해 범위를 모바일로 좁혔다.
- "모바일 퍼스트 점검"은 이번 변경(풀페이지+상단고정) 자체가 그
  점검의 핵심 산출물이다 — 추가로 더 손볼 지점이 보이면 구체적으로
  알려주면 이어서 진행한다.
