# open_spaces 목록 컬럼 정리 + 체크박스 일괄 편집 기능

## 구현 대상
사용자 지시: "현재 open_spaces에 나오는 데이터 목록 컬럼보면 불필요하게 많이
나오는게 보여..
1. ID와 출처는 비슷하니 출처 컬럼만 남겨
2. 원천 대/중분류 컬럼은 안보이게 해
3. 제목/명칭 컬럼과 장소/시설명 컬럼도 동일해.. 제목/명칭 컬럼만 남겨
4. 요금, 접수상태 컬럼은 안보이게 해
5. 리스트 앞에 체크박스 하나 만들고 체크 박스 선택된 것들에 대하여 표준
   중분류랑 노출 중분류 일괄적으로 수정 가능하도록도 기능만들어줘"

## 구현 일시
2026-09-07

## 변경 사항

### 1~4. 컬럼 정리 (open_spaces 전용, events는 영향 없음)
`src/components/admin/data-grid-client.tsx`의 테이블 `<thead>`/`<tbody>`:
- ID(external_id) 컬럼을 open_spaces에서 숨김(출처만 남김). events는 유지.
- 원천 대/중분류(MAXCLASSNM/MINCLASSNM 또는 카테고리 배지) 컬럼을 open_spaces에서
  숨김. events는 유지.
- 장소/시설명 컬럼을 open_spaces에서 숨김 — open_spaces는 제목/명칭과 장소/
  시설명이 둘 다 `name` 컬럼이라 완전히 같은 값이었다(실측 확인). events는
  title과 venue_name이 서로 다른 값이라 그대로 유지.
- 요금/접수상태 컬럼을 open_spaces에서 숨김. events는 유지.

### 5. 체크박스 + 일괄 편집
- 헤더에 "이 페이지 전체 선택" 체크박스, 각 행에 개별 선택 체크박스 추가
  (open_spaces 탭 전용, `onClick` 이벤트 전파를 막아 체크박스를 눌러도 상세
  모달이 열리지 않게 했다).
- 1건 이상 선택되면 그 위에 일괄 편집 바가 나타난다 — "표준 중분류" 드롭다운
  (`filterOptions.open_spaces.categoryMins` 재사용, 새 조회 없음)과 "노출
  중분류" 드롭다운(`serviceCategories`, 상세 모달이 이미 쓰던 지연 로딩을
  체크박스 선택 시에도 함께 트리거하도록 공유 — `ensureServiceCategoriesLoaded`)
  중 고른 것만 적용한다.
- 서버 호출은 기존 엔드포인트 2개를 그대로 재사용한다(제5장 제4조 기존 구조
  우선 — 새 엔드포인트를 만들지 않음):
  - 표준 중분류: `PATCH /api/admin/data-grid/category-min`에 `ids: string[]`
    배열 모드를 새로 추가했다(기존 단일 `id` 모드는 그대로 유지 — 상세
    모달의 개별 수정에 계속 쓰인다). 대량 오적용 방지를 위해 이 배열 모드는
    값 없이 NULL로 되돌리는 것을 허용하지 않는다(개별 되돌리기는 상세
    모달에서 계속 가능).
  - 노출 중분류: 기존 `POST /api/admin/open-spaces/bulk-category-mapping`의
    `ids` 모드를 그대로 재사용(신규 코드 없음).
- 적용 성공 시 화면의 해당 행들을 즉시 갱신(재조회 없이)하고 선택을 해제한다.

## 특이 사항
- 구현 중 발견한 버그 2건을 자체적으로 고쳤다: (1) "전체 선택" 체크박스가

  테스트를 작성하는 과정에서 실측으로 발견해 수정했다.
