# 놀이방찜질방/스파 뱃지 — 유아의자/기저귀 교환대/수유실 추가

## 구현 대상
사용자 지시(2026-09-26): "편의쪽에 유아의자 이런거도 넣어줘 그래도 키즈친화인데..
기저기갈이대라던가 수유룸? 이있을수도 있나 요즘 찜질방 스파는?" → "어.. 그렇게 해".

## 근거
아뮤즈스파&피트니스 남악점 실측 크롤링 결과 편의시설(conveniences) 배열에
"유아의자"가 실제로 있었다: `["단체 이용 가능","예약","무선 인터넷","남/녀
화장실 구분","유아의자","대기공간","유아시설 (놀이방)","주차"]`. 반면 같은
실측 데이터의 `InformationFacilities` 전체 카탈로그(네이버가 정의한 선택
가능한 편의시설 태그 전체 목록)에는 "기저귀갈이대"/"수유실"에 해당하는
항목이 없었다 — 이 업체가 선택을 안 했을 가능성도 있어 완전히 없다고 확정할
수는 없지만, 최소한 이 실측 데이터로는 근거가 약하다.

## 변경 사항
`src/lib/admin/curation-badges.ts`의 `SPA_JJIMJILBANG_CONFIG`(이동/편의
그룹)에 3개 추가:
- `jj_kids_chair`(유아의자) — 실측으로 확인됨. 편의시설(conveniences) 텍스트
  자동 매칭 대상(다른 뱃지들과 동일하게 이미 일반화된 `matchBadgeKeysFromText`
  경로를 그대로 탄다 — 별도 코드 추가 불필요).
- `jj_diaper_table`(기저귀 교환대), `jj_nursing_room`(수유실) — 근거가 약해
  편의시설 자동체크 대상에 넣지 않고, 블로그 후기 키워드 매칭으로만 채운다
  (추측 금지, 제3장 제5조 — 확신 없는 사실을 자동 확정하지 않음).
- 키워드는 기존 `RESTAURANT_KEYWORD_GROUPS`/`GENERIC_KEYWORD_GROUPS`의 동일
  개념 키워드를 그대로 재사용했다(제5장 제4조, 새로 지어내지 않음).
