## nadrilab.com 실측 구조 (예시 페이지 기준)
사용자가 제공한 URL(`/places/경기-하남시-...`)을 직접 조회해 확인한
실제 페이지 구조, 위에서 아래 순서:

1. 상단 내비(로고, 추천/지도/캘린더/내 기록, 하단에 서비스 소개·약관·
   블로그·인스타 링크)
2. 제목 영역: 지역+카테고리("경기 하남시 키즈카페") + 장소명
3. 기본 정보: 주소(지도 보기 링크) + 추천 연령("영아 ~ 미취학"). **가격/
   영업시간/주차는 별도 항목으로 없음**
4. 주변 탐색 배너("5km 안에 갈 곳 4곳")
5. 액션 버튼(계획 세우기/저장/카톡 공유/네이버 검색)
6. "풍선 남기기"(방문 인증, 로그인 없이 3일간 노출)
7. 사진 슬라이드(검증된 사진만)
8. 사진 제보 안내 + 방문 횟수 뱃지(첫 발걸음/나들이 단골/애호가/마스터)
9. **"나들이랩 코멘트"** — 편집자가 쓴 글 하나에 가격·주차·매점·직원
   유무를 전부 녹여서 설명(예: "직원이 없는 구조라 아이를 혼자 두고
   자리를 비우면 안 돼요")
10. 근처 다른 키즈카페 목록
11. 쿠팡 파트너스 상품 추천(한 줄 설명 + 수수료 고지)
12. 위치(네이버 지도/카카오맵 링크)
13. 주변에서 함께 볼 만한 곳
14. "이런 상황이면 여기도"(연령/날씨/놀이 유형별 가이드 링크)

**블로그 리뷰 섹션 자체가 없다** — 상단 내비의 외부 블로그 링크 하나뿐.

## 톤/표현
설명적이고 실용적인 해요체. 감성 표현보다는 "이거 조심하세요" 류의
상황 안내가 중심. 뱃지는 시설 정보용이 아니라 **방문 인증용**(사진
개수 기준)이고, 주차가능/실내외 같은 정보 뱃지 자체가 없다 — 전부
코멘트 본문 문장으로 표현된다.

## 우리 쪽과의 비교 및 시사점

| 항목 | nadrilab.com | 우리 쪽(이번 세션 변경 후) |
|---|---|---|
| 페이지 구조 | 처음부터 풀페이지 | 모바일 기준 풀페이지로 전환 완료 |
| 정보 표현 방식 | 뱃지 거의 없음, 편집자 글로 풀어서 설명 | 뱃지 + 뱃지별 한 줄 문구(사용자가 명시적으로 요청한 방향) |
| 톤 | 실용적 해요체 | 사용자가 명시적으로 "감성적이고 부드러운 톤" 요청 |
| 블로그 리뷰 | 없음 | 유지(제목 노출 개선 완료) |
| 방문 인증/뱃지 | 사진 개수 기반 방문 인증 뱃지 | 미보유(이번 범위 밖) |
| 주변 정보 | 별도 배너+목록(거리 표시) | 아코디언 폐기 → 평면 섹션(이번에 적용) |

**핵심 발견**: "나들이랩처럼"이 꼭 "뱃지에 한 줄씩 감성 문구 붙이기"를
의미하진 않는다 — 오히려 nadrilab은 뱃지를 거의 안 쓰고 글로 풀어서
설명하는 쪽이다. 다만 사용자가 뱃지+한줄문구를 명시적으로 예시까지
들어 요청했으므로(todo.md 원문: "주차가능 뱃지는 '주차하기 편해요'"),
그 방향은 nadrilab 벤치마킹과 무관하게 사용자의 직접 지시로 그대로
구현했다(이미 완료, `2026-10-20-spot-badge-area-one-liner-copy.md`).

풀페이지 전환/주변정보 평면화는 nadrilab과 방향이 일치해 그대로
반영했다(이미 완료).

## 벤치마킹할 만하다고 판단되는 것(제안, 구현 안 함)
Spec에 없는 추가 기능 제안이라 여기 기록만 하고 구현하지 않는다 —
필요하면 검토 후 별도 지시로 진행.

1. **방문 인증 뱃지(사진 개수 기반)**: 사용자 참여를 유도하는 간단한
   게이미피케이션. 우리 쪽엔 유사 기능이 없다.
2. **"주변에서 함께 볼 만한 곳" / "이런 상황이면 여기도"**: 연령/날씨/
   상황 기반 추천 목록 — 우리의 "맘스픽"이나 추천 로직과 결이 다른,
   상세페이지 하단의 가벼운 2차 탐색 유도 섹션.
3. **코멘트 하나로 가격/주차/주의사항을 녹여 쓰는 방식**: 우리는 뱃지로
   쪼개 보여주는 반대 방향을 택했다 — 장단점이 있다(뱃지: 스캔하기
   쉬움 / 글: 맥락과 뉘앙스 전달에 유리). 지금 방향(뱃지+한줄문구)을
   유지하되, 향후 "큐레이션 노트"처럼 자유 서술 영역을 보강할 여지는
   있다.
