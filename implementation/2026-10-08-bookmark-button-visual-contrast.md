# 찜 버튼 on/off 비주얼 대비 강화

## 구현 대상
사용자 지적(2026-10-08): "각 카드들에 대하여 찜하는거.. 찜이게 어떤게
누른거고 안누른건지... 눈에 안띄어 찜안한거랑 한거랑 차이 확 나도록
해줘... 찜한건 루비색으로 하던가.."

## 구현 일시
2026-10-08

## 근본 원인
`BookmarkButton`(스팟/이벤트/이마트·롯데마트·신세계·현대 문화센터 카드 등
앱 전역에서 공유하는 단일 컴포넌트)이 ❤️/🤍 이모지 전환만으로 on/off를
구분했다. 흰색/밝은 배경의 카드 위에서 🤍(흰 하트, 보통 옅은 테두리만
있는 글리프)가 배경에 거의 묻혀 "찜 안 한 상태"가 눈에 띄지 않았다.
이모지 글리프는 플랫폼 폰트가 자체 색을 고정해 CSS `color`로 재지정할
수 없어, 테두리/배경을 더하는 식으로는 근본적인 대비 문제를 해결할 수
없었다.

## 변경 사항
- `src/components/community/bookmark-button.tsx`: 이모지 대신 직접 그린
  `HeartIcon` SVG로 교체.
  - 찜 안 함: `fill="none"`, `stroke="#9ca3af"`(연한 회색 윤곽선만).
  - 찜함: `fill="#e11d48"`(루비/로즈 레드, 사용자가 제안한 "루비색"),
    `stroke`도 동일 색.
  - SVG는 CSS가 아니라 React prop으로 색을 직접 지정하므로 플랫폼/폰트에
    무관하게 항상 동일하게 렌더링된다 — 이모지 대비 문제의 근본 해결.
  - `aria-label`(`찜하기`/`찜 해제`)은 그대로 유지 — 기존
    `bookmark-button.test.tsx`는 aria-label만 참조해 수정 없이 통과.

## 검증
- `npx tsc --noEmit` 통과.
- `npm run test`(292개 파일 2,998개 전체, `bookmark-button.test.tsx` 3개
  포함) 통과 — 테스트가 아이콘 렌더링 방식이 아니라 aria-label/토스트
  문구만 검증해 수정 불필요.
- `npm run build` 통과.
- 실제 브라우저 스크린샷 확인은 이 환경에 브라우저/스크린샷 도구가 없어
  수행하지 못했다 — SVG 자체 속성(fill/stroke 색상)으로 대비를 주는
  방식이라 렌더링 엔진에 따라 달라질 여지가 거의 없음을 코드 레벨로
  확인했다(정직하게 한계를 기록).
