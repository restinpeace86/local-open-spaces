# 사용자 제공 CSV 기반 어린이도서관 뱃지 일괄 반영

## 구현 대상
사용자 지시(2026-09-28): "D:\workspace\local-open-spaces\children_libraries_analysis.csv
여기에 도서관 관련 뱃지 부여한것들 있어 C열.. 도서관 명칭과 지역으로
'어린이도서관'중분류에 있는 데이터중 어떤 데이터인지 확인하고 부여된 뱃지에
대하여 체크해서 db에 저장해"

## 처리 과정
1. CSV가 CP949(EUC-KR)로 인코딩돼 있어 UTF-8로 변환 후 파싱(66개 행,
   컬럼: 도서관 명칭/지역/부여된 뱃지 리스트/판단 근거).
2. category_min='어린이도서관'의 대표 행(그룹 대표 또는 그룹 미소속) 132건을
   조회해 이름(표준명/노출명/원본명, 공백 무시)으로 1차 매칭.
3. **동명이인 위험 검증**: 이름만으로 매칭하면 같은 이름, 다른 실제 장소를
   잘못 연결할 위험이 있다 — 실제로 "화전어린이도서관"이 CSV는 경기 고양시를
   가리키는데 DB에는 경남 남해군 소재의 동명 시설만 있었다(사용자가 이전
   대화에서 "화정하고 화전은 주소부터 다르다"고 직접 확인해준 사례와 정확히
   일치하는 함정). 그래서 이름 매칭 후 CSV의 "지역" 열과 DB 주소의 시/도가
   실제로 일치하는 것까지 확인했다(대구/서울/인천 등 17개 광역시도
   별칭 테이블로 대조).

## 결과
- **안전 반영 61건**(스팟 행 기준, CSV 66행 중 57행에 대응):
  - 52건: 이름+지역이 명확히 일치.
  - 4건(8행): 같은 실제 장소를 가리키는 **미병합 중복 대표 행**이 DB에 2개씩
    남아있어(예: 국립어린이청소년도서관 — 5fbaa562/37419c19 둘 다 같은 주소의
    대표 행) 둘 다에 반영했다(같은 실제 장소라 둘 다 반영해도 안전 — 어느 쪽이
    최종 대표로 남든 뱃지가 보인다). 이 4쌍(노원어린이도서관/
    국립어린이청소년도서관/아리랑어린이도서관/지혜샘어린이도서관)은 아직
    dedup 그룹으로 묶이지 않은 별개 데이터 품질 이슈라 이번 범위에서는 손대지
    않고 기록만 남긴다.
  - 1건: "글마루한옥어린이도서관" — 후보 2개 중 원문 소개글로 이미 확인된 쪽
    (aac0f845, "우리구 개봉동에 조성한 '구로구립 글마루 한옥어린이도서관'")만
    반영. 다른 후보(4895720d)는 주소 문자열 자체에 "개봉어린이도서관"이라는
    다른 이름이 박혀 있어 다른 시설일 가능성이 높아 제외.
- **미반영 8건 — 지역 불일치**(추측으로 반영하지 않음, 제3장 제5조):
  - 느티나무어린이도서관(CSV: 경기 용인시 / DB 유일 후보: 서울 중구) — DB
    쪽은 이전 세션에서 원문 소개글까지 확인된 실제 서울 중구 사립 도서관이라,
    CSV가 다른 동명 시설(경기 용인시)을 가리켰을 가능성이 높다.
  - 화전어린이도서관(CSV: 경기 고양시 / DB 유일 후보: 경남 남해군) — 사용자가
    이미 별개 장소로 확인해준 바로 그 사례.
  - 생각자람어린이도서관, 서구어린이생태학습도서관, 서구영어도서관, 서구
    어린이영어도서관, 죽정도서관, 달빛나래어린이도서관 — CSV 지역란이 원래
    "인천 서구 등"/"강원 원주시 등"처럼 스스로도 불확실하게 적혀 있었고, DB
    유일 후보의 실제 주소는 그 지역과 다른 광역시도였다.
- **미반영 1건 — 카테고리 불일치**: "구로꿈나무도서관"은 DB에 존재하지만
  표준중분류가 '어린이도서관'이 아니라 '도서관'이다(id 6a6c060a) — 이번 지시
  범위("어린이도서관 중분류에 있는 데이터중")를 벗어나 반영하지 않았다.

## 특이 사항 — 후속 확인 필요
1. **지역 불일치 8건**은 CSV의 지역 표기가 틀렸을 수도, 또는 DB에 해당 실제
   장소가 아직 없을 수도 있다 — 사용자 확인 후 처리(추측 보류).
2. **미병합 중복 대표 행 4쌍**(8개 행)이 발견됐다 — 각 쌍이 같은 실제 장소를
   가리키는데도 dedup 그룹으로 안 묶여 있어, 지금 소비자 화면에 같은 도서관이
   두 번 보일 수 있다. 이번 지시 범위(뱃지 반영) 밖이라 손대지 않았지만, 별도
   중복 검수 작업이 필요하다.
3. **구로꿈나무도서관**은 현재 표준중분류가 '도서관'으로 분류돼 있다 —
   '어린이도서관'으로 재분류가 필요한지 확인이 필요하다.
