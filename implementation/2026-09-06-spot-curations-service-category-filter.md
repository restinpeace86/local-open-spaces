# 스팟 큐레이션 탭 — 노출중분류 있는것/없는것 따로 보기

## 구현 대상
사용자 지시: "스팟 큐레이션 탭에 노출중분류 된거랑 안된거 따로도 볼수 있게해줘
기본적으로 노출중분류가 분류된 식당에 대하여 스팟 큐레이션에서 메뉴작업할꺼라..
아닐수도 있고.. 하여튼 일단은 노출중분류 있는것만도 볼수있어야돼"

## 구현 일시
2026-09-06

## 변경 사항

### 백엔드 — 대칭 필터 추가
`src/app/api/admin/data-grid/route.ts`: 어제 추가한 `only_unmapped`(service_
category_id IS NULL)의 반대 방향인 `only_mapped`(service_category_id IS NOT
NULL)를 추가했다. `queryOpenSpaces`의 메인 쿼리 빌더 경로에만 적용했다(어제
`only_unmapped`를 추가할 때와 동일한 범위 — SEOUL_YEYAK 소스 전용 서브셋 경로는
이 필터를 쓰는 화면에서 호출되지 않는다).

### 프론트엔드 — 3단 필터 + 행별 뱃지
`src/components/admin/spot-curations-panel.tsx`:
- 검색창 아래에 "노출 중분류: 있음 / 없음 / 전체" 세그먼트 버튼 추가.
  **기본값은 "있음"** — 사용자가 밝힌 주된 작업 흐름("노출중분류가 분류된
  식당에 대하여 메뉴작업")에 맞춘 것이고, 언제든 다른 탭으로 바로 바꿔볼 수
  있다.
- 목록의 각 행에도 `service_category_id` 유무에 따라 "노출중분류 있음"(파란
  배지)/"노출중분류 없음"(주황 배지)을 바로 보여준다 — 필터로 걸러 보는 것과
  별개로 한눈에 확인 가능하게 했다.

  어제 다른 카테고리에서 겪은 인덱스 부재 문제와 달리 이 규모에서는 재현되지
  않아 별도 인덱스는 추가하지 않았다). 실제 API로 재확인: 전체 1824건 중
  only_mapped 5건 / only_unmapped 1777건으로 필터가 정상적으로 갈라 보여줌.

## 특이 사항
- "일단은 노출중분류 있는것만도 볼수있어야돼"라는 요청에 맞춰 최소 요구사항
  (있음 필터)은 확실히 충족했고, 사용자가 언급한 "따로도"(있음/없음 둘 다)에
  맞춰 전체/없음까지 3단으로 만들었다 — 어느 쪽이 주력이 될지 아직 확정되지
  않았다고 밝혀주셔서, 기본값만 "있음"으로 두고 나머지 옵션도 항상 즉시
  전환 가능하게 했다.
