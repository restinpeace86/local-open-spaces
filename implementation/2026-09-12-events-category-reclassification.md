## 조사 결과
- `events.category_maj`는 두 가지 서로 독립된 경로로 관리된다:
  1. **데이터(DB 컬럼)**: 어댑터가 채우거나(`buildEventRow`), 배치
     재분류 엔진(`scripts/ingest/lib/category-maj-taxonomy.mjs`의
     `applyCategoryMajTaxonomy`)이 `category_min_source`(RAW/RULE/MANUAL)별로
     다르게 재계산한다. **MANUAL은 절대 건드리지 않는다** — 이번 모든 수정에
     `category_min_source='MANUAL'`을 써서 향후 이 엔진이 다시 돌아도 되돌아가지
     않게 보호했다.
  2. **어드민 필터 UI 그룹핑(`src/lib/admin/category-min-groups.ts`)**: `/admin/
     data-grid` events 탭의 "표준 중분류" 체크박스를 대분류별로 접어서 보여주기
     위한 **완전히 별개의 정적(hardcoded) 매핑**이다. DB의 실제 `category_maj`
     컬럼 값을 전혀 읽지 않고, `category_min` 문자열이 어느 정적 그룹의 `minors`
     배열에 나열돼 있는지로만 어느 대분류 아래에 보여줄지 정한다 — 그래서 DB
     데이터를 아무리 고쳐도 이 화면의 그룹핑은 안 바뀐다(항목 5의 실측 확인 내용).
- "역사"/"전시실"/"공연장" 같은 category_min 값은 **소스에 따라 성격이 완전히
  다르다** — 예: "역사" 2,607건 중 2,506건(96%)은 문화행사 API의 실제 전시/유적
  탐방 콘텐츠고, 78건(교육강좌 소스)만 진짜 강좌다. "전시실"은 16건(공간시설
  대관)과 19건(실제 문화체험/전시)이 거의 반반, "공연장"은 45건(공간시설 대관)이
  4건(실제 공연)보다 훨씬 많다. 하나의 category_min 값을 통째로 다른 대분류로
  옮기면 성격이 다른 나머지가 잘못 딸려가므로, **원천 MAXCLASSNM(공간시설/체육시설/
  교육강좌 등)으로 정확히 조건을 좁혀서만** 데이터를 수정했다.

## 변경 사항

### 1. 데이터 재분류(직접 SQL, 프로덕션 즉시 적용— 코드 변경 아님)
모두 `source='seoul_public_reservation'`, 조건에 맞는 행만, `category_min_source='MANUAL'`로 보호:

| 조건(원천 MAXCLASSNM/MINCLASSNM) | 결과 | 건수 |
| --- | --- | --- |
| 공간시설 / 다목적실·회의실·주민공유공간·강의실 | category_maj='공공청사/행정' | 593건 |
| 공간시설 / 전시실 | category_maj='공공청사/행정' | 16건 |
| 교육강좌 / 역사 (category_min='역사'는 유지) | category_maj='배움 / 클래스' | 78건 |
| category_min in (수영장, 파크골프장) ∧ 체육시설 | category_maj='체육시설' | 5건 |
| 공간시설 / (나머지 전부: 강당·공연장·광장·녹화장소·민원 등 기타·청년공간) | category_maj='공공청사/행정' | 나머지분 |
| 공간시설 / 캠핑장 | category_maj='자연 / 캠핑' (예외 — 레저 시설이라 행정 시설 대관이 아님) | 99건 |
| 체육시설 / (전체 17개 중분류) | category_maj='체육시설' | 1,407건 |

최종 재확인: `공간시설`·`체육시설` 두 원천 대분류 범위 전체에서 `category_min ≠
원천 MINCLASSNM` 또는 `category_maj` 불일치 **0건**.

### 2. 어드민 필터 그룹핑 코드 수정 (실제 코드 변경, 검증 필요)
`src/lib/admin/category-min-groups.ts`의 `EVENTS_GROUPS_STATIC`: `'전시실'`을
`'문화/축제'` 그룹의 minors에서 제거하고 `'공공청사/행정'` 그룹의 minors로 이동.
`src/lib/admin/category-min-groups.test.ts`: 신규 테스트 — "전시실은 공공청사/행정
그룹에 배정되고 문화/축제 그룹에는 더 이상 없다".

**의도적으로 그대로 둔 것**: "역사"/"공연장"은 이 그룹핑 파일에서 옮기지 않았다 —
위 조사에서 확인했듯 두 값 모두 대다수가 여전히 "문화/축제" 성격이라(역사 96%,
공연장 91%), 그룹 자체를 옮기면 그 다수가 잘못된 그룹 아래 나열된다. 사용자가
이번에 명시적으로 지적한 "전시실"만 반영했다.

## 특이 사항
- `문화체험`/`교육강좌` 원천 대분류의 나머지(역사 제외) 항목들은 이번 범위에
  포함하지 않았다 — 사용자가 확인 질문을 남긴 상태(마지막 답변에서 "그쪽도
  훑어봐 드릴까요?" 제안, 아직 승인 대기).
- 이 두 재분류 메커니즘(DB 컬럼 vs 어드민 UI 정적 그룹핑)이 서로 완전히 독립적이라는
  사실 자체가 이번 조사에서 새로 드러난 구조적 특징이다 — 앞으로 category_maj를
  데이터로 고칠 때마다 "어드민 화면에 보이는 그룹이 실제로 반영되길 원하면"
  `category-min-groups.ts`도 함께 확인해야 한다(자동 동기화되지 않음).
