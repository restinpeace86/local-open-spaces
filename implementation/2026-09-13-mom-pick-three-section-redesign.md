## 변경 사항

### 1. 기존 구조
`mom-pick-view.tsx`는 지금까지 3개 섹션 모두 공용 `PreviewSection` +
`DashboardPostCard`를 그대로 재사용해왔다(헤더 텍스트/카드 모양이 3개 섹션
전부 동일). 카드를 누르면 `PostDetailModal`(개별 글 상세)이 열렸다.

### 2. 섹션별 전용 카드 3종 신규 작성
- `expert-pick-card.tsx` + `expert-pick-section.tsx`: 골드→퍼플 그라데이션
  원형 아바타(닉네임 첫 글자) + 닉네임/등급 + 스팟명 + 내용 1줄. 세로 목록
  유지(사용자 지시에 "스크롤" 언급 없음).
- `trending-pick-card.tsx` + `trending-pick-section.tsx`: 오렌지/레드 톤,
  썸네일(없으면 📷 플레이스홀더) + "🔥 HOT" 뱃지 + 요약 텍스트(최대 2줄) +
  좋아요 수. 이 섹션만 `overflow-x-auto` 가로 스크롤 컨테이너로 만들었다
  (지시 원문에 "가로 스크롤" 명시).
- `live-pick-card.tsx` + `live-pick-section.tsx`: 레드 계열 pulse 애니메이션
  라이브 점 + "LIVE" 뱃지 + 스팟명 + 작성자 · 상대 시간(초록색 강조). 세로
  목록 유지(스크롤 언급 없음).

3개 카드 모두 카드 전체가 `next/link`이며, 각각 `/mom-pick/expert`,
`/mom-pick/trending`, `/mom-pick/live`로 즉시 이동한다("터치 시 이동" 요구
반영) — 기존처럼 개별 글 상세 모달을 열지 않는다. 헤더는 "제목 + 전체보기 ›"
형식을 유지하되 텍스트/링크 색상을 섹션별 톤에 맞췄다.

### 3. `mom-pick-view.tsx` 교체
3개 `PreviewSection` 호출을 `ExpertPickSection`/`TrendingPickSection`/
`LivePickSection`으로 교체했다. 기존 게스트/미등업 유저용 "투명 인터셉트
오버레이"(2026-09-10/11 기획)는 그대로 살아있다 — 새 카드들도 결국 이
오버레이가 덮는 같은 `<div className="relative">` 안에 위치하므로, 로그인
전/새싹맘 미달 상태에서는 카드를 눌러도 여전히 안내 팝업이 먼저 뜬다(카드가
Link인지 button인지와 무관하게 절대 위치 오버레이가 클릭을 가로챈다).

기존 공용 `preview-section.tsx`는 더 이상 아무 곳에서도 쓰이지 않아
완전히 삭제했다(전용 테스트 파일이 없던 순수 레이아웃 컴포넌트).

### 4. [정직한 데이터 한계] — 임의로 새로 만들지 않은 것들
- **프로필 사진**: `profiles` 테이블에는 사진 컬럼이 없다(2026-09-02
  `create-profiles-table.sql` 실측 확인, 소셜 로그인 사진 저장/노출 기능도
  스펙에 없음). "프로필 사진이 큼직하게 들어간 원형 아바타"를 문자 그대로
  구현하려면 사진 업로드/저장 기능을 새로 설계해야 하는데, 이는 이번 지시의
  범위를 넘는 별도 기능이라 임의로 만들지 않았다(제3장 제5조 추측 금지, 제7장
  제1조 Spec 없는 기능 추가 금지). 대신 닉네임 첫 글자를 큼직한 원형 배지에
  넣어 "사람이 먼저 보이게" 의도는 유지했다.
- **조회수**: "조회수나 좋아요 수 표시"에서 조회수 컬럼 자체가
  `mom_pick_posts`에 없다(`getTrendingPosts` 주석에 이미 기록된 기존 제약 —
  찜 기능도 게시글엔 없다는 것과 같은 종류의 제약). 실존하는 좋아요 수만
  표시했다.
- **"진행 중인 이벤트"**: 실시간 라이브 섹션의 실제 데이터 소스
  `getLivePosts()`는 2026-09-02 기획 그대로 "단순 최신순 게시글 피드"다(실제
  이벤트 진행 상태를 추적하는 기능이 아니다). "진행 중"이라는 지시 문구에
  맞춰 없는 상태값을 새로 만드는 대신, 이미 있는 `created_at`으로 상대 시간
  (방금 전/N분 전/N시간 전/N일 전)을 계산해 보여줘 "지금 막 올라온 글"이라는
  현장감만 전달한다.

## 특이 사항
- "전체보기"(`/mom-pick/expert` 등) 페이지 자체(`full-list-view.tsx`)는 건드리지
  않았다 — 여전히 `DashboardPostCard`를 써서 카드를 누르면 개별 글 상세
  모달(`PostDetailModal`)이 열린다. 이번 변경은 "메인 화면 미리보기"에서
  "카드 누르면 상세로"가 아니라 "카드 누르면 전체보기로" 바뀐 것이며, 전체보기
  안에서의 상세 열람 동작은 그대로다.
- `dashboard-post-card.tsx`는 이제 메인 화면 미리보기에서는 쓰이지 않고
  "전체보기" 3개 페이지 전용이 됐지만, 파일/컴포넌트 자체는 계속 필요해
  삭제하지 않았다.
