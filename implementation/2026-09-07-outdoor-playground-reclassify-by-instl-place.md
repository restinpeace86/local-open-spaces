# 어린이놀이시설(야외) — raw_data.instlPlaceCdNm 기준 재분류

## 구현 대상
사용자 지시: "어린이놀이시설(야외) 중분류에서도 instlPlaceCdNm: 주택단지,
하기는 학교 중분류 새로 추가해서 학교 중분류로 instlPlaceCdNm: 학교,
하기는 어린이집 중분류로 instlPlaceCdNm: 어린이집, 하기는 유치원 중분류로
instlPlaceCdNm: 유치원" — [[2026-09-06-indoor-playground-reclassify-by-instl-
place]]의 실내(indoor) 케이스를 야외(outdoor)에도 동일하게 적용하는 후속
요청.

## 구현 일시
2026-09-07

## 확인 질문 — "주택단지"의 목적지
메시지에서 "주택단지"만 목적지 문장이 없이 값만 나열돼 있었다. 실내
케이스에서는 "주택단지"가 소수(285건)였지만, 실측해보니 야외 케이스에서는
**5,908건**(해당 중분류 전체의 상당 부분)으로 규모가 크게 달라 임의로
"기타"라고 판단하지 않고 사용자에게 직접 확인했다 — "기타로 이동" 응답을
받아 그대로 진행했다(제3장 제5조 추측 금지).

## 변경 사항
`scripts/migrations/2026-09-07-reclassify-outdoor-playground-by-instl-place.sql`
(적용 완료):
- `category_min='어린이놀이시설(야외)'` 대상 `raw_data->>'instlPlaceCdNm'`
  - `주택단지` → `기타` (확인 질문 답변 반영)
  - `학교` → `학교` (**신규 표준 중분류**, `category_rules`에 등록)
  - `어린이집` → `어린이집`
  - `유치원` → `유치원`
- 전부 이름 키워드가 아닌 raw_data 필드값 기준 관리자 판단이라
  `category_min_source='MANUAL'`.
- `'학교'`는 이 프로젝트에 아직 없던 새 표준 중분류라 `category_rules`에도
  `('open_spaces', '학교', '학교', false)`를 등록했다(어린이집/유치원/식당과
  동일한 관례 — 향후 신규 수집 데이터의 이름 키워드 기반 자동 분류 목적).
  `'기타'`/`'어린이집'`/`'유치원'`은 이미 존재하는 표준 중분류라 별도 등록
  불필요.
- `src/lib/admin/category-min-fallback.ts`의
  `OPEN_SPACES_CATEGORY_MIN_FALLBACK`에도 `'학교'`를 추가해 안전망 스냅샷을
  갱신했다.

## 검증(실측)
- 사전 확인: `어린이놀이시설(야외)` 대상 `instlPlaceCdNm`별 건수 — 주택단지
  5,908 / 어린이집 1,803 / 유치원 957 / 학교 642.
- 적용 후 재확인: `어린이놀이시설(야외)` → **163**건(라이브 배치 드리프트로
  사전 합계 대비 소폭 차이, 정상 범위), `기타` +5,908, `어린이집` 208 →
  **2,011**(+1,803, 정확히 일치), `유치원` 93 → **1,051**(+957~958, 드리프트
  범위 내), `학교` 0 → **642**(정확히 일치).
- 재확인 쿼리로 남은 `어린이놀이시설(야외)`의 `instlPlaceCdNm` 분포에서
  주택단지/학교/어린이집/유치원이 전부 사라졌음을 확인(다른 값 —
  아동복지시설/식품접객업소/주상복합/종교시설/학원/하천/대규모점포/
  의료기관/도로휴게시설/목욕장업소 — 은 이번 요청 범위 밖이라 그대로 유지).
