# 캘린더 상시 예약 슬롯 과밀 현상 개선

## 구현 대상
- 사용자 확정 규칙: 30일 이상 장기/상시 항목을 일별 타일에서 분리, 일별 타일 최대 3칩 + "+N개 더보기" 클릭 시 레이어로 전체 목록 표시

## 구현 일시
2026-08-21

## 변경 사항
- `src/lib/spaces/event-duration.ts` 신규: `getSpanDays`(기간 일수 계산), `isLongRunning`(30일 이상 판정), `splitByDuration`(단기/상시 분리)
- `src/components/calendar/calendar-view.tsx`:
  - 월별 조회 결과를 `splitByDuration`으로 분리 — 캘린더 그리드는 `shortTerm`만 사용
  - 상단에 "상시 운영/예약 (N건)" 접이식(Accordion) 섹션 추가, 펼치면 상태 뱃지 포함 목록 노출
  - 일별 타일 칩 상한을 2 → 3으로 변경, 초과분은 "+N개 더보기"로 표시
  - 날짜 클릭/"+N개 더보기" 클릭 시 기존 인라인 패널 대신 **모달 레이어**로 전환 (배경 클릭 또는 X로 닫기) — 사용자가 "레이어로 확인"이라고 명시했기 때문
  - 상태 뱃지가 포함된 목록 아이템을 `EventStatusListItem`으로 추출해 상시 섹션과 날짜 레이어 양쪽에서 재사용

## 검증 결과
- `npx tsc --noEmit` / `npm run test` / `npm run build`: 모두 통과
- Playwright 실브라우저 검증 (`/calendar`, 2026년 8월 기준):
  - "상시 운영/예약 (704건)" 섹션이 정확히 분리됨 — 이전에 매일 반복 노출되던 연중 예약 슬롯들이 여기로 이동
  - 접이식 섹션 펼치기 시 704건 전체가 상태 뱃지("접수중" 등)와 함께 정상 렌더링
  - 42개 날짜 셀 전수 검사 결과 셀당 칩 개수 최대 3개로 제한됨 확인 (`maxChipsInAnyCell: 3`)
  - "+N개 더보기" 클릭 시 레이어(모달) 정상 노출 — "2026-07-28 행사 4건"에 상태 뱃지("오늘 마감", "접수중") 포함 정상 표시
  - 콘솔 에러 0건

## 특이 사항
- **개선 후에도 일부 날짜는 여전히 칩이 많음** (예: 8/20에 "+255개 더보기"). 이는 30일 이상 상시 항목을 제외한 뒤에도, 짧은 기간(30일 미만) 반복성 프로그램(예: 각기 다른 회차의 강좌 예약이 개별 행으로 저장된 경우)이 실제로 다수 겹치기 때문 — 요청받은 규칙(30일 기준 분리, 셀당 3개 제한, 레이어 접근)을 정확히 구현한 결과이며 추가 규칙(예: 반복 강좌 그룹핑, 카테고리별 추가 제외)은 요청받지 않아 임의로 추가하지 않음. 필요 시 다음 단계로 논의 가능
