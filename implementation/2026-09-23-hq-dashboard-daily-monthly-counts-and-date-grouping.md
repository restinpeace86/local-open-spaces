# HQ 대시보드 오늘/이번달/전체 건수 표시 + 상세 화면 일자별 접기/펼치기

## 구현 대상
사용자 지시(2026-09-23): "/hq쪽에서 농장업체들 몇건 예약 들어왔는지 리스트로
보여주던것에 대하여 이게 일별 / 월별 / 전체로 몇건들어왔는지를 알 수 있게
해줘 그리고 상세로 들어갔을때 A농장이면 A농장만 쫙 나오는데. 이것도 일별로해서
최신일자 기준으로 sorting해줘 최신일자가 맨위로 올수 있게.. 그리고 이거
일자별로 영역나눠서 일자별 접기 펼치기 할수있게해줘. 예를들어 9/23에 9건,
9/22에 3건 예약 들어왔으면 9/23이 제일 위에 오고 펼쳐져있어서 9건 보이고
9/22 3건은 3건 같은섹션에 묶이고 이거는 접기 되어있고."

## 1) 대시보드 요약 목록 — 오늘/이번달/전체 건수
`src/app/hq/page.tsx`: 파트너별 예약 건수를 "전체 N건" 하나만 보여주던 것을
"오늘 N건 · 이번달 N건 · 전체 N건" 세 가지로 확장했다. "일별"을 날짜별로 전부
나열하는 것으로 해석하지 않았다 — 그건 상세 화면(2번 항목)의 일자별 섹션이
이미 담당하고, 요약 목록에서 더 세분화하면 "요약"이라는 목적과 어긋난다고
판단해 "오늘 하루치 대표 숫자"로 좁혔다.
- `todayKstDateString()`(기존 유틸, `@/lib/partner/date` 재수출) 재사용.
- `booking_date`가 "YYYY-MM-DD" 문자열이라 날짜 연산 없이 정확히 일치(오늘)/
  월 접두어 일치(이번달)만으로 판정 — 기존 "집계는 JS에서" 관례(monthly/page.tsx)
  그대로 따름.
- 이전에는 `bookings`에서 `partner_id`만 select했는데, `booking_date`도 함께
  select하도록 확장(집계에 필요).

## 2) 상세 화면 — 일자별 접기/펼치기 섹션
`src/app/hq/partners/[id]/page.tsx`: 파트너 한 명의 예약을 하나의 평평한
표로 보여주던 것을, 날짜별로 묶은 접기/펼치기 섹션으로 재구성했다.
- 정렬 자체는 원래부터 `order('booking_date', {ascending: false})`로 최신
  날짜가 위에 오게 돼 있었다(버그 아님) — 이번에 바뀐 건 "날짜별로 시각적으로
  나뉘어 보이는지"이지 정렬 순서 자체가 아니다.
- 신규 `src/lib/hq/group-bookings-by-date.ts` (`groupBookingsByDate`): 이미
  정렬된 배열을 날짜 경계에서만 잘라 그룹으로 묶는 순수 함수(재정렬하지
  않음 — 같은 작업을 두 번 하지 않기 위해 호출부의 정렬을 전제로 한다는 점을
  주석/테스트로 명시).
- 접기/펼치기는 별도 클라이언트 상태 없이 네이티브 `<details>`/`<summary>`로
  구현 — 첫 번째(가장 최신 날짜) 그룹만 `open`, 나머지는 기본 접힘. 브라우저
  기본 동작이라 이 페이지를 클라이언트 컴포넌트로 바꿀 필요가 없었다(제5장
  제4조 — 접기/펼치기 때문에 굳이 상태 관리를 추가하지 않음).
- 각 날짜 섹션 헤더는 `formatMonthDayWithWeekday`(기존 유틸, 주간 뷰가 이미
  씀)로 "9/23 (화)" 형식 + 그 날짜의 건수를 표시.
- `HqBookingRow`(개별 행 컴포넌트)는 그대로 재사용 — 삭제 버튼 등 기존 동작
  변경 없음.

## 검증
- `npx tsc --noEmit` / `npm run test`(200개 파일 2,299개, 신규
  `group-bookings-by-date.test.ts` 4개 포함) / `npm run build` 모두 통과.
  빌드 라우트 출력에서 `/hq`, `/hq/partners/[id]` 둘 다 `ƒ`(Dynamic) 유지 확인.

## 특이 사항
- `groupBookingsByDate`는 입력이 이미 `booking_date` 기준 정렬돼 있다는
  전제로 설계했다(재정렬하지 않음) — 호출부가 정렬을 보장하지 않고 이 함수를
  재사용하면 같은 날짜가 여러 그룹으로 쪼개질 수 있다는 점을 함수 주석과
  테스트 케이스로 명시해뒀다.
