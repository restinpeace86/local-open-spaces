# 롯데마트 문화센터 강좌 상세정보(강좌코드/강의실/소개/Tip) 1회성 수집

## 구현 대상
사용자 지시(2026-10-04): "상세정보 롯데마트 문화센터는 클래스 상세정보같은거
왜 안나와? 관리자화면에서.. 강좌코드나 강의실이나 강좌소개나 강좌수강
Tip이랄던가 상세들어가면 다 있던데.." — 이전 구현(2026-10-04, UI 빌드)에서
"상세 페이지를 별도로 긁어야 한다 ... 이번 범위에는 포함하지 않았다"고
명시적으로 미뤄뒀던 부분을 이번에 실제로 구현했다.

## 실측 확인
`courseview.do`(상세 페이지)의 `<div id="lctInfo"><table class="view-table">`
(caption: "강좌정보 표 - 강좌코드, 강의실, 강좌소개, 강좌 수강 Tip")에 정확히
4개 필드가 있다 — 2개 class_id로 직접 확인해 구조가 일관됨을 검증:
- 강좌코드/강의실: 한 `<tr>` 안에 th/td 2쌍이 나란히(`24010`/`본관 6층
  신비한방`).
- 강좌소개/강좌 수강 Tip: 각각 별도 `<tr>`, `colspan="3"`, 내용이 `<br/>`로
  줄바꿈된 자유 텍스트(수강 Tip에는 장점/포인트/주차안내/취소환불기준이
  한 필드에 섞여 있음 — 원문 그대로 보존, 임의로 쪼개지 않음).

- `scripts/migrations/2026-10-04-lottemart-culture-club-detail-columns.sql`

  `<br/>` 줄바꿈 보존을 위해 플레이스홀더 치환 → 전체 공백 정규화 →
  플레이스홀더 기준 재분리 방식을 쓴다(원본 HTML의 들여쓰기가 텍스트에

  건수가 많아 더 걸림) — 이후론 그날 신규 강좌만 대상이라 빨라진다.

  강좌 수강 Tip(전체 폭 섹션, 줄바꿈 보존) 추가. 아직 상세정보 미수집
  행에는 이마트와 동일한 안내 문구 표시.
- `scripts/ingest/lottemart-culture-club-detail.test.mjs`(신규): 실측
  표본 HTML 기반 4개 테스트(강좌코드/강의실 추출, 소개/Tip 줄바꿈 보존,
  표 없을 때 전부 null).

## 검증
- `npx tsc --noEmit` / `npm run test`(268개 파일 2,795개, 신규 4개 포함) /
  `npm run build` 전부 통과.
- **실제 라이브 백필 실행**(dry-run 아님) — 시작 직후 13건 완료 확인, DB에서
  실제 강좌코드/강의실/소개 내용 직접 조회로 재확인, 관리자 화면에서
  양평점 지점 필터 적용 후 실제 강좌 상세 모달에 강좌코드(37230)/강의실
  (문화센터 로비)/강좌소개/강좌 수강 Tip(체크박스 이모지 포함 원문 그대로)
  전부 정상 렌더링되는 것을 브라우저로 직접 확인. 전체 백필은 세션 종료
  후에도 프로덕션 cron이 계속 이어서 완료한다(증분 수집이라 안전).
