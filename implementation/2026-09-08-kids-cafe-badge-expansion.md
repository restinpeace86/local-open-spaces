# 키즈카페 큐레이션 뱃지 확장 (미끄럼틀/체험존/카페테리아 키워드/공공·민간/연령대)

## 구현 대상
사용자 지시: "키즈카페 큐레이션쪽에 뱃지에 미끄럼틀 추가해. 그리고 체험존
같은것도 하나.. 드로잉존이나 뭔가 프로그램 선택가능한거? 그런게 있네
레인보우스타는 물감과 미술, 오감놀이를 진행하는 드로잉존과 시설을 즐기는
키즈존이 나뉘어져 있어요. 카페테리아는 키워드로해서 부모 쉼터라던가의
키워드로 넣고.. 아니면 식음료존? 원래 키즈카페가 음료팔기는 하는데...
그리고 공공인지 민간인지 뱃지도 만들어줘... 그리고 연령대... 보통 서울형
공공 키즈카페는 영유아 만36개월까지 가는게 좋더라.. infant인지
미취학아동인지 취학아동인지 체크할수있는거 정도? 이런 뱃지만들어주던가...
이건 복수선택가능하게 영유아가 36개월 미취학이 7살이하 취학이 초등학생
맞겠지?"

  "큐레이션쪽 뱃지"로 명시돼 있어 새 DB 컬럼을 만들지 않고 기존 블로그
  키워드 매칭 뱃지 방식(`curation_badges`)에 포함시켰다.

## 변경 사항 (`src/lib/admin/curation-badges.ts`, `KIDS_CAFE_CONFIG`만 수정)
7개 뱃지 신규 추가, 기존 뱃지 1개는 키워드만 조정:
- `kc_slide`(미끄럼틀, 놀이/시설): 기존엔 `kc_ball_pool_jungle`(볼풀장/
  정글짐) 키워드 목록에 '미끄럼틀'이 섞여 있어 미끄럼틀만 따로 체크할 수
  없었다. 전용 뱃지로 분리하고 키워드('미끄럼틀', '슬라이드')를 이동했다.
- `kc_experience_zone`(체험존/프로그램존(미술·오감놀이 등), 놀이/시설):
  사용자가 예로 든 "레인보우스타"(드로잉존 vs 키즈존 분리 운영) 사례를
  반영. 키워드: 체험존/드로잉존/프로그램존/미술놀이/오감놀이/창의미술/
  아트존.
- `kc_food`(식사 및 간식 판매, 기존 뱃지) 키워드에 '카페테리아' 추가 —
  사용자가 직접 "원래 키즈카페가 음료팔기는 하는데"라고 판단한 대로, 신규
  뱃지가 아니라 이미 있는 식음료 뱃지의 키워드 확장으로 처리했다.
- `kc_public_operated`(공공 운영)/`kc_private_operated`(민간 운영): 새
  그룹 "공공/민간"으로 분리(기존 "운영" 그룹은 예약 관련이라 헷갈리지
  않도록 그룹명을 다르게 뒀다). 키워드: 공공운영/국공립/시립/구립/공립,
  민간운영/사설/프랜차이즈.
- `kc_age_infant`(영유아(0~36개월))/`kc_age_preschool`(미취학(7세
  이하))/`kc_age_school`(취학(초등학생)): 새 그룹 "연령대". 사용자가 확인한
  경계값 그대로(영유아=만 3세/36개월 이하, 미취학=7세 이하, 취학=초등학생)
  라벨을 붙였다. 세 뱃지 모두 다른 뱃지들과 동일하게 체크박스라 동시에
  여러 개 선택 가능(복수 선택 요구사항 충족).

`badgeGroups`도 `['이동/편의', '놀이/시설', '부대시설/보호자', '운영']`
(4개)에서 `['이동/편의', '놀이/시설', '부대시설/보호자', '운영', '공공/민간',
'연령대']`(6개)로, `badgeOptions`는 13개 → 20개로 늘었다.
