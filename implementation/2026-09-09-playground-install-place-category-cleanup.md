## 사전 확인(사용자에게 직접 질문, 2회)
1. **"표준 중분류"/"대분류 '기타'"가 가리키는 체계**: `open_spaces.category_min`
   (내부 표준 분류) vs `service_categories`(노출 중분류, 지도에 바로 노출) 중
   어느 쪽인지 — service_categories 쪽으로 하면 82,376건이 즉시 공개 지도에
   노출되는 "공개 범위 변경"이 되므로 반드시 확인이 필요했다. → **category_min
   확정**(기존 `localdata-playground-install-place-mapping.mjs`가 이미 이
   방식으로 8개 코드를 처리 중이었음).
2. **"이미 수작업/큐레이션을 거쳐서 고정된 데이터" 보호 범위**: 실측 결과 A010
   (주택단지, 45,875건)의 대부분(39,230건)이 이미 `category_min='어린이놀이터'`
   (RULE 자동분류)로 의미 있게 분류돼 있었다 — 코드 하나로 통일하면 이 좋은
   분류를 파괴할 위험이 있어 확인했다. → **대표 확인: "놀이방식당으로 중분류
   된 것만 건들지 않으면 됨"** — RULE 자동분류값(어린이놀이터 등)은 보호
   대상이 아니라는 것을 명시적으로 확인받았다.

## 변경 사항
### `scripts/ingest/lib/localdata-playground-install-place-mapping.mjs`
- `INSTALL_PLACE_CODE_TO_CATEGORY_MIN`을 기존 8개 코드에서 **22개 코드
  전체**로 확장했다: A001(목욕장업소)/A002(도로휴게시설)/A004(식품접객업소)/
  A005(아동복지시설)/A006(어린이집)/A007(유치원)/A008(대규모점포)/
  A009(의료기관)/A010(주택단지)/A011(학교)/A012(학원)/A020(주상복합)/
  A023(종교시설)/A031(하천) 14개를 신규 추가(기존 A003/A013/A022/A030/A032/
  A033/A092/A093은 유지).
- 신규 `PRESERVED_CATEGORY_MIN = new Set(['놀이방식당'])` — `classifyRows`가
  이 값을 가진 행은 어떤 설치장소코드든 무조건 건드리지 않는다(대표 확인
  원문 그대로 반영).
- 이 파일은 `playground-adapter.mjs`(신규 수집)와 `run-monthly.mjs`의
  `PLAYGROUND_INSTALL_PLACE_MAPPING` 배치 스텝(기존 행 백필)이 공유하므로,
  이번 확장이 향후 신규 수집분에도 자동으로 계속 적용된다(제5장 제4조).

## 실행(일회성 마이그레이션 실제 적용)
`applyPlaygroundInstallPlaceCategoryMapping()`을 프로덕션 DB에 직접 1회
실행했다(임시 스크립트로 호출, 실행 후 삭제 — `run-monthly.mjs`의 정기
실행을 다음 달까지 기다리지 않고 "일회성" 요구사항대로 즉시 반영).
- 적용 전 영향받는 전체 행(82,376건 스캔 대상 중 놀이방식당 제외분)의

  place-category-min-backfill.json`에 백업했다(기존 `dedupeOpenSpaces`와
  동일한 안전장치 관례).
- 1차 실행 중 A010(주택단지, 45,875건) 배치 처리 도중 `statement timeout`
  발생(33,000/45,875건 반영된 상태로 중단) — `classifyRows`가 이미 목표
  값과 같은 행은 건너뛰도록 설계돼 있어(멱등) 그대로 재실행해 나머지를
  안전하게 마무리했다.
- 총 26,629건 갱신(1차 실행분 포함 시 A010만 45,875건 전량 반영).

## 검증
- 실측(적용 후 전수 확인): 22개 코드 전부 `distinct_category_min_count`가
  1(코드 하나=값 하나로 완전히 통일) 또는 2(그 코드 안에 놀이방식당 예외가
  1건 섞여 있는 경우, A004/A005/A013에서 확인) — 모든 행이 "코드에 맞는
  표준값" 또는 "놀이방식당 보호" 둘 중 하나로 100% 설명됨을 확인했다.
- `localdata-playground-install-place-mapping.test.mjs`: 신규 2개(놀이방식당
  보호, RULE 자동분류값은 보호 대상 아님을 명시적으로 검증) + 기존 테스트를
  22개 코드 기준으로 갱신.
- `playground-adapter.test.mjs`: `it.each` 매핑 표를 8개→22개로 확장,
  "매핑 대상 아님" 케이스는 실존하지 않는 코드(A999)로 교체.
- `npx tsc --noEmit` / `npm run test`(1378건, 기존 1362 + 신규 16) /
  `npm run build` 전체 통과.
