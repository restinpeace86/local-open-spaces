# 중복 스팟 스캔 — 건물형 시설 좌표 근접 임계값 확대

## 구현 대상
사용자 지시(2026-09-29): "일단 30m에서 건물형 시설은 좀 넓힐까? 어차피
중복에 대하여체크는 내가 직접하잖아."

## 배경
직전 대화에서 확인한 원인: 어린이도서관 미병합 4쌍은 같은 실제 건물인데도
원본 소스별 지오코딩 오차가 30m(기존 `PROXIMITY_THRESHOLD_METERS`)를
넘어(실측 Haversine 거리: 노원 36.3m, 국립 55.3m, 아리랑 118.2m, 지혜샘
136.8m) 자동 중복 스캔에 후보로도 안 떴다. 이 판정 결과는 관리자가 매번
직접 확인 후 저장하는 "후보 제안"일 뿐 자동 병합이 아니므로(사용자 표현:
"어차피 체크는 내가 직접 하잖아"), 임계값을 넓혀 후보가 늘어나도 최종
데이터가 잘못 합쳐질 위험은 없다.

## 변경 사항
### `src/lib/admin/spot-dedup-grouping.ts`
- `BUILDING_TYPE_PROXIMITY_THRESHOLD_METERS = 150`(실측 최대값 136.8m에
  여유를 더한 값) 신설.
- 건물형 판정 대상은 `category-min-groups.ts`의 '문화시설' 대분류 minors
  (공연장/전시실/도서관/어린이도서관/문화원/문화의집/미술관/역사박물관/
  종합·기타박물관/과학관/시민교육센터)를 그대로 재사용 — 새 목록을 따로
  만들지 않았다(제5장 제4조 기존 구조 우선).
- `getProximityThresholdMeters(categoryMin)`: 건물형이면 150m, 아니면 기존
  30m를 반환.
- 좌표 근접 비교 루프에서 두 후보 중 하나라도 건물형이면(미매핑 스캔처럼
  두 후보의 category_min이 다를 수 있는 경우까지 대비해 `Math.max`로 더
  넓은 쪽을 적용) 150m 임계값을 쓴다. 야외 시설(공원/놀이터/캠핑장 등)은
  그대로 30m.

### `src/lib/admin/spot-dedup-grouping.test.ts`
- 실측 노원어린이도서관 좌표(36.3m)가 건물형(어린이도서관)이면 묶이는지 검증(1).
- 150m를 초과하면 건물형이어도 안 묶이는지 검증(1).
- 동일한 36.3m 거리라도 건물형이 아니면(공원) 여전히 30m 기준으로 안
  묶이는지 검증(회귀 방지, 1).

## 검증
- `npx vitest run src/lib/admin/spot-dedup-grouping.test.ts` — 15개 통과(기존 12개 + 신규 3개).
- `npx tsc --noEmit` / `npm run test`(전체 218개 파일 2,490개) / `npm run build` 모두 통과.

## 특이 사항
- 이미 병합해둔 4쌍(2026-09-29-merge-children-library-duplicate-pairs.mjs)에는
  영향 없음 — 이 변경은 향후 스캔에서 유사 사례가 후보로 뜨게 하는 것이 목적.
- 150m는 이번에 실측한 최대 사례(136.8m) 기준으로 정한 값이라, 더 큰 건물
  복합단지(예: 대형 문화센터) 사례가 추가로 나오면 재조정이 필요할 수 있다.
