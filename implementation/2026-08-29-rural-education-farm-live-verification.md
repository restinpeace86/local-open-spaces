# [농촌교육농장(RURAL_EDUCATION_FARM) 라이브 검증 및 DB 적재 완료]

## 배경
직전 작업(`implementation/2026-08-29-rural-village-and-education-farm-adapters.md`)에서
농사로(api.nongsaro.go.kr) 자체 인증키가 없어 소스 B(농촌교육농장) 어댑터는 코드만
완성하고 라이브 검증을 보류했었다. 사용자가 실제 인증키(NONGSARO_API_KEY)를 발급받아
`.env.local`에 채워 넣고 검증을 요청했다.

## 구현 일시
2026-08-29

## 검증 및 후속 조치
1. `.env.local`에 `NONGSARO_API_KEY`가 실제로 설정됐는지 확인.
2. 실제 엔드포인트를 직접 호출해 응답을 확인 — `resultCode: '00'`(정상), 총 253건,
   응답 구조가 어댑터 구현 시 참고 샘플 코드(`fmlgEdcFarmmList.php`)를 근거로 추정했던
   구조(`items` 안에 `item[]`/`numOfRows`/`totalCount`/`pageNo`가 함께 옴)와 정확히
   일치함을 확인했다 — 코드 수정 없이 그대로 동작.
3. `node scripts/ingest/rural-education-farm.mjs --dry-run`으로 어댑터 전체 파이프라인
   (페이지네이션 26페이지, XML 파싱, 전량 지오코딩) 검증 — 253건 수신, 250건 유효 변환.
4. 실제 DB 적재: `node scripts/ingest/rural-education-farm.mjs` 실행 → RAW 레이어 253건
   보존 + open_spaces 250건 upsert.
5. DB 직접 조회로 데이터 무결성 확인: 250건 전량 좌표/category_min('교육농장') 보유,
   202건 sigungu_name 자동 추출 성공. 무작위 표본(제주/순천/인천/파주/청주)으로 전국
   분포 및 한글 인코딩 손상 없음 확인.
6. 검증 완료에 따라 후속 연결 작업 수행:
   - `run-monthly.mjs`의 STEPS에 `RURAL_EDUCATION_FARM` 연결(자동 월간 배치 편입).
   - 어드민 카테고리 그룹핑("농장/체험")과 필터 안전망 목록에 `'교육농장'` 추가.
   - 어댑터 파일 상단의 "⚠️ 라이브 검증 안 됨" 주석을 실제 검증 결과로 갱신.

## 데이터 품질 특이사항(실측 확인, 원본 데이터 자체의 특성)
- 지오코딩 실패 3건(253건 중): "와부음"(정확히는 "와부읍" 오탈자), "전남광주통합특별시"
  ×2(실재하지 않는 행정구역명 — 전라남도/광주광역시 표기 오류로 추정) — 전부 원본
  `locplc` 값 자체의 오류이며, 어댑터는 설계대로 안전하게 skip했다(임의로 주소를
  고쳐 짐작하지 않음).
- sigungu_name 결측 48건(250건 중): 원본 주소가 시/도 접두어 없이 시/군/구부터
  시작하는 경우가 잦다(예: "함양군 안의면...", "제주시 조천읍..."). 공용
  `extractSigunguName()`은 `{시/도} {시/군/구} ...` 형태를 전제하므로 이런 표기에서는
  시/군/구를 식별하지 못해 null로 남는다 — 이는 기존에 정의된 안전한 동작(임의 추정 금지)
  이며 이번 어댑터만의 문제가 아니다. 필요하면 향후 별도 작업으로 "시/도 없는 주소" 보정
  로직을 검토할 수 있으나, 이번 작업 범위를 벗어나 진행하지 않았다.

## 검증

### 코드 검증
- `npx tsc --noEmit` 통과.
- `npm run test`(62파일 640건, `category-min-groups.test.ts`의 교육농장 그룹 테스트
  갱신 포함) 통과.
- `npm run build` 통과.

### 실측 검증(로컬 실행, 프로덕션 DB, 실제 인증키)
- `--dry-run` 및 실제 실행 모두 확인, DB 직접 조회로 250건 데이터 무결성 확인
  (위 "검증 및 후속 조치" 4~5번 참고).

## 특이 사항
- 홈페이지 링크(info_url)는 여전히 null이다 — 상세조회(`fmlgEdcFarmmDtl`)는 건별 개별
  호출이 필요해 이번 라이브 검증 범위에는 포함하지 않았다. 필요하면 별도 후속 작업으로
  진행할 수 있다(250건 기준 250회 추가 호출이 필요해 별도로 요청 제한/응답 시간을
  확인하며 진행하는 것이 안전하다).
