사용자 피드백 3건:
1. "[8회] 10/4~11/22 일요 트니트니 C [15~24개월/11:50] 제목 그대로 두는게
   낫겠지? 괜히 파싱했다 잘못될 수도 있으니" — 질문에 대한 확인.
2. "위치쪽에 스타필드시티위례.. 링크걸어놔서 누르면 위치 뜨도록해줘. 지도
   인앱? 팝업으로?"
3. "전체적으로 회색 글씨라던가.. 검은색은 좀 칙칙한거 같아.. 밝게 혹은
   파란색 계열로 눈에 띄면서도 안칙칙하게"

## 구현 일시
2026-10-07

## 1 — 제목 원문 유지 (확인, 코드 변경 없음)
`item.class_title`은 카드/상세 모두 가공 없이 그대로 보여주고 있다
(`culture-club-tab-view.tsx`에서 `{item.class_title}` 그대로 렌더). 연령/
회차/시간 등은 전용 컬럼으로 "별도로" 파싱해 보여주고 있을 뿐, 제목 문자열
자체를 재구성하거나 치환하지는 않는다 — 사용자 판단대로 그대로 두는 게
맞다(파싱 실패 시 원문이라는 안전망이 항상 남아있는 구조).

## 2 — 위치 클릭 → 인앱 지도 팝업
기존에 스팟/이벤트 상세에서 이미 쓰고 있던 `MapPreviewModal`(인앱 지도 +
"🧭 현재 위치에서 길찾기" 기능 포함, Kakao Map 기반)을 그대로 재사용했다
(제5장 제4조 — 새로 만들지 않음). "위치" 줄(지점명 · 거리)을 누르면 이
모달이 열린다.

- `/api/culture-club/search`가 Branch-First 과정에서 이미 들고 있던 지점
  좌표를 응답에 `store_lat`/`store_lng`로 추가(기존 `distance_meters`와
  같은 맵에서 함께 내려줌 — 추가 조회 없음).
- `culture-club-tab-view.tsx`에 `LocationLink` 컴포넌트를 추가 — 좌표가
  있으면 클릭 가능한 버튼(파란 텍스트)으로, 없으면 평범한 텍스트로 보인다
  (추측으로 좌표를 지어내지 않음). 카드의 "위치" 줄과 상세 시트의
  "접수가능지점" 줄 둘 다 적용했다. 카드에서 클릭 시 이벤트 버블링을 막아
  상세 시트까지 같이 열리지 않게 했다.

## 3 — 색상 톤 개선
- 활성 pill(브랜드/반경/요일/지점/조회 버튼)의 `bg-gray-900`(검은색)을
  `bg-sky-600`(파란색)으로 전환 — 가장 큰 면적을 차지하던 "칙칙한" 요소.
- "수업"/"접수"/"위치"/"👶 기준"/"반경" 라벨을 `text-gray-400`에서
  `text-sky-600`(굵게)으로 — 파란 포인트 컬러로 통일.
- 제목/가격 텍스트를 `text-gray-900`에서 `text-slate-900`으로(미묘하게
  차가운 톤), 본문 보조 텍스트를 `text-gray-500`에서 `text-slate-600`으로
  살짝 밝게.
- 상세 시트 상단의 카테고리/연령 표시도 카드와 동일하게 흐린 텍스트에서
  뱃지(pill)로 통일.
