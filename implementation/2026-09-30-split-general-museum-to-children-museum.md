# 종합/기타박물관 → 어린이박물관 추가 이관 + 노출중분류 매핑

## 구현 대상
사용자 지시(2026-09-30): "'종합/기타박물관' 표준중분류의 데이터들에 대하여
하기파일의 데이터들을 '어린이박물관'으로 이관시켜줘(97건). 그리고
노출중분류는 '어린이 박물관'으로 매핑시켜주고. 박물관1.csv" — 이미 신규
생성된 '어린이박물관' 표준중분류(2026-09-30 역사박물관 분리 건)에, 이번엔
'종합/기타박물관' 쪽에서도 추가로 이관한다.

## 실측 확인
1. `박물관1.csv`(CP949 인코딩, UTF-8 변환 후 확인, 97개 행)를
   category_min='종합/기타박물관' 대표 행 1,388건(페이지네이션으로 전량
   조회)과 이름+주소로 대조했다.
2. **63개는 단일 후보로 명확히 매칭**됐다.
3. **33개는 같은 주소를 공유하는 후보가 여러 개**였는데, 이번엔 전부
   "미병합 중복"으로 단정하지 않고 두 경우를 구분해서 판단했다(제3장 제5조
   추측 금지):
   - **진짜 중복**(이름이 공백/로마자 표기/지역 접두사 차이만 있음): 두
     후보 모두 이관 대상에 포함(예: "양평곤충박물관" 완전 동일 2건, "피규어
     뮤지엄W"/"피규어뮤지엄더블유", "괴산 한지체험박물관"/"한지체험박물관").
   - **의미 있게 다른 별개의 하위 시설/기관**: CSV가 실제로 적어낸 이름과
     정확히 일치하는 후보만 포함하고 나머지는 제외했다. 구체적으로:
     - "부산과학관 어린이놀이터-3"만 CSV에 있고 같은 주소의 "-2"는 CSV에
       없었다(-1은 이미 별도 행으로 CSV에 있었음) — 사용자가 의도적으로
       고른 선택을 그대로 존중해 "-3"만 포함, "-2" 제외.
     - "경기도어린이박물관"과 "경기도박물관"은 같은 부지의 서로 다른 실제
       기관(용인 상갈동에 실제로 두 박물관이 나란히 있음) — 어린이박물관만
       포함.
     - "OO어린이놀이시설 야외놀이터"/"실내놀이터", "국립등대박물관"/"국립
       등대박물관 실내놀이터", "고인돌 박물관 어린이놀이터"/"고인돌박물관"
       처럼 본관과 부속 놀이시설이 별도 행으로 존재하는 경우, CSV가 명시한
       쪽만 포함.
     - "공룡화석지 어린이놀이시설4" 주소에는 후보가 7개나 있었다(해남공룡
       박물관, 공룡박물관 어린이놀이시설, 공룡화석지 어린이놀이시설1/2/3,
       공룡사파리랜드 어린이놀이시설) — 큰 공룡박물관 단지 안의 서로 다른
       개별 놀이시설들이라, CSV가 명시한 "4"만 포함.
4. 최종 고유 ID 기준 **총 123건**(안전 매칭 63건 + 검토 후 포함한 중복
   후보 60건).
5. 노출중분류는 2026-09-30 역사박물관 분리 때 확인한 **'어린이 박물관'**
   (bc3b83df-b478-4620-9495-6499870bebdc)을 그대로 재사용 — 표준중분류
   출처(역사박물관이든 종합/기타박물관이든)와 무관하게 소비자에게는 같은
   "어린이 박물관"으로 모인다.
