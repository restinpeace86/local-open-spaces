# get-home-feed.test.ts 날짜 하드코딩으로 인한 테스트 실패 수정

## 발견 경위
2026-09-30에 진행한 박물관 표준중분류 이관 작업(무관한 변경)의 검증 루프
(`npm run test`) 중, 이번 작업과 전혀 관련 없는 기존 테스트
`getTodayEvents: 당일 한정(end_date=오늘) 조건 강화 (Task 9-6-9) > end_date가
오늘이 아니면(몇 주짜리 장기 행사 등) 제외한다`가 실패했다.

## 원인
테스트 픽스처가 "오늘이 아닌 미래의 어느 날"을 표현하려고 `end_date:
'2026-09-30'`을 하드코딩해뒀는데, 실제 실행 시점(오늘)이 정확히 2026-09-30이
되면서 "장기 전시"(원래 의도는 제외 대상)가 "오늘 마감"으로 잘못 인식돼
결과에 포함됐다. 같은 파일에 이미 이런 문제를 피하기 위한
`daysFromToday(offsetDays)` 헬퍼(실행 시점 기준 상대 날짜 생성)가 있었는데,
이 테스트만 그걸 안 쓰고 절대 날짜 문자열을 썼던 게 원인이다.

## 변경 사항
### `src/lib/home/get-home-feed.test.ts`
`longRunning` 픽스처의 `start_date`/`end_date`를 하드코딩 문자열 대신
`daysFromToday(-30)`/`daysFromToday(30)`로 교체 — 실행 시점과 무관하게
항상 "오늘이 아닌" 날짜가 되도록 고쳤다.

## 특이 사항
이번 세션의 실제 작업(박물관 표준중분류 이관)과는 무관하지만, 검증 루프
도중 발견돼 harness 규칙(오류 발생 시 수정 후 재검증)에 따라 함께
고쳤다. 같은 파일에 다른 절대 날짜 하드코딩이 더 있는지는 확인하지
않았다(이번에 실제로 실패한 것만 수정, 추측성 선제 수정은 하지 않음).
