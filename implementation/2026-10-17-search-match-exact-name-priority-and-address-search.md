# 네이버 플레이스 매칭 — 이름 유일성 우선 + 주소검색 재시도 + 지번 보정 (유아숲체험원)

## 구현 대상
사용자 지시(2026-10-17): "정확히 같은 이름인데 지번이 다르면 지번을
네이버껄로 바꿔. 그리고 배봉산근린공원 유아숲체험원 이런식으로 검색안될때
배봉산 유아숲체험원 이렇게도 검색해서 나오나 보고.. 그래도 안나오면
우리쪽 주소로 검색해서 유아숲체험원이 나오는지 확인하고... 지번하고
주소 둘이 매핑해서 교차로 보는건 이름 검색시 여러개 나오는경우.. 이경우
다건에 대하여 우리주소 교차로 봐서 가장 적합한거."

실제 계기: 사용자가 "배봉산근린공원 유아숲체험원 이거는 쳤을때 나오는데?"

## 변경 사항 (전부 `search-and-match.mjs` / `address-match.mjs`)

### 1. 동일 지번 블록 내 서브 지번 허용 (`address-match.mjs`)
공원/산림 시설은 같은 부지가 여러 인접 지번("산6-80"/"산6-91" 등, 하이픈
앞 메인 지번은 같음)에 걸쳐 등재되는 경우가 흔하다. 동(洞)과 메인 지번
(하이픈 앞)까지 같으면 서브 지번만 달라도 매칭 가능한 점수(0.7)를 준다 —
동 자체가 다르면 여전히 낮은 점수(0.2)로 걸러낸다. 이 과정에서 "금호동3가"
처럼 동 이름 뒤 구역 숫자+"가"가 붙는 표기를 지번으로 잘못 캡처하던
부수적 버그도 같이 고쳤다.

### 2. 이름 유일성 우선 매칭 (`address-match.mjs`의 `pickBestCandidate`)
주소 교차검증은 "이름 검색 결과가 여러 개일 때 그중 하나를 고르는" 도구로
한정한다. 검색 결과 중 이름이 정확히 일치하는 후보가 **유일하면** 주소가
달라도(지번 표기 차이 등) 그 자체로 확정한다. 이름이 정확히 같은 후보가
**여러 개**(동명이인)면 그중 주소가 가장 잘 맞는 것을 고르고, 주소로도
못 가르면 매칭하지 않는다. 이름이 정확히 같은 게 하나도 없으면 기존처럼
이름+주소 둘 다 최소 기준(0.5)을 만족하는 것만 고른다.

### 3. 공원형 복합어 재시도 확장 (`search-and-match.mjs`)
"공원"만 떼던 걸 "도시자연공원"/"근린공원"/"생태공원"/"시민공원"까지
긴 복합어부터 순서대로 떼도록 확장 — "배봉산근린공원 유아숲체험원"을
"배봉산근린 유아숲체험원"(근린만 덜렁 남음)이 아니라 "배봉산 유아숲체험원"
으로 정확히 변형한다.

### 4. 주소 검색 최종 재시도 (`search-and-match.mjs`)
이름으로 전부 실패하면(원본/공원제거/LLM 보조 검색어) 주소 자체를 검색어로
써서, 그 주소에 등록된 업체 중 카테고리 키워드("유아숲체험")가 이름에
포함된 것을 찾는다. 주소 검색 결과는 전부 그 위치에 있다는 것 자체가
확인된 것이므로 이름/주소 유사도 재검증 없이 키워드 포함 여부만 보되,
키워드 포함 업체가 여러 개면(드묾) 근거 불충분으로 매칭하지 않는다.
`run({ addressSearchCategoryKeyword })`로 켜고 끌 수 있어(기본값 null,
비활성) 식당 등 이름이 다양한 카테고리에는 영향 없다.

### 5. 이름 정확 일치 시 지번 보정, 단 네이버 주소가 충분히 상세할 때만
이름이 정확히 같으면 우리 지번을 네이버 쪽 주소로 덮어쓴다("지번을
네이버껄로 바꿔"). **실측으로 발견한 회귀**: 네이버 주소가 "서울특별시
강북구"처럼 시/구까지만 있고 동/번지가 없는 경우("북서울꿈의숲
유아숲체험원") 그대로 덮어쓰면 오히려 기존 상세 주소가 사라진다 — 네이버
주소가 충분히 상세할 때만(관리자 접두어를 뗀 나머지가 10자 이상) 덮어쓰고,
아니면 우리 주소를 그대로 유지한다.

## 특이 사항
- 식당 매칭(`node search-and-match.mjs metadata/식당.csv`)에는 영향이
  제한적이다 — "공원"류 복합어 재시도는 식당명에 해당 단어가 없으면
  건너뛰고, 주소검색 재시도는 키워드를 넘기지 않으면 비활성 상태다. 다만
  "이름 유일성 우선" 규칙(2번)은 공유 모듈이라 식당 매칭에도 그대로
  적용된다 — 체인점처럼 동명이 여러 지점에 있는 식당은 검색 결과에 실제로
  여러 개가 나오는 한 기존과 동일하게 주소로 가려진다(영향 없음).
