## 점검 방법 및 발견 — 실측(코드 레벨)
관리자 화면 전체(`data-grid-client.tsx` + 자기완결적 패널 6개 + 모달 다수)를 다음
기준으로 훑었다: 고정 픽셀 너비(`w-[...]`, 모바일 대응 없이), 가로 스크롤 없는 넓은
테이블, `flex`(줄바꿈 없음) 컨테이너의 폭 초과 가능성, `flex-1` 텍스트 요소의
`min-width` 기본값(auto)으로 인한 넘침.

**확실한 버그 1건 발견**: 탭 바(`AdminTable` 탭 목록, 오늘 `category_mapping` 추가로
8개)가 `flex`(가로 스크롤/줄바꿈 없음) 컨테이너 안에 있는데, 그 바깥 조상
(`<div className="flex-1 flex flex-col overflow-hidden">`)이 `overflow-hidden`이라
좁은 화면(예: 375px)에서 화면 폭을 넘는 뒤쪽 탭("🗂️ 노출 중분류 매핑" 등)이
**완전히 잘려서 클릭할 방법이 없었다**(스크롤도, 줄바꿈도 안 됨 — 진짜로 도달 불가).

그 외에는 이 코드베이스가 이미 일관되게 모바일 우선 패턴(`w-full md:w-[...]` 모달,
`flex flex-wrap` 필터 바)을 쓰고 있어 심각한 문제는 없었다 — 다만 방어적으로 보완할
가치가 있는 지점 두 곳을 함께 고쳤다(아래).

## 변경 사항 (`src/components/admin/data-grid-client.tsx`, `spot-dedup-panel.tsx`)
1. **탭 바**: `overflow-x-auto` 추가 + 각 탭 버튼에 `shrink-0` — 이 프로젝트의 다른
   가로 칩 목록(SpotCategoryFilter 등)과 동일한 패턴으로, 화면에 다 들어가지 않는
   탭도 가로로 스와이프해 도달할 수 있게 한다.
2. **헤더 행**(제목 + "카테고리 키워드 규칙 관리"/"필터 초기화" 버튼): `flex-wrap`
   추가 — `justify-between` + nowrap이라 아주 좁은 화면에서 버튼이 밀려나갈 여지가
   있어 줄바꿈을 허용한다.
3. **중복 의심 그룹 목록 / 진행 중 저장된 그룹 목록**(`spot-dedup-panel.tsx`): 긴
   시설명이 들어간 그룹 라벨을 담은 `flex-1` 요소에 `min-w-0 truncate` 추가 — flex
   아이템은 기본 `min-width: auto`라 텍스트가 길면 형제 버튼("🙈 중복 아님"/"이어서
   검수" 등)을 화면 밖으로 밀어낼 수 있는 잘 알려진 flexbox 함정이다.

## 특이 사항
- **넓은 데이터 테이블(open_spaces/events 그리드)은 이미 동작한다** — 명시적인
  `overflow-x-auto` 래퍼는 없지만, 그 부모(`flex-1 overflow-auto p-4`)가 가로/세로
  모두 자동 스크롤을 이미 허용하고 있어 페이지 자체가 깨지지는 않는다(테이블 내부
  스크롤로 동작). 다만 세로 스크롤과 가로 스크롤이 같은 컨테이너에 있어 대각선
  스와이프 시 다소 부자연스러울 수 있다 — 이번엔 "완전히 도달 불가능한" 탭 바
  버그가 더 시급하다고 판단해 우선 처리했고, 테이블 스크롤 UX 개선은 필요하면
  별도로 진행할 수 있다.
- **"전체 컬럼" 원문 뷰**(`RawDataModal`)는 `grid-cols-2`를 모바일에서도 그대로
  쓴다 — 각 값에 `truncate`가 있어 넘치지는 않지만, 라벨이 길면 다소 빡빡해 보일 수
  있다. 이건 어드민 파워유저용 디버깅 뷰(자주 쓰는 주 화면이 아님)라 이번 점검에서
  더 손대지 않았다.
