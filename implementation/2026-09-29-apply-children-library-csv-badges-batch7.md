# 사용자 제공 CSV(batch7) 기반 어린이도서관 뱃지 반영 — 정확한 주소로 재확인된 항목

## 구현 대상
사용자 지시(2026-09-29): "children_libraries_analysis_batch7.csv 여기 다시
넣어놨어 뱃지빈거.. 채워넣어줘" — batch1/batch6에서 이름+지역(시/도)만으로는
확신할 수 없어 반영을 보류했던 항목들을 사용자가 **정확한 전체 주소**로
직접 재확인해 다시 제공했다.

## 처리 방식 변경 — 이번엔 주소 완전일치로 대조
이전(batch1/batch6)엔 CSV의 "지역"(시/도 수준)과 DB 주소를 대조했지만, 이번
CSV는 컬럼 자체가 "주소"(전체 도로명주소)로 바뀌었다 — 그래서 province
수준 대조가 아니라 공백/괄호를 제거한 **주소 문자열 완전일치**로 재대조했고,
21건(1건은 중복 조회로 겹침, 실제 20개 스팟) **전부** DB에서 정확히 일치하는
행을 찾았다.

## 중요한 정정 3건
1. **서울특별시교육청 어린이도서관**: batch6에서는 후보 3개 중 주소가 다른
   `fc529917`(사직로 89)을 근거 부족으로 제외하고 `f5759c7f`/`4ecb04fc`
   (사직로9길 7) 쌍만 반영했었다. 이번에 사용자가 제공한 정확한 주소가
   `fc529917`과 정확히 일치해, 실제로는 이 행이 맞았다. 기존 두 행에 반영된
   뱃지는 그대로 두고 `fc529917`에도 동일하게 반영했다 — **세 행 중 어느 게
   진짜 대표인지는 이번 지시 범위 밖의 별도 중복 검수가 필요하다.**
2. **글마루한옥어린이도서관**: batch1/batch6에서는 원문 소개글로 확인된
   `aac0f845`만 반영하고, 주소에 "개봉어린이도서관"이라는 다른 이름이 섞여
   있던 `4895720d`는 다른 시설일 가능성으로 제외했다. 이번에 사용자가 제공한
   정확한 주소가 `4895720d`와 정확히 일치해, 이 역시 반영 대상에 포함했다.
   **두 행이 실제로 같은 곳인지, 중복 병합이 필요한지는 별도 확인 필요.**
3. **화전어린이도서관**: batch1에서 "경기 고양시"로 알려진 지역과 DB의
   유일한 후보(경남 남해군)가 달라 반영을 보류했다. 이번에 사용자가 제공한
   정확한 주소가 경남 남해군 쪽과 정확히 일치해, 이전 지역 정보("경기
   고양시")가 부정확했던 것으로 확인됐다.
4. **구로 꿈나무어린이도서관**: 이전 세션에서 "구로꿈나무도서관"이
   category_min='도서관'으로 분류돼 있어 반영을 보류했던 것과는 **다른,
   이미 category_min='어린이도서관'으로 정확히 분류된 별도 행**(`a11c8b4d`)
   이 정확한 주소로 확인돼 반영했다 — 카테고리 불일치 문제가 아니라 별개의
   중복 행이 있었던 것.
