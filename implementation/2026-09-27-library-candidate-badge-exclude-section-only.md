# 키즈 공간 후보 뱃지 — 도서관 "자료실"(구역) 제외

## 구현 대상
사용자 지시(2026-09-27): "아니 통영시립도서관 아동자료실_유아자료실은 아니야
순수 어린이 도서관만." — 도서관 category_min 후보 검수 중 발견.

## 배경
`category_min='도서관'` 후보 160건(이름에 "어린이/아동" 포함) 중 4건이
"[일반도서관 이름]_아동/어린이자료실" 패턴이었다: 레인보우영동도서관_
어린이자료실, 통영시립도서관 아동자료실_유아자료실, 통영시립욕지도서관
아동_유아자료실, 통영시립충무도서관 아동_유아 자료실. 이 4건은 건물 전체가
아동 전용인 "OOO어린이도서관"과 달리, 일반도서관 안의 한 구역(자료실)일
뿐이다 — 사용자가 "순수 어린이 도서관만"으로 범위를 확정했다.

가장 큰 소스(`cultural_facility_summary`, 1,210건)의 raw_data 필드를 전부
확인했으나 "어린이도서관 여부"를 나타내는 구조화된 필드는 없었다(설립근거
지자체/교육청/사립/국립만 있음) — 이름 키워드가 유일한 구분 신호임을
재확인했다.

## 변경 사항
`src/lib/admin/kids-space-candidate.ts`: `categoryMin === '도서관'`이고
이름에 "자료실"이 포함되면 후보에서 제외하는 규칙 추가(공원의
`PARK_THEME_KEYWORDS`와 동일한 카테고리별 예외 패턴). 그 외 카테고리는
"자료실"이 노이즈 신호인지 확인된 바 없어 건드리지 않았다.

## 검증
- `src/lib/admin/kids-space-candidate.test.ts`(신규 1개): "OO도서관_아동자료실"
  류는 false, "노원어린이도서관"(순수 어린이도서관)은 true.
- `npx tsc --noEmit` / `npm run test`(207개 파일 2,414개) / `npm run build`
  모두 통과.

## 특이 사항
- 이 변경으로 도서관 후보 뱃지가 뜨는 행은 160건 → 156건으로 줄어든다(실제
  category_min 데이터는 바꾸지 않음, 표시만 조정).
