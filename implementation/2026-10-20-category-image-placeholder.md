# 이미지 없는 스팟/이벤트에 카테고리별 기본 플레이스홀더

## 구현 대상
`todo.md` 개선사항 2 중: "우리 현재 이미지 나타내는거 이미지 없는것에
대하여서는 AI로 그에 맞는 이미지 생성한 것을 넣을 수 있도록 하자."

사용자 확인(AI 이미지 정책 질문): **실시간 생성 API 연동 대신 "단일
카테고리별 기본 플레이스홀더"**로 범위를 좁힘(API 호출 비용이 계속
발생하는 결정이라 사전 확인).

## 구현 일시
2026-10-20

## 변경 사항
- `src/lib/spaces/category-meta.ts`: 기존 5대 UI 카테고리 메타(color/
  label)에 `emoji` 필드 추가(체험·클래스 🎨/야외·자연 🌳/전시·박물관
  🖼️/공연·축제 🎪/키즈·액티비티 🧸, 기본값 📍). 순수 UI 장식용이라
  하드코딩 최소화(제5장 제6조) 대상이 아니라고 판단.
- `src/components/map/detail-modal.tsx`: EVENT 분기(기존엔 이미지
  없으면 영역 자체를 숨김)와 SPACE 분기(기존엔 큐레이션 이미지 없으면
  영역을 숨김) 둘 다, 실제 이미지가 없을 때 카테고리 색상 배경 + 이모지
  플레이스홀더를 보여주도록 바꿨다.

## 검증
- `npx tsc --noEmit` / `npm run test -- --run`(337 파일 3,358개) /
  `npm run build` 전부 통과.

  테스트를 "플레이스홀더를 보여준다"로 교체, SPACE 쪽에도 동일한
  테스트 신규 추가.

## 특이 사항
- 실시간 AI 이미지 생성은 이번 범위에 포함하지 않음(API 호출 비용이
  계속 발생하는 결정이라 사용자가 먼저 "단일 카테고리별 기본
  플레이스홀더"를 선택). 나중에 실제 생성형 이미지로 바꾸고 싶다면
  별도 지시로 진행.
