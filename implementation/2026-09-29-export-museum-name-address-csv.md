# 문화시설 표준중분류별 명칭·주소 CSV 내보내기

## 구현 대상
todo.md [개선사항 2] (2026-09-29 등록): open_spaces에서 과학관/역사박물관/
종합·기타박물관 3개 표준중분류를 필터링해 명칭+주소만 각각 CSV로 저장하는
Node.js 스크립트. "정규 기수제 수강료를 내고 다니는 학원형/멤버십형 민간
시설(예: 어린이천문대 등 사설 교육기관)"은 제외.

## 변경 사항
### `scripts/export-museum-name-address.mjs` (신규)
- 요청 원문의 `category_sub`는 실제 스키마 컬럼명이 아니라 `category_min`을
  그대로 사용(제5장 제4조 기존 구조 우선), `@supabase/supabase-js` +
  `scripts/lib/load-env.mjs`(.env.local 로더) + `scripts/ingest/lib/
  supabase-admin.mjs`(createAdminClient)도 이 프로젝트의 기존 관례를 그대로
  재사용.
- 중복 스팟 그룹은 대표 행만 추출(`group_id.is.null,is_dedup_representative.
  eq.true` — 관리자 데이터 그리드 목록 API와 동일한 필터, 같은 실제 장소가
  중복 원본 멤버 수만큼 여러 줄로 찍히는 것을 방지).
- `종합/기타박물관`이 1,388건이라 Supabase 기본 조회 상한(1,000건)을
  넘어 `.range()` 페이지네이션으로 전량 조회.
- 쉼표/줄바꿈/쌍따옴표가 포함된 명칭·주소도 안전하게 처리(RFC 4180 쌍따옴표
  이스케이프).

### 사설 교육기관 제외 — 실측 근거
구조화된 DB 필드(예: `is_free`)만으로는 "학원형/멤버십형 민간 시설"과 유료
입장 공공 박물관(예: 국립대구과학관, 대한민국역사박물관)을 신뢰성 있게
구분할 근거가 없다(제3장 제5조 추측 금지). 실제 데이터를 확인한 결과
"OO어린이천문대"(공백 유무 무관) 이름 패턴의 시설이 **18곳**이나 전국
각지(세종/분당/파주/안산/의왕/광교/동탄/안양/부천/수지/구리/판교/일산/
송파하남/울산/별내/용인/인천)에 프랜차이즈 형태로 퍼져 있음을 확인했다 —
이는 사용자가 제시한 예시("어린이천문대")와 정확히 일치하고, 여러 지역에
동일 브랜드명 패턴으로 반복되는 것 자체가 사설 교육 프랜차이즈의 특징과
부합한다. 이 패턴에 걸리는 행만 확실한 근거로 제외했고, 그 밖의 잠재적
사설 교육기관은 추측으로 제외하지 않았다(실행 로그에 제외된 18건 전체를
남겨 관리자가 직접 검증 가능).

## 특이 사항
- 생성된 CSV 3개는 실행 결과물(수시로 재생성 가능한 산출물)이라 커밋 대상에
  포함하지 않았다 — 스크립트 자체만 커밋한다.
- 이번에 제외한 18건 외에 "학원형/멤버십형" 시설이 더 있을 수 있으나, 이름
  패턴만으로 신뢰성 있게 구분할 근거가 없는 건 그대로 CSV에 남겼다 — 추가
  제외 기준이 필요하면 `EXCLUDED_NAME_PATTERNS` 배열에 패턴만 추가하면
  된다(확장 가능한 구조, 요구사항 4번 대응).
