# 놀이방찜질방/스파 뱃지 — 안마의자 추가

## 구현 대상
사용자 지시(2026-09-26): "안마의자가 빠졌네....".

## 근거
이 세션 앞부분에 사용자가 붙여준 실제 블로그 후기 원문(아뮤즈스파&피트니스
남악점)에 이미 명확한 근거가 있었다: "하지만 휴식의 하이라이트는 역시
안마의자실이죠? 프라이빗하게 공간이 분리된 룸에 고급 안마의자가 가득해요.
요금은 15분에 2,000원인데 락커키로 간편하게 결제 가능해요" — 뱃지 목록을
확정할 때 이 부분을 놓쳤다. `KIDS_CAFE_CONFIG`에도 동일 개념(`kc_parent_relax`,
"부모 쉼터/안마의자")이 이미 있어 이 프로젝트에서 처음 다루는 개념도 아니다.

## 변경 사항
`src/lib/admin/curation-badges.ts`의 `SPA_JJIMJILBANG_CONFIG`(휴게/청결
그룹)에 `jj_massage_chair`(안마의자) 추가. 블로그 후기 키워드 매칭으로만
채운다(네이버 리뷰 투표 코드 목록에는 안마의자 전용 코드가 없었음). 키워드는
`KIDS_CAFE_CONFIG.kc_parent_relax`의 관련 항목을 재사용(제5장 제4조).

## 검증
- `src/lib/admin/curation-badges.test.tsx`: 뱃지 개수 20→21(휴게/청결
  그룹 4→5개), 신규 키워드 매칭 테스트 1개 추가.
- `npx tsc --noEmit` / `npm run test`(203개 파일 2,372개) / `npm run build`
  모두 통과.
