# 로딩 화면 — 커스텀 GIF 애니메이션을 기본 스피너로 복귀

## 구현 대상
사용자 지시(2026-10-09): "어 우리 로딩할때 애니메이션인가 그거 넣었잖아.
그거 그냥 기본로딩 버튼으로 좀 바꿔줘"

## 구현 일시
2026-10-09

## 배경
2026-09-03에 `BrandSplash`(라우트 전환/탭 전환 시 보이는 공용 로딩
컴포넌트, `app/loading.tsx` + `bottom-tabs.tsx`에서 사용)의 기본
회전 스피너(`animate-spin`)를 사용자가 직접 제공한 움직이는 GIF
(`public/loading/loading_image.gif`)로 교체했었다. 이번 지시는 그
커스텀 GIF를 다시 평범한 스피너로 되돌리라는 요청이다.

## 변경 사항
- `src/components/common/brand-splash.tsx`: `<img>` GIF를 제거하고,
  2026-08-22 최초 구현 당시의 스피너 마크업(`h-10 w-10 rounded-full
  border-4 border-gray-200 border-t-blue-600 animate-spin`)을 git
  히스토리(커밋 `9f083a0`의 부모)에서 그대로 복원했다. 타이틀/서브
  문구("나드리픽" / "오늘 어디 가지?" / "LOADING...")는 이번 요청과
  무관한 이후 변경(영문 표기 제거 등)이라 그대로 유지했다 — 요청
  범위(애니메이션→기본 스피너)만 되돌림.
- `public/loading/loading_image.gif` 파일 자체는 삭제하지 않았다 —
  더 이상 코드에서 참조되지 않지만, 다른 곳에서 재사용될 가능성을
  배제할 수 없어(추측 금지, 제3장 제5조) 삭제는 별도 지시 없이
  진행하지 않는다.

## 검증
- `npx tsc --noEmit` / `npm run test`(294개 파일 3,005개 전체) /
  `npm run build` 전부 통과 — `BrandSplash` 전용 테스트는 없었고,
  다른 테스트도 GIF/스피너 마크업을 직접 참조하지 않아 수정 없이
  통과.
- 실제 브라우저 스크린샷 확인은 이 환경에 브라우저 도구가 없어
  수행하지 못했다(정직하게 한계 기록) — 변경이 git 히스토리에 있던
  기존 검증된 마크업을 그대로 복원한 것이라 렌더링 리스크는 낮다.
