# EventCard — 썸네일 없는 카드의 텍스트 잘림 수정

## 구현 대상
사용자 지시: "이벤트픽의 체험학습장같은경우 이미지 없을때 카드가 텍스트영역이랑
5:5하려고 해서 그런지.. 텍스트 있어도 짤리더라... 카드가 작게나오고"

## 구현 일시
2026-09-05

## 원인 — 실측(코드) 확인
`src/components/cards/event-card.tsx`의 이미지 영역/텍스트 영역은 카드 고정 높이를
`flex-[5]`/`flex-[5]`로 정확히 5:5 분할하도록 이미 여러 차례(2026-08-29~09-03)
세심하게 튜닝돼 있었다 — 다만 이 비율은 **실제 썸네일이 있는 카드**를 기준으로
잡은 값이었다.

체험학습장/캠핑장 등 `SHARED_OPEN_SPACES_CATEGORY_MINS`로 이벤트픽에 연동되는
open_spaces 기반 카드는 `thumbnail_url`이 **항상 null**이다(`get-home-feed.ts`
toSpaceItem 기존 주석 — 공공데이터 스팟은 실제 썸네일을 제공하지 않음). 이 경우
이미지 영역에는 정보 없는 placeholder 이모지(🖼️)만 뜨는데도 카드 높이의 절반을
그대로 차지해, 남은 절반(텍스트 영역)에 제목(2줄)+장소+거리+기간까지 다 넣기엔
비좁아 실제로 내용이 있어도 잘렸다.

## 변경 사항
- `src/components/cards/event-card.tsx`: `hasThumbnail = Boolean(item.thumbnail_url)`을
  계산해, 썸네일이 있으면 기존과 동일하게 `flex-[5]`/`flex-[5]`를 유지하고, 없으면
  이미지 영역을 `flex-[2]`로 줄이고 텍스트 영역을 `flex-[8]`로 늘린다. 이미지 영역
  위 오버레이(중분류 뱃지, 무료/유료, 실내/야외)는 그대로 유지된다 — 영역이 좁아질
  뿐 내용 손실은 없다.

  - "썸네일이 있으면 flex-[5]/flex-[5]" — 기존 검증 그대로 유지(픽스처만 실제
    thumbnail_url을 갖도록 수정).
  - 신규: "썸네일이 없으면 flex-[2]/flex-[8]로 바뀐다".
  - dateBanner 관련 두 테스트: 배너 유무가 비율에 영향을 주지 않는다는 기존 취지는
    그대로 유지하되, 기본 픽스처(썸네일 없음)의 새 비율(flex-[2]/flex-[8])에 맞게
    기댓값을 갱신했다.
- `npm run build` 통과.

## 특이 사항
- **비율 값(2:8)은 사용자가 지정한 정확한 숫자가 아니라, "텍스트가 잘리지 않을
  만큼 충분히 크게"라는 의도를 반영해 판단한 값이다** — 실제 화면에서 봤을 때 더
  조정이 필요하면 이 두 숫자만 바꾸면 된다(다른 로직에 영향 없음).
- 이 변경은 EventCard를 쓰는 모든 화면(이벤트픽 홈 피드, 카테고리별 피드, 검색
  결과 등)에 동일하게 적용된다 — 체험학습장뿐 아니라 썸네일이 없는 모든 이벤트/
  연동 카드에 공통으로 이득이 있다.
