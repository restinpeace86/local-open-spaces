# Common Specification (`spec/common/`)

본 디렉토리는 `local-open-spaces` 서비스 전반에서 공통으로 사용되는 UI 레이아웃, 검색 UI, 그리고 기능 제어 규칙을 정의한다.

## 하위 스펙 문서 목록

- **`responsive.md`**: Mobile(< 768px) 바텀시트 레이아웃과 Desktop(>= 768px) 2단 Split View 레이아웃 동작 규칙 정의 (Decision 004)
- **`search.md`**: 상단 통합 검색 바 및 카테고리/반경 필터 UI 공통 컴포넌트 스펙
- **`feature-flags.md`**: 미승인/미오픈 확장 기능의 UI 노출을 제어하는 Feature Flag 적용 원칙 (Decision 003)
