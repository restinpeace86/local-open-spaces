# 반응형 레이아웃 스펙 (spec/common/responsive.md)

## 1. 개요

본 문서는 `local-open-spaces` 서비스의 화면 레이아웃 및 디바이스별 인터페이스 분기 규칙을 정의한다. 

프로젝트 의사결정(Decision 004)에 따라, 브라우저 뷰포트 너비 **Breakpoint `768px`**을 기준으로 모바일과 데스크톱 환경의 2단 멀티 레이아웃 시스템을 채택한다.

---

## 2. 디바이스별 레이아웃 구조

### 2.1. Mobile 환경 (`< 768px`)
- **전체 화면 지도 (Fullscreen Map):** 화면 전체(`100vw`, `100vh`)를 Kakao Map SDK가 가득 채운다.
- **바텀시트 (Bottom Sheet) 인터페이스:**
  - 화면 하단에 고정되거나 드래그 가능한 형태로 리스트 및 상세 정보가 노출된다.
  - 평소에는 최소 높이(Collapsed)로 주요 요약 카드만 보여주며, 위로 드래그하거나 클릭 시 확장(Expanded)되어 주변 공간/행사 목록을 탐색할 수 있다.
- **마커 상호작용:** 지도 위의 마커를 터치하면 해당 아이템의 바텀시트 카드가 포커싱되며 상세 모달로 전환된다.

### 2.2. Desktop 환경 (`>= 768px`)
- **2단 Split View 레이아웃:** 화면을 좌우로 분할하여 배치한다.
  - **좌측 패널 (Control & List Panel, 약 380px ~ 420px 고정/가변):** 상단 검색바, 필터, 주변 열린 공간 및 행사 리스트가 스크롤 영역으로 제공된다.
  - **우측 패널 (Main Map Panel, 나머지 잔여 공간):** Kakao Map SDK가 렌더링되는 메인 지도 영역으로 항상 고정된다.
- **마커 및 리스트 연동:** 
  - 좌측 리스트에서 특정 항목을 마우스로 클릭하면 우측 지도의 해당 마커가 센터링 및 활성화된다.
  - 우측 지도에서 마커를 클릭하면 좌측 리스트의 해당 아이템 카드로 스크롤이 이동하며 하이라이트된다.

---

## 3. 구현 시 유의사항 (Technical Notes)

1. **Kakao Map 리사이징 대응:**
   - 브라우저 창 크기가 조절되거나 모바일/데스크톱 브레이크포인트 경계를 넘나들 때, Kakao Map SDK의 `relayout()` 메서드와 `setCenter()`를 호출하여 지도 영역이 깨지거나 회색 타일이 노출되는 현상을 방지해야 한다.
2. **상태 공유 (State Management):**
   - 현재 선택된 지도 중심 좌표(`center`), 반경(`radius`), 활성화된 필터, 그리고 선택된 아이템(`selectedId`)의 상태는 모바일과 데스크톱 환경 모두 동일하게 전역 또는 컨텍스트 상태로 공유되어야 한다.
