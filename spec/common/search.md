# 검색 및 필터 UI 스펙 (spec/common/search.md)

## 1. 개요

본 문서는 서비스에서 사용자의 위치 주변 놀거리(열린 공간·시한성 행사·핫딜)를 탐색하기 위해 제공되는 통합 검색 바와 필터 UI, 그리고 탐색 범위 제한 정책을 정의한다. 서비스 모토/카테고리 정책의 SSOT는 `docs/spec.md`이며 (Decision 008), 본 문서는 그 검색·필터 UI 세부 규칙을 다룬다.

---

## 2. 검색 및 필터 구성 요소

### 2.1. 통합 검색 바 (Search Bar)
- **위치:**
  - 모바일: 지도 상단 오버레이 영역 (Floating Header)
  - 데스크톱: 좌측 컨트롤 패널 상단 고정
- **기능:** 공간/행사 명칭, 키워드(예: "공원", "축제", "도서관") 실시간 검색 입력
- **인터랙션:** 입력 즉시(Debounce 300ms 적용) 현재 설정된 반경 내 검색 결과 필터링 또는 명칭 매칭 수행

### 2.2. 반경 선택 필터 및 범위 제한 정책 (Radius Selector & Boundary Policy)

- **기본 반경 옵션 (`1km`, `5km`, `10km`):**
  - 사용자가 1km, 5km, 10km 버튼을 클릭할 때는 **필터 선택 여부와 상관없이 무조건 팝업 없이 즉시 적용**된다.
- **광역 확장 반경 옵션 (`20km`, `30km`):**
  - **조건부 해금:** 카테고리 또는 Quick 필터('키즈', '무료', '오늘/주말') 중 1개 이상 활성화 시에만 `20km`, `30km` 반경 선택 가능.
  - **조건 만족 시 동작:** `20km`/`30km` 선택 시 `circle.getBounds()` 기반 자동 줌아웃 수행 및 지도 상 마커를 숫자 클러스터(Cluster)로 그룹핑하여 노출.
  - **차단 팝업 노출 조건:** 사용자가 **'20km' 또는 '30km' 버튼을 직접 클릭했을 때만**, 필터가 하나도 선택되지 않은 상태인 경우에 한해 광역 안내 팝업(`GridViewPrompt`)을 노출하고 10km 범위 조정을 유도한다. (1km/5km/10km 클릭 시에는 절대 팝업을 노출하지 않음. 서버 과부하 방지 목적)

### 2.3. 카테고리 및 유형 필터 (Category & Type Filter)
- **UI 노출 카테고리 (5대, Decision 008):** 전체, 🎨 체험·클래스, 🌳 야외·자연, 🏛️ 전시·박물관, 🎪 공연·축제, 🎡 키즈·액티비티 (`spec/data/ai-rule.md` 3.3 매핑 기준. DB 원본 세부 카테고리는 이 5대 카테고리 안으로 그룹핑되어 노출됨)
- **인터랙션:** 칩(Chip) 형태의 단일 선택 UI로, 선택 시 지도 위 마커와 리스트가 즉시 동기화되어 렌더링됨

### 2.4. Quick Filters & Parental Targeting
- **👶 키즈/어린이**: `target_age_group`이 유아/어린이 대상인 항목 스크리닝
- **🎁 무료 이용**: `is_free`가 true인 항목 스크리닝
- **⚡ 오늘/주말 방문**: 사전 예약 없이 당일/주말 즉시 이용 가능 항목 스크리닝 (`docs/spec.md` 1: 사전 예약 마감건은 메인 노출에서 제외)
