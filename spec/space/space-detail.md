# 공간 상세 정보 스펙 (spec/space/space-detail.md)

## 1. 개요
사용자가 특정 공간 카드를 클릭했을 때 노출되는 **공간 상세 정보 모달(Modal / Bottom Sheet)**의 구성과 외부 연동 규칙을 정의한다.

---

## 2. 상세 모달 구성 요소

- **헤더 영역:** 
  - 카테고리 칩, 공간 명칭, 즐겨찾기(북마크) 버튼
- **기본 정보 영역:**
  - **주소:** 전체 도로명 주소 및 원클릭 복사(Copy) 버튼 제공
  - **운영시간:** 요일별 운영 시간 또는 상시 개방 여부 안내 (`operating_hours`)
  - **이용 요금:** 무료/유료 여부 및 상세 안내
- **액션 버튼 (CTA):**
  - **길찾기 연동:** 카카오맵/네이버지구/T맵 등 외부 길찾기 앱으로 좌표(`lat, lng`)를 전달하여 바로 길 안내를 시작하는 버튼
  - **관련 행사 보기:** 만약 해당 공간(예: 서울시립미술관, 난지한강공원 등)에서 진행 중이거나 예정된 **시한성 이벤트(`events`)**가 있는 경우, 하단에 연관 행사 리스트를 슬라이드 형태로 노출

---

## 3. 예외 및 Fallback 처리

- 운영시간이나 상세 정보가 공공 API 원본에 누락(`NULL`)된 경우, 빈 칸으로 두지 않고 *"정보 준비 중 (공공 기관 문의)"* 등의 기본 문구를 노출하여 UI가 깨지지 않도록 방어한다.
