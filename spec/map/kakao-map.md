# Kakao Map SDK 연동 스펙 (spec/map/kakao-map.md)

## 1. 개요

본 문서는 `local-open-spaces` 서비스에서 지도 화면을 구현하기 위해 사용하는 **Kakao Maps API SDK v2**의 초기화, 반응형 레이아웃 대응, 그리고 마커 및 인포윈도우 렌더링 규칙을 정의한다.

---

## 2. SDK 초기화 및 로드 방식

- **비동기 스크립트 로드:** 앱 실행 시 Kakao Map SDK 스크립트를 동적으로 로드하며, `autoload=false` 파라미터를 사용하여 카카오맵 객체가 완전히 로드된 후 초기화 함수(`kakao.maps.load()`)가 실행되도록 보장한다.
- **API Key 관리:** 발급된 Kakao App Key는 환경 변수(`NEXT_PUBLIC_KAKAO_MAP_API_KEY` 등)로 분리하여 관리하며, 프론트엔드 빌드 시 안전하게 주입한다.

---

## 3. 반응형 뷰포트 및 리사이징 대응

- **모바일/데스크톱 대응:**
  - 모바일 뷰에서는 화면 전체(`100vw`, `100vh - Header Height`)를 채우도록 오버레이 형태로 렌더링한다.
  - 데스크톱 뷰에서는 좌측 패널(리스트 및 필터)과 우측 지도 영역이 분할된 레이아웃으로 구성한다.
- **리사이징 이벤트 처리:**
  - 브라우저 크기 변경이나 모바일 기기 회전(Orientation Change) 시, `map.relayout()` 및 `map.setCenter()` 메서드를 호출하여 지도 영역이 깨지거나 회색 타일이 노출되는 현상을 방지한다.

---

## 4. 마커 및 인포윈도우 렌더링 규칙

### 4.1. 커스텀 마커 (Custom Marker)
- 기본 제공되는 핀 대신, 서비스의 성격(상시 공간 vs 시한성 행사)과 카테고리별로 시각적으로 구분되는 **커스텀 HTML 마커 이미지**를 사용한다.
- 마커 렌더링 시 과도한 DOM 생성을 막기 위해 Kakao Map 기본 `MarkerClusterer` 라이브러리를 연동하여 인접한 마커들을 그룹화한다.

### 4.2. 오버레이 및 인포윈도우 (Overlay / InfoWindow)
- 사용자가 마커를 터치/클릭했을 때, 해당 공간 또는 행사의 핵심 정보(이름, 카테고리, D-day 등)를 담은 **모바일 최적화 미니 카드(Bottom Sheet 또는 Popup Overlay)**가 노출되도록 한다.
- 지도를 터치하거나 다른 영역을 클릭하면 인포윈도우가 즉시 닫히도록 이벤트 리스너를 관리한다.
