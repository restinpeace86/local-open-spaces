# [open_spaces NULL 데이터 그룹핑 분석] 신규 중분류 후보 제안

> **성격**: 분석·제안 문서다. [open_spaces 세부 중분류 매핑](2026-08-28, `docs/open-spaces-
> detailed-category-mapping-dryrun-report.md`)에서 8개 source_type(문화/역사/자연/관광
> 시설류)에 한해 category_min을 채웠는데, 그 작업에서 **의도적으로 범위 밖으로 둔** 나머지
> 4개 source_type의 잔여 NULL을 대상으로 한다. 이 문서는 후보 제안만 하며, 실제
> `category_rules` 반영이나 DB UPDATE는 수행하지 않았다 — 실행 여부는 별도 확인 후 진행한다.

## 0. 배경 — 왜 이 4개 소스만 남았나

이전 작업에서 `LOCALDATA_PLAYGROUND`/`LOCALDATA_AMUSEMENT`/`SWIMMING_POOL`/`GG_EVENTS`는
`name`이 "놀이시설이 설치된 호스트 건물명"이라 문화/역사/자연/관광 taxonomy와 데이터
도메인 자체가 다르다고 판단해 제외했다. 이번 문서는 그 4개 소스를 **각자의 실제 도메인
기준으로** 별도 분류하는 방안을 검토한다.

## 1. 전체 분포 (실측, 2026-08-28)

`category_min IS NULL`인 open_spaces 16,344건 전량이 이 4개 source_type이다(다른
source_type의 NULL은 이미 0건).

| source_type | 건수 | 비율 |
| :--- | ---: | ---: |
| LOCALDATA_PLAYGROUND | 13,103 | 80.2% |
| LOCALDATA_AMUSEMENT | 2,039 | 12.5% |
| SWIMMING_POOL | 715 | 4.4% |
| GG_EVENTS | 487 | 3.0% |
| **합계** | **16,344** | 100% |

## 2. source_type별 분석 및 후보 제안

### 2.1. `LOCALDATA_PLAYGROUND` (13,103건, 80.2%) — 신뢰도 높음

- **도메인**: 행정안전부 전국어린이놀이시설정보. `name`은 놀이시설이 설치된 호스트
  건물명(아파트/교회/어린이집/학원/식당 등)이라 키워드로 성격을 구분할 수 없지만, 소스
  자체가 "어린이놀이시설" 등록 정보이므로 **전량이 어린이놀이시설이라는 사실 자체는
  확실**하다(추측이 아니라 소스 정의).
- **구조화된 신호**: `facility_type` 필드가 이미 100% 채워져 있고 신뢰도가 높다.
  - 야외: 9,814건(74.9%)
  - 실내: 3,289건(25.1%)
- **샘플**: 순복음강북교회, 창동신도브래뉴 103동 앞, 은봉초등학교 병설유치원 놀이장,
  본가 왕뼈 감자탕(식당 부속 놀이시설로 추정), 태영아파트(106동 뒤)
- **제안**: `어린이놀이시설(야외)` / `어린이놀이시설(실내)` 2종 신규. 키워드 매칭이 아니라
  **소스 도메인 + 구조화된 facility_type 필드 기준**이라 이름 오탐 위험이 없다(이전 작업의
  "수목원호정포레스트" 같은 이름 키워드 오탐 문제 자체가 발생하지 않음).

### 2.2. `SWIMMING_POOL` (715건, 4.4%) — 신뢰도 높음, 기존 카테고리 재사용 가능

- **도메인**: 수영장 사업자 등록 정보. 전량 수영장이다(이미 이 소스의 나머지 817건은
  기존 `수영장` 카테고리로 분류되어 있음).
- **샘플**: 스윔아이, 짐스아쿠아, (주)부산시민스포츠센터, 스포렉스, 보아스수영클럽 —
  상호에 "수영장" 문자열이 없어 키워드 매칭에서만 빠졌을 뿐 실질은 전부 수영장이다.
- **제안**: 신규 카테고리 불필요 — **기존 `수영장`으로 소스 기반 일괄 재사용**(제5장
  제4조 기존 구조 우선).

### 2.3. `LOCALDATA_AMUSEMENT` (2,039건, 12.5%) — 신뢰도 중간, 부분 매칭

- **도메인**: 유원시설업(유원시설 설치·운영 사업) 등록 현황. 어린이 놀이터보다 범위가
  넓고(`facility_type='복합'`이 97.2%), "호텔159"/"태화강 참숯가마" 같은 사업자 등록명이
  섞여 있어 실제 운영 내용을 이름만으로 확정하기 어렵다.
- **실측**: 이름에 "키즈카페" 포함 **262건(12.8%)**. 나머지 1,777건(87.2%)은 이름
  패턴이 제각각이라 안전하게 묶을 공통 키워드를 찾지 못했다.
- **제안(부분)**: `키즈카페` 신규 — 262건만 안전하게 매칭 가능. 나머지 1,777건은 이름
  기반으로 확정할 근거가 부족해(추측 금지) 이번 제안에서 보류한다.

### 2.4. `GG_EVENTS` (487건, 3.0%) — 신뢰도 중간, 부분 매칭

- **도메인**: 경기도 공공데이터 이벤트/시설. `category`(대분류) 기준 OUTDOOR_NATURE
  465건/KIDS_ACTIVITY 22건. 샘플 대부분이 "이벤트"가 아니라 아파트 단지에 상시 설치된
  놀이 시설(바닥분수 등)로 보인다.
- **실측**: 이름에 "바닥분수" 또는 "물놀이" 포함 **163건(33.5%)**. 나머지 324건은
  "광주행정타운 아이파크 아파트", "위례아너스포레"처럼 단지명만 있어 어떤 시설인지
  이름만으로 알 수 없다(같은 단지 내 여러 시설 중 어떤 것인지 특정 불가).
- **제안(부분)**: `바닥분수/물놀이시설` 신규 — 163건만 안전하게 매칭 가능. 나머지
  324건은 근거 부족으로 보류. 소수(예: "김포반다비체육센터")는 기존 `체육관`류와 개념이
  겹치나 건수가 미미해(2건 내외) 별도 처리 실익이 낮다고 판단했다.

## 4. 별도 발견 — 기존 데이터 인코딩 손상 1건 (참고용, 이번 작업 범위 밖)

`category_min` 옵션 목록(46종)을 실측 확인하는 과정에서 문자 인코딩이 손상된 값 1건을
발견했다:

| id | external_id | name | category_min(손상됨) | category_min_source |
| :--- | :--- | :--- | :--- | :--- |
| `58957d18-8afa-4816-afaf-e228c9b39245` | `CULTURAL_FACILITY_SUMMARY_LVCLCNTR_0302736` | 서울생활문화센터 체부 | `���ý�` | `MANUAL` |

`category_min_source='MANUAL'`로, 관리자가 어드민 화면에서 직접 입력하다 인코딩이 깨진
것으로 보인다(이름("생활문화센터")으로 미루어 `문화의집`이 의도된 값이었을 가능성이 있으나
확정할 근거가 없어 임의로 수정하지 않았다 — 추측 금지). `/admin/data-grid`의 다중 체크박스
필터 목록에도 이 깨진 값이 그대로 노출된다. 관리자 수동 확인·재분류가 필요하다.

## 5. 결론

이번 문서는 분석·제안까지만 수행했다. 3절 표의 "적용 가능" 항목(14,183건, 86.8%)은
안전하게 실행 가능한 근거(구조화 필드 또는 명시적 키워드)를 갖췄고, "보류" 항목
(2,161건, 13.2%)은 이름만으로 확정할 근거가 부족해 추가 조사 없이는 진행하지 않는다.
실제 반영은 이 문서 검토 후 별도로 진행한다.
