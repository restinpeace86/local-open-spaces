# 📋 [통합 명세서] 가성비 놀거리 서비스 (Spec & Data Pipeline)

## 1. 서비스 정의 & 핵심 모토
- **모토**: "오늘/이번 주말, 아이·가족과 가성비 있게(0원~1만 원) 뭐 하고 놀지?"
- **핵심 가치**: 
  - 80% 이상의 안정적인 공식 API 중심 데이터 수집
  - 사전 예약 없이 '오늘/주말 당일 즉시 출발 가능한 장소' 위주 우선 추천
  - 야놀자 스타일의 직관적인 카테고리/큐레이션 뷰 제공

---

## 2. UI / UX 및 화면 구조 명세

### 2.1. 상단 고정 헤더 & 서브 탭 (메인 홈 3rd Tab)
- **고정 헤더**: `[위치 선택기 (예: 성남시 분당구 ▾)]` + `[🔍 통합 검색바]`
- **상단 3대 서브 탭 (Sub Navigation)**:
  1. `🏠 홈`: 종합 큐레이션 메인 뷰 (디폴트)
  2. `🏷️ 특가·핫딜`: 쿠팡/네이버 연동 50% 이상 타임특가 및 1만 원 이하 핫딜
  3. `🎁 무료·공공`: 입장료 0원 공공시설, 무료 박물관, 지자체 무료 행사·물놀이장

### 2.2. 메인 홈 레이아웃 스택 (스크롤 순서)
1. **메인 비주얼 카드 슬라이더 (Hero Carousel)**: 
 - 데이터 조건: 당일 진행 중인 행사/이벤트 중 추천 5~10개 동적 페칭
 - UI 카드 내용: 대형 썸네일 + [⚡ 오늘 당일 입장] / [🎁 무료] 뱃지 + 행사명 + 장소/거리
2. **5대 카테고리 Quick 아이콘 그리드**: 클릭 시 하단 `[🏷️ 카테고리]` 탭 연동 및 해당 카테고리 즉시 필터링
3. **큐레이션 카드 피드**:
   - `🎁 0원의 행복`: 지출 부담 없는 완전 무료 공공장소/행사 카드
   - `🔥 오늘만 이 가격`: 타임커머스 핫딜 카드

### 2.3. 하단 메인 탭바 (Bottom Navigation - 5개 고정)
`[🏷️ 카테고리]` - `[📍 내주변 (지도)]` - `[🏠 홈 (중앙/디폴트)]` - `[❤️ 찜]` - `[👤 마이]`

## 3. 데이터 파이프라인 (ETL) & 가공 규약

### 3.1. 수집 전략 및 Fail-Safe 예외 처리
- **메인 수집 (80% / Stable)**: TourAPI, 문화포털, 산림청, 네이버 Local API, 쿠팡 파트너스/네이버 쇼핑 API.
- **보완 수집 (20% / Dynamic)**: 마트 문화센터 1일 특강, 지자체 광장 행사 게시판.
- **Fail-Safe Skip 규칙**:
  - 웹 크롤링/스크래핑 대상 사이트 오류/구조 변경 시 전체 수집 파이프라인을 중단하지 않고, **해당 모듈만 Skip(경고 로그 기록)** 후 정상 API 데이터만으로 DB 동기화 완료.

### 3.2. AI 정제 및 태깅 규칙 (`ai-tagger.mjs`)
- **5대 핵심 카테고리 강제 매핑**:
  - `🎨 체험·클래스` / `🌳 야외·자연` / `🏛️ 전시·박물관` / `🎪 공연·축제` / `🎡 키즈·액티비티`
- **4대 핵심 뱃지 자동 추출**:
  1. 가성비: `🎁 완전 무료` / `💰 1만원 이하` / `🎟️ 유료`
  2. 방문 시점: `⚡ 오늘 당일 입장 가능` / `📅 사전 예약 필수` (*사전 예약 마감건은 메인 노출 제외*)
  3. 실내/야외: `🏛️ 실내` / `☀️ 야외` / `🌦️ 실내외 겸용`
  4. 대상 연령: `👶 영유아(0-7세)` / `👦 어린이(8-13세)` / `👨‍👩‍👧 가족 전체`
- **요금 오탐 방지 (Vision OCR & Fallback Rule)**:
  - 요금 정보가 포스터 이미지 형태인 경우 '무료/0원' 키워드 OCR 파싱.
  - 요금 미기재 국공립/공공기관 데이터는 기본값 `is_free: true` (`🎁 완전 무료`)로 우선 추정 및 자동 보정.

## 4. 데이터 적재 및 DB 규약 (Upsert)
- **Upsert 기준**: `장소명 + 도로명 주소` 또는 `원천 고유 ID` 기반 중복 방지 및 최신 정보 업데이트.
- **배치 주기**: 공공 API 매일 새벽 1회 동기화 / 제휴 타임특가 및 당일 사용 데이터 1시간 주기 갱신.
