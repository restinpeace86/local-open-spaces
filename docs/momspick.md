👑 맘스픽(Mom's Pick) 게이미피케이션 & 등급 체계
1. 비로그인 사용자 (Visitor)
진입 조건: 앱 접속 시 기본 상태

이용 권한:

스팟픽 & 이벤트픽 지도 및 리스트 탐색 가능

AI 맞춤 추천 챗봇 체험판 1회 제한 제공 (더 이용하려면 회원가입 유도)

2. 🌱 새싹맘 (Sprout Mom) — 온보딩 및 락오픈
달성 조건: 소셜 로그인(구글/카카오) 회원가입 + 첫 스팟 방문 후기(3초 컷 마이크로 리뷰) 또는 체크리스트 1회 작성

부여 권한:

맘스픽 커뮤니티 피드 및 블로그 아웃링크 프리뷰 열람 권한 오픈

AI 맞춤 추천 챗봇 무제한 이용

3. 🌿 열심맘 (Active Mom) — 활성 유저
달성 조건: 월 2회 이상 후기/글쓰기 활동

부여 권한:

마이페이지 찜(북마크) 기능 및 나만의 찜 장소 모아보기 오픈

작성한 리뷰에 대한 일반 유저들의 반응(좋아요 등) 확인 가능

(추가 아이디어) 찜한 장소들의 실시간 기상/미세먼지 변화 간편 알림

4. 🌳 우수맘 (Excellent Mom) — 핵심 로열티 유저
달성 조건: 월 5회 이상 꾸준한 후기 및 정보 공유 활동 (또는 유저들에게 채택/좋아요를 많이 받은 기여도 기준)

부여 권한:

맞춤형 큐레이션 푸시 알람: 마이페이지에 설정해 둔 필터(아이 연령, 선호 성향, 거주 지역 등)와 연계하여, 조건에 딱 맞는 이벤트나 스팟이 올라올 때 매일 아침/주말 맞춤형 앱 푸시 알람 제공

맘스픽 피드 내에서 작성글이 상단에 우선 노출되거나 눈에 띄는 뱃지 부착

5. ✨ 파워맘 (Power Mom) — 명예 및 인플루언서
달성 조건: 우수맘 중 월간 채택 수 상위 1% (또는 일정 인원 선발)

부여 권한 및 리워드 (초기 MVP 최적화):

스포트라이트 카드 노출: 맘스픽 메인 화면이나 주간 베스트 섹션에 전용 프로필 및 대표 추천글이 스포트라이트 형태로 대대적으로 노출

실속형 리워드: 금전적 부담은 줄이고 만족도는 높이는 스타벅스 등 월간 커피 쿠폰(기프티콘) 혜택 연동

황금빛 전용 레전드 배지 부여

[개발요청 2]
현재 개발 중인 장소·이벤트 큐레이션 웹 플랫폼 프로젝트('local-spaces')의 인증, 온보딩, DB 스키마, 마이페이지, 메인 피드까지의 전체 플로우를 구현하려고 해. 아래 요구사항과 시스템 관리용 컬럼들을 반영하여 통합적인 코드와 구조를 작성해줘.

### 🛠️ 프로젝트 환경
- 백엔드/DB: Supabase (PostgreSQL), `auth.users` 연동 트리거 구조
- 주요 기술 스택: Next.js (App Router) / Tailwind CSS / Supabase JS Client

### 📌 상세 구현 요구사항

1. **DB 스키마 및 관리용 컬럼 정의 (`public.profiles` 테이블):**
   - **유저 입력 필수 항목:** 
     - `nickname` (2~10자, 중복 방지)
     - `birth_years` (다자녀 가구를 고려한 출생년도 정수형 배열, 예: `[2022, 2024]`)
     - `region` (주요 활동 지역)
   - **시스템 관리용 컬럼 (백그라운드 제어용):** 
     - `role`: 회원 권한 (기본값 'user', 향후 'partner', 'admin' 확장 고려)
     - `tier`: 회원 등급/리워드 체계 (기본값 'seed' 새싹, 추후 우수맘/열심맘 연동용)
     - `status`: 계정 상태 ('active' 정상, 'suspended' 정지, 'withdrawn' 탈퇴)
     - `marketing_agreed`: 마케팅/주말 핫플 알림 수신 동의 여부 (boolean)
     - `last_login_at`: 마지막 로그인 일시 (타임스탬프)

2. **소셜 로그인 컴포넌트 (Kakao & Google):**
   - Supabase OAuth(`supabase.auth.signInWithOAuth()`)를 활용한 카카오 및 구글 로그인 버튼 UI 구현.
   - 인증 성공 후 콜백 라우트 처리.

3. **온보딩 플로우 & 라우팅 가드:**
   - 로그인 후 앱 진입 시 `public.profiles`를 조회하여 필수 정보(`nickname`, `birth_years`, `region`)가 하나라도 누락되어 있으면 자동으로 `/onboarding` 페이지로 리다이렉트.
   - 온보딩 폼에서 3가지 필수 정보를 입력받아 `profiles` 테이블을 업데이트(`update`)하고 메인으로 이동.

4. **마이페이지 (`/mypage`):**
   - 프로필 정보(닉네임, 출생년도 배열, 지역) 조회 및 수정 기능 폼 구현.
   - Supabase 로그아웃 (`supabase.auth.signOut()`) 연동.

5. **맘스픽 메인 피드 (`/`):**
   - 유저의 프로필 데이터(지역, 자녀 연령)를 반영한 상단 맞춤형 문구 섹션.
   - 카테고리 필터와 장소/이벤트 카드 그리드 UI 뼈대.

위 내용에 맞춰 바로 적용할 수 있는 컴포넌트 코드들과 전체적인 데이터 연동 가이드를 작성해줘.

### 🛠️ 핵심 비즈니스 로직 (권한 및 팝업 플로우)
1. **공개 콘텐츠와 제한 콘텐츠 분리:**
   - 비로그인 유저나 막 가입한 유저는 메인 화면의 '이벤트픽(Event Pick)', '스팟픽(Spot Pick)' 등 기본 콘텐츠를 자유롭게 구경할 수 있음.
2. **'맘스픽(Moms Pick)' 클릭 시 권한 체크:**
   - 유저가 '맘스픽' 메뉴를 클릭했을 때 아래 3가지 분기 처리 수행:
     - **Case 1 (비로그인):** 로그인/회원가입 유도 모달 띄우기.
     - **Case 2 (로그인 완료 + 첫 글 작성 수 0개 / 새싹맘 아님):** 
       - 안내 모달(Popup) 띄우기: *"아직 새싹맘 등급이 아니에요! 동네 핫플이나 정보를 하나 공유하고 맘스픽의 모든 기능을 이용해보세요."*
       - 버튼 제공: **[첫 글 쓰러 가기]** (클릭 시 `/write` 또는 글쓰기 페이지로 이동) 및 **[닫기]**
     - **Case 3 (로그인 완료 + 새싹맘 달성 유저):**
       - 정상적으로 맘스픽 콘텐츠 페이지로 진입 허용.

3. **새싹맘 자동 승급 처리:**
   - 유저가 첫 번째 장소 추천/리뷰 글을 작성하여 성공적으로 등록하면, Supabase `public.profiles` 테이블의 `tier` 컬럼이 `'seed_mom'` (새싹맘)으로 자동 업데이트되도록 처리.

- **권한 체크 훅 또는 함수 (`useAuthGuard` 또는 유사한 로직):** '맘스픽' 클릭 시 유저의 로그인 상태와 `profiles.tier` (또는 작성 글 개수)를 검사하는 로직.
- **안내 모달 컴포넌트 (`SaessakMomGuideModal`):** 조건 미달 시 뜨는 깔끔한 UI 모달 구현.
- **글쓰기 폼 및 승급 처리 연동 코드.**

### 📌 맘스픽(Moms Pick) 메인 화면 기획 요구사항

맘스픽 메인 화면은 모든 글이 무작위로 섞이는 피드가 아니라, **철저히 검증된 3가지 핵심 영역(Preview + 전체보기 구조)**으로 구성되어 빠르고 가벼운 로딩과 명확한 정보 탐색을 제공해야 함.

1. **상단 개인화 배너 (Personalized Header):**
   - 유저의 프로필 데이터(`region`, `birth_years`)를 반영한 맞춤형 환영 문구 노출 (예: "서울 강남구에 사는 아이와 이번 주말 여기 어때요?").

2. **섹션 ①: 파워맘 / 우수맘 추천 (Expert Curation Preview)**
   - **특징:** 상급 등급 유저(파워맘, 우수맘)가 작성한 신뢰도 높은 장소/이벤트 추천 글.
   - **노출 방식:** 메인에는 핵심 상위 2~3개만 카드뉴스/와이드 배너 형태로 노출.
   - **UI 요소:** 작성자의 닉네임과 신뢰감을 주는 등급 배지(Badge) 필수 표시.
   - **전체보기:** 우측 상단 `[전체보기 ➔]` 버튼 클릭 시 파워맘 글만 모아보는 페이지(`/moms-pick/expert`)로 이동.

3. **섹션 ②: 인기 / 우수글 (Trending Posts Preview)**
   - **특징:** 찜(북마크)이나 좋아요 인터랙션이 많이 몰려 대중성이 검증된 베스트 글.
   - **노출 방식:** 메인에는 상위 3~5개만 요약 노출.
   - **전체보기:** 우측 상단 `[전체보기 ➔]` 버튼 클릭 시 인기글 모음 페이지(`/moms-pick/trending`)로 이동하여 탐색 가능.

4. **섹션 ③: 실시간 라이브 글 (Real-time Live Feed Preview)**
   - **특징:** 방금 막 등록된 따끈따끈한 동네 핫플/이벤트 최신 제보.
   - **노출 방식:** 메인에는 최신 순으로 상위 3~5개만 가볍게 타임라인 형태로 노출.
   - **전체보기:** 우측 상단 `[전체보기 ➔]` 버튼 클릭 시 실시간 전체 피드 페이지(`/moms-pick/live`)로 이동.

5. **성능 및 쿼리 최적화 고려:**
   - 메인 대시보드 진입 시 전체 데이터를 다 불러오지 않고, 각 영역별로 필요한 소량의 데이터만(`LIMIT 3` 또는 `LIMIT 5`) 가볍게 쿼리하여 속도를 최적화하는 구조로 작성해줘.

위 내용을 바탕으로 맘스픽 메인 대시보드 컴포넌트와 각 영역별 카드 UI, 전체보기 페이지의 기본 뼈대 코드를 작성해줘.

현재 개발 중인 장소·이벤트 큐레이션 웹 플랫폼 프로젝트('local-spaces')의 핵심 기능인 'AI 챗봇 맞춤 추천' 컴포넌트와 관련 데이터 연동 로직을 아래 요구사항에 맞춰 최종 완성해줘.

### 📌 AI 챗봇 맞춤 추천 상세 구현 요구사항 (최종 통합본)

1. **[Step 1] 실시간 날씨 기반 '선제적 제안' 및 일정 분기 로직:**
   - 챗봇 실행 시, 오늘의 날씨 정보를 체크하여 유저에게 **구체적인 제안(Default Option)**을 먼저 던질 것. (강요가 아닌, 원클릭으로 수락하거나 거부/대안을 고를 수 있는 구조)
     - *맑음 제안 예시:* "오늘 날씨가 화창하고 참 좋네요! ☀️ 파란 하늘 아래 아이랑 뛰어놀기 좋은 야외 공원이 좋아보여요. 야외/공원 위주로 알아볼까요?"
     - *비/흐림 제안 예시:* "오늘 날씨를 보니 구름이 많거나 비가 오네요. 🌧️ 아이와 함께 포근한 실내 위주가 좋아보여요. 실내 위주로 알아볼까요?"
     - *선택지 포맷:* `[네, 제안대로 볼래요! 👍]` / `[아니요, 다른 스타일로 고를래요 🏛️]` / `[상관없어요, 전체 다 믹스 ✨]`
   - 날씨 제안 직후, 일정 선택 질문 던지기:
     > *"오늘 바로 아이와 나들이 다녀오실 계획이신가요, 아니면 다른 날 갈 예정인가요?"*
     - **분기 A [오늘 바로 나갈래요! 🚀]:** 곧바로 다음 나들이 조건 스텝으로 진행.
     - **분기 B [다른 날 갈래요 (날짜 선택) 🗓️]:** 
       - 유저가 특정 날짜를 고르면, 시스템이 해당 날짜의 날씨 예보를 조회하여 *"선택하신 [0월 0일]에는 날씨가 맑을 것으로 예상되네요! 야외 공원 위주로 먼저 볼까요?"* 같은 선제적 제안 멘트와 [예/아니오] 선택지를 동적으로 출력할 것.

2. **로그인 유저 프로필 자동 연동 (자녀 나이 계산):**
   - Supabase `public.profiles` 테이블에서 유저의 `birth_years` (자녀 출생년도 배열) 데이터를 불러와 **현재 연도(2026년 기준)로 자동 환산**.
   - 챗봇이 다정하게 인지: *"아, OO맘님! 네 살 아이와 함께 나들이 가시는군요!"* (출생년도를 그대로 출력하거나, 자녀 나이를 묻는 불필요한 입력 스텝은 완전 생략. 또한 도보/차량 이동수단 같은 기계적 질문 절대 금지)

3. **핵심 질문 스텝 (스마트 조건부 꼬리 질문):**
   - **① 장소 성격 / 대분류:** 앞서 제안에 동의하지 않았거나 대안을 고른 경우, 명확한 다중 선택지 제공 (`[실내 위주]`, `[야외 위주]`, `[상관없어요]`)
   - **② 방문 시간대 및 조건부 식사 분기:**
     - `[아침 먹고 오전 일찍]` `[점심 먹기 전]` `[점심 후 느긋하게]` `[오후 늦게 슬슬]`
     - **[스마트 조건부 꼬리 질문]:** 
       - 유저가 **[아침 먹고 오전 일찍]** 또는 **[점심 먹기 전]** 등 식사 시간이 걸쳐 있는 시간대를 선택한 경우에만 식사 관련 꼬리 질문 띄우기:
         > *"그럼 나간 김에 점심은 밖에서 해결하실 예정인가요?"*
         > (선택지: `[네, 밖에서 맛있는 거 먹을래요 🍲]` / `[아니요, 도시락 싸가거나 따로 먹어요 🍱]`)
       - *-> '아니요' 선택 시 피크닉·공원 위주, '네' 선택 시 식당/나들이 복합 공간 세트 연계.*
       - *-> [점심 후 느긋하게] 등 그 외 시간대에는 불필요한 꼬리 질문 없이 곧바로 결과로 직행.*

4. **챗봇 감성 UX 및 추천 장소/식당 쿼리 로직:**
   - 유저가 최종 선택을 제출한 직후 바로 답이 튀어나오지 않고, **1~1.5초 정도의 '생각 중...' 타이핑 애니메이션/로딩 텀**을 주어 감성적 완성도 높이기.
   - 자녀 나이대에 맞는 장소뿐만 아니라, 박물관·대형공원 등 **`[온가족 함께]` 태그가 붙은 장소들도 백그라운드 쿼리에서 자연스럽게 함께 포함**시켜 검색 결과가 부족하지 않도록 방어 로직 구현.
   - **[식당 연계 조건]:** '밖에서 먹을래요(네)'를 선택한 경우, 나들이 장소 근처 식당(맛집) 정보를 **세트로 묶어서** 출력.
   - 조건에 맞는 장소 2~3곳을 부드러운 대화 멘트와 함께 카드 UI 형태로 예쁘게 출력하기.

위 모든 요구사항을 완벽히 반영하여 컴포넌트 코드와 쿼리 로직을 작성해줘.
