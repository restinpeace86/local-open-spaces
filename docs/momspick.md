👑 맘스픽(Mom's Pick) 게이미피케이션 & 등급 체계
1. 비로그인 사용자 (Visitor)
진입 조건: 앱 접속 시 기본 상태

이용 권한:

스팟픽 & 이벤트픽 지도 및 리스트 탐색 가능

AI 맞춤 추천 챗봇 체험판 1회 제한 제공 (더 이용하려면 회원가입 유도)

2. 🌱 새싹맘 (Sprout Mom) — 온보딩 및 락오픈
달성 조건: 소셜 로그인(구글/카카오) 회원가입 + 첫 스팟 방문 후기(3초 컷 마이크로 리뷰) 또는 체크리스트 1회 작성

부여 권한:

맘스픽 커뮤니티 피드 및 블로그 아웃링크 프리뷰 열람 권한 오픈

AI 맞춤 추천 챗봇 무제한 이용

3. 🌿 열심맘 (Active Mom) — 활성 유저
달성 조건: 월 2회 이상 후기/글쓰기 활동

부여 권한:

마이페이지 찜(북마크) 기능 및 나만의 찜 장소 모아보기 오픈

작성한 리뷰에 대한 일반 유저들의 반응(좋아요 등) 확인 가능

(추가 아이디어) 찜한 장소들의 실시간 기상/미세먼지 변화 간편 알림

4. 🌳 우수맘 (Excellent Mom) — 핵심 로열티 유저
달성 조건: 월 5회 이상 꾸준한 후기 및 정보 공유 활동 (또는 유저들에게 채택/좋아요를 많이 받은 기여도 기준)

부여 권한:

맞춤형 큐레이션 푸시 알람: 마이페이지에 설정해 둔 필터(아이 연령, 선호 성향, 거주 지역 등)와 연계하여, 조건에 딱 맞는 이벤트나 스팟이 올라올 때 매일 아침/주말 맞춤형 앱 푸시 알람 제공

맘스픽 피드 내에서 작성글이 상단에 우선 노출되거나 눈에 띄는 뱃지 부착

5. ✨ 파워맘 (Power Mom) — 명예 및 인플루언서
달성 조건: 우수맘 중 월간 채택 수 상위 1% (또는 일정 인원 선발)

부여 권한 및 리워드 (초기 MVP 최적화):

스포트라이트 카드 노출: 맘스픽 메인 화면이나 주간 베스트 섹션에 전용 프로필 및 대표 추천글이 스포트라이트 형태로 대대적으로 노출

실속형 리워드: 금전적 부담은 줄이고 만족도는 높이는 스타벅스 등 월간 커피 쿠폰(기프티콘) 혜택 연동

황금빛 전용 레전드 배지 부여

소셜 로그인 연동 준비

카카오 KAKAO_REST_API_KEY 확보 및 Supabase Auth(구글/카카오)를 활용한 소셜 로그인 아키텍처 및 연동 방식 점검 완료.

맘스픽(Mom's Pick) 기획안 복원 및 구체화

어제 작업하다 유실되었던 맘스픽 핵심 기획 원문 복원 및 커뮤니티 생태계 방향성 재확인.

블로그 아웃링크 프리뷰: 네이버 블로그 검색 API 기반으로 저작권 리스크 없이 외부 상세 후기를 카드 형태로 제공하는 구조 설계.

등급 및 게이미피케이션(Reputation/Reward) 체계 확립

비로그인: 탐색 및 AI 챗봇 1회 체험

🌱 새싹맘: 로그인 + 첫 스팟 후기/체크리스트 작성 ➔ 맘스픽 오픈 및 챗봇 무제한 해제

🌿 열심맘: 월 2회 이상 글쓰기 ➔ 마이페이지 '찜(북마크)' 기능 오픈

🌳 우수맘: 월 5회 이상 글쓰기 ➔ 맞춤형 조건 필터 기반의 일일 푸시 알람 제공

✨ 파워맘: 우수맘 중 채택 수 상위 1% ➔ 메인 스포트라이트 카드 노출 및 월간 커피 쿠폰(기프티콘) 리워드 연동

3초 컷 마이크로 리뷰 & 피드 UX 레이아웃 확정

리뷰 작성: 타이핑 지옥을 없애기 위해 '핵심 터치 태그 칩 + 사진 1장 + 가벼운 한 줄 톡' 조합으로 결정.

피드 디자인: 한 화면에 큼직하게 1개만 나오는 구조 대신, 바쁜 엄마들이 빠르게 훑어볼 수 있는 컴팩트 스캔형 피드 레이아웃으로 최종 확정.

🛠️ 1단계: 카카오 디벨로퍼스(Kakao Developers) 설정
카카오 측에서 Supabase로 인증 권한을 넘겨줄 수 있도록 길을 터주는 단계입니다.

Kakao Developers 콘솔 접속 후 내 애플리케이션 선택.

[카카오 로그인] 메뉴로 이동 후 활성화 상태(ON) 확인.

[Redirect URI] 등록:

Supabase가 제공하는 인증 콜백 URL을 입력해야 합니다.

형식: https://<당신의-수파베이스-프로젝트-ID>.supabase.co/auth/v1/callback

(수파베이스 프로젝트 대시보드 Authentication > Providers > Kakao 상단에서도 이 URL을 확인할 수 있습니다.)

[보안] 메뉴로 이동 (매우 중요):

Client Secret을 반드시 [활성화(Generate)] 하세요. (Supabase는 보안 강화를 위해 카카오 시크릿 키를 필수로 요구합니다.) 발급된 시크릿 키를 복사해 둡니다.

⚙️ 2단계: Supabase 대시보드 프로바이더 설정
카카오에서 발급받은 열쇠들을 Supabase에 꽂아주는 단계입니다.

Supabase 대시보드 접속 ➔ [Authentication] ➔ [Providers] 메뉴로 이동.

Kakao 항목을 찾아 클릭 후 활성화(Enable Kakao 체크).

입력란 채우기:

Client ID (API Key): .env.local에 넣어두신 KAKAO_REST_API_KEY 입력

Client Secret: 1단계에서 카카오 콘솔 보안 메뉴에서 발급받은 시크릿 키 입력

[Save] 저장.

[개발요청 1]
현재 개발 중인 웹 프론트엔드 프로젝트에 Supabase Auth를 활용한 '카카오' 및 '구글' 소셜 로그인 기능을 동시에 구현하려고 해. 아래 요구사항과 설정을 바탕으로 로그인 버튼 컴포넌트들과 관련 인증 로직을 작성해줘.

### 🛠️ 프로젝트 및 연동 환경 정보
- 백엔드/인증 서비스: Supabase (Project ID: geffyjfnqrabovtmjcev)
- 인증 제공자(Provider): Kakao, Google (Supabase 대시보드 및 각 디벨로퍼스 콘솔 세팅은 이미 완료됨)
- 주요 기술 스택: [사용 중인 프레임워크 예: Next.js App Router / React 등 프로젝트 환경에 맞게 수정 가능]

### 📌 구현 요구사항
1. **소셜 로그인 버튼 컴포넌트들 (KakaoLoginButton & GoogleLoginButton):**
   - **카카오 버튼:** 브랜드 가이드에 맞는 시그니처 컬러(#FEE500)와 텍스트("카카오로 3초 만에 시작하기") 적용.
   - **구글 버튼:** 깔끔하고 직관적인 UI ("구글로 시작하기" 또는 구글 디자인 가이드 스타일) 적용.
   - 두 버튼 모두 클릭 시 Supabase의 `supabase.auth.signInWithOAuth()` 메서드를 호출하되, `provider` 값만 각각 `'kakao'`와 `'google'`로 다르게 전달하도록 구현.
   - 공통으로 `options.redirectTo` 설정 포함 (로그인 성공 후 돌아올 콜백 경로 지정, 예: `${window.location.origin}/auth/callback`).

2. **로그인 에러 핸들링:**
   - 인증 요청 중 발생할 수 있는 에러(`error`)를 콘솔 또는 UI 상에서 확인할 수 있도록 예외 처리 코드 추가.

3. **콜백 페이지 또는 세션 처리 가이드:**
   - 로그인이 완료되고 Supabase 콜백 URL을 거쳐 돌아왔을 때, 세션이 정상적으로 유지되도록 처리하는 방법(또는 라우트 핸들러 예시)이 있다면 함께 설명해줘.

위 내용에 맞춰 바로 가져다 쓸 수 있는 깔끔한 컴포넌트 코드들과 적용 방법을 작성해줘.

[개발요청 2]
현재 개발 중인 웹 프론트엔드 프로젝트('local-spaces')에 Supabase Auth를 활용한 소셜 로그인과 온보딩 플로우를 구현하려고 해. 아래 요구사항과 아키텍처를 바탕으로 전체적인 코드와 로직을 작성해줘.

### 🛠️ 프로젝트 및 연동 환경 정보
- 백엔드/인증 서비스: Supabase (Project ID: geffyjfnqrabovtmjcev)
- 인증 제공자: Kakao, Google
- 주요 기술 스택: [사용 중인 프레임워크 예: Next.js App Router / React 등 프로젝트 환경에 맞게 작성]

### 📌 구현 요구사항

1. **소셜 로그인 버튼 컴포넌트 (Kakao & Google):**
   - 카카오(시그니처 컬러 #FEE500) 및 구글 로그인 버튼 UI 구현.
   - 클릭 시 Supabase의 `supabase.auth.signInWithOAuth()` 메서드를 호출 (`provider`를 각각 `'kakao'`, `'google'`로 지정).
   - 콜백 경로 설정: `options.redirectTo`를 통해 인증 후 앱 내 콜백 페이지로 리다이렉트.

2. **로그인 직후 온보딩 체크 및 라우팅 로직 (Route Guard / Middleware 또는 공통 레이아웃):**
   - 로그인이 완료되어 서비스에 진입했을 때, Supabase의 `public.profiles` 테이블을 조회하여 필수 프로필 정보(`nickname`, `birth_years`, `region`)가 모두 채워져 있는지 확인.
   - 만약 정보가 하나라도 누락되어 있다면(null이거나 비어있다면), 자동으로 `/onboarding` 페이지로 리다이렉트 처리.

3. **온보딩 페이지 컴포넌트 (`/onboarding`):**
   - 유저로부터 딱 **3가지 필수 정보**를 입력받는 깔끔하고 직관적인 UI 폼 작성:
     ① **닉네임 (`nickname`):** 커뮤니티/후기 작성용 (2~10자, 중복 방지 유효성 검사 포함)
     ② **자녀 출생년도 (`birth_years`):** 다자녀 가구를 고려해 **출생년도를 여러 개 선택하거나 추가할 수 있는 형태** (예: 체크박스, 셀렉터 배열, 혹은 연도 추가 버튼 UI)
     ③ **주요 활동 지역 (`region`):** 우리 동네 맞춤형 장소/이벤트를 추천받기 위한 지역 선택 입력란
   - 제출 버튼 클릭 시, `public.profiles` 테이블의 해당 유저 데이터(`id` 기준)를 `update` 하고 메인 페이지(`/`)로 이동시키는 로직 구현.

4. **에러 핸들링 및 예외 처리:**
   - 네트워크 에러나 닉네임 중복 등 발생 가능한 예외 상황에 대한 가벼운 피드백(토스트 메시지 또는 에러 텍스트) 처리.

위 내용에 맞춰 바로 가져다 쓸 수 있는 컴포넌트 코드들과 전체적인 연동 가이드를 작성해줘.
