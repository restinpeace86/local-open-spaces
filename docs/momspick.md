👑 맘스픽(Mom's Pick) 게이미피케이션 & 등급 체계
1. 비로그인 사용자 (Visitor)
진입 조건: 앱 접속 시 기본 상태

이용 권한:

스팟픽 & 이벤트픽 지도 및 리스트 탐색 가능

AI 맞춤 추천 챗봇 체험판 1회 제한 제공 (더 이용하려면 회원가입 유도)

2. 🌱 새싹맘 (Sprout Mom) — 온보딩 및 락오픈
달성 조건: 소셜 로그인(구글/카카오) 회원가입 + 첫 스팟 방문 후기(3초 컷 마이크로 리뷰) 또는 체크리스트 1회 작성

부여 권한:

맘스픽 커뮤니티 피드 및 블로그 아웃링크 프리뷰 열람 권한 오픈

AI 맞춤 추천 챗봇 무제한 이용

3. 🌿 열심맘 (Active Mom) — 활성 유저
달성 조건: 월 2회 이상 후기/글쓰기 활동

부여 권한:

마이페이지 찜(북마크) 기능 및 나만의 찜 장소 모아보기 오픈

작성한 리뷰에 대한 일반 유저들의 반응(좋아요 등) 확인 가능

(추가 아이디어) 찜한 장소들의 실시간 기상/미세먼지 변화 간편 알림

4. 🌳 우수맘 (Excellent Mom) — 핵심 로열티 유저
달성 조건: 월 5회 이상 꾸준한 후기 및 정보 공유 활동 (또는 유저들에게 채택/좋아요를 많이 받은 기여도 기준)

부여 권한:

맞춤형 큐레이션 푸시 알람: 마이페이지에 설정해 둔 필터(아이 연령, 선호 성향, 거주 지역 등)와 연계하여, 조건에 딱 맞는 이벤트나 스팟이 올라올 때 매일 아침/주말 맞춤형 앱 푸시 알람 제공

맘스픽 피드 내에서 작성글이 상단에 우선 노출되거나 눈에 띄는 뱃지 부착

5. ✨ 파워맘 (Power Mom) — 명예 및 인플루언서
달성 조건: 우수맘 중 월간 채택 수 상위 1% (또는 일정 인원 선발)

부여 권한 및 리워드 (초기 MVP 최적화):

스포트라이트 카드 노출: 맘스픽 메인 화면이나 주간 베스트 섹션에 전용 프로필 및 대표 추천글이 스포트라이트 형태로 대대적으로 노출

실속형 리워드: 금전적 부담은 줄이고 만족도는 높이는 스타벅스 등 월간 커피 쿠폰(기프티콘) 혜택 연동

황금빛 전용 레전드 배지 부여

🛠️ 1단계: 카카오 디벨로퍼스(Kakao Developers) 설정
카카오 측에서 Supabase로 인증 권한을 넘겨줄 수 있도록 길을 터주는 단계입니다.

Kakao Developers 콘솔 접속 후 내 애플리케이션 선택.

[카카오 로그인] 메뉴로 이동 후 활성화 상태(ON) 확인.

[Redirect URI] 등록:

Supabase가 제공하는 인증 콜백 URL을 입력해야 합니다.

형식: https://<당신의-수파베이스-프로젝트-ID>.supabase.co/auth/v1/callback

(수파베이스 프로젝트 대시보드 Authentication > Providers > Kakao 상단에서도 이 URL을 확인할 수 있습니다.)

[보안] 메뉴로 이동 (매우 중요):

Client Secret을 반드시 [활성화(Generate)] 하세요. (Supabase는 보안 강화를 위해 카카오 시크릿 키를 필수로 요구합니다.) 발급된 시크릿 키를 복사해 둡니다.

⚙️ 2단계: Supabase 대시보드 프로바이더 설정
카카오에서 발급받은 열쇠들을 Supabase에 꽂아주는 단계입니다.

Supabase 대시보드 접속 ➔ [Authentication] ➔ [Providers] 메뉴로 이동.

Kakao 항목을 찾아 클릭 후 활성화(Enable Kakao 체크).

입력란 채우기:

Client ID (API Key): .env.local에 넣어두신 KAKAO_REST_API_KEY 입력

Client Secret: 1단계에서 카카오 콘솔 보안 메뉴에서 발급받은 시크릿 키 입력

[Save] 저장.

### 📌 구현 요구사항
1. **카카오 로그인 버튼 컴포넌트 (KakaoLoginButton):**
   - 카카오 브랜드 가이드에 맞는 시그니처 컬러(#FEE500)와 텍스트("카카오로 3초 만에 시작하기")를 가진 깔끔한 UI 버튼 컴포넌트 작성.
   - 버튼 클릭 시 Supabase의 `supabase.auth.signInWithOAuth()` 메서드를 호출하여 카카오 인증 페이지로 리다이렉트 처리.
   - `options.redirectTo` 설정 포함 (로그인 성공 후 돌아올 콜백 경로 지정).

2. **로그인 에러 핸들링:**
   - 인증 요청 중 발생할 수 있는 에러(`error`)를 콘솔 또는 UI 상에서 가볍게 확인할 수 있도록 예외 처리 코드 추가.

3. **(선택/필요시) 콜백 페이지 또는 세션 처리:**
   - 카카오 로그인이 완료되고 Supabase 콜백 URL을 거쳐 돌아왔을 때, 세션이 정상적으로 유지되도록 처리하는 가이드나 코드가 필요하다면 함께 설명해줘.

위 내용에 맞춰 바로 가져다 쓸 수 있는 깔끔한 컴포넌트 코드와 적용 방법을 작성해줘.
