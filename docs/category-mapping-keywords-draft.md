# [카테고리 정제 1단계 사전 작업] 서울시 표준 중분류별 매핑 키워드 정의서 (검토용 초안)

> **상태: 검토 대기 — 실행 금지**
> 이 문서는 대표 검토·수정 가이드용 **초안**이다. 아래 키워드/규칙을 기준으로 한 실제 DB
> 업데이트나 룰베이스 분류 스크립트 실행은 이 문서가 검토·승인되기 전까지 하지 않는다.
> 작성일: 2026-08-26

## 0. 작업 배경

[프론트엔드 UI/UX 개선](2026-08-26) 작업에서 이벤트픽/스팟픽의 "원천 중분류(MINCLASSNM) 전체
노출" 요구사항을 실측 확인 결과 스킵(보류)했다 — `MINCLASSNM`은 SEOUL_YEYAK
(`source='seoul_public_reservation'`) 원본 API에만 있는 필드라, 나머지 16개 소스에는 이
필드 자체가 없기 때문이다(`implementation/2026-08-26-events-spots-main-screen-revamp.md`
참고). 이 문서는 그 후속으로, SEOUL_YEYAK의 실제 중분류 체계를 "표준"으로 삼아 나머지
소스의 시설/행사명을 키워드로 이 표준에 맞춰 넣는 1단계 룰베이스 분류기를 설계하기 위한
사전 정의서다.

## 2. 중분류별 매핑 키워드/규칙 매트릭스

**표기 규약**
- **매핑 키워드**: 다른 소스의 시설명/행사명(name·title)에 이 키워드가 포함되면 해당
  중분류 후보로 1차 스캔한다.
- **제외 키워드**: 매핑 키워드와 동시에 매칭되더라도, 이 키워드가 있으면 후보에서 제외한다
  (다른 더 적합한 중분류로 넘어가도록 우선순위 규칙과 함께 검토 필요).
- **예상 매핑 대상 소스**: `source` 컬럼 값 기준. 각 소스가 실제로 다루는 데이터 도메인
  (`project/data_sources.md`, `src/lib/theme-spots.ts`의 기존 검증된 분류 근거)에 비춰
  **가능성이 있다고 판단한 예상치**이며, 실제 매칭률은 룰 적용 후 재검증이 필요하다(추측
  표시 명확화 — 이 열은 "확정"이 아니라 "1차 스캔 대상 후보").

## 3. 종합 메모

- **47개 표준 중분류 중 다른 소스와 실질적으로 겹칠 가능성이 높은 것은 체육시설류(15종)와
  문화/전시/스포츠/역사류·강좌류(약 12종) 정도**이고, 나머지(공공청사 대관형 9종 + 서울형
  키즈카페/청년정보/단체봉사/기타 4종 = 13종)는 SEOUL_YEYAK 고유 개념이라 다른 소스로는
  채워지지 않을 가능성이 높다 — 이 경우 "SEOUL_YEYAK만 이 중분류를 쓰고, 다른 소스는 이
  중분류에 매칭되는 게 정상적으로 0건"이라는 결과 자체가 맞는 결과일 수 있다.
- 위 매핑 규칙은 시설명/행사명 키워드 기반 1차 스캔안이며, 실제 적용 시 (a) 오탐(예:
  "테니스장"이 실제로는 "OO테니스장 옆 주차장" 같은 부속 명칭에 우연히 포함) (b) 누락(원본
  표기 변형 — 축약어, 띄어쓰기, 영문 병기 등)이 있을 수 있어, 룰 적용 후 표본 검수가 필요하다.
- 골프장/전시실 항목 등 일부는 기존 5대 UI 카테고리(예: EXHIBITION_MUSEUM)와 개념이 겹쳐,
  이중 분류 체계를 어떻게 공존시킬지(대체 vs 병행 태그) 대표 결정이 필요하다.
- 이 문서에서 제시한 키워드 목록/제외 규칙/예상 소스는 전부 **제안(초안)**이며, 대표 검토 후
  수정 지시를 받으면 확정판으로 갱신한다. 확정 전까지 룰베이스 분류 스크립트는 작성·실행하지
  않는다.
