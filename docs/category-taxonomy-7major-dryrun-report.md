## 0. 지시사항 항목 수 확인 — "37종" vs 실제 나열 개수

지시에 나열된 7대 대분류 아래 항목을 그대로 세어보면 **36개**다(사용자가 말한 "37종"과 1건
차이). 괄호 안 예시(예: "도시농업(가족텃밭/주말농부)", "공공키즈카페(서울형키즈카페/경기
아이사랑놀이터 등)")는 하나의 중분류에 대한 키워드 예시로 해석해 1개 항목으로 처리했다.
추측으로 항목을 임의로 추가해 36을 37로 맞추지 않고, 나열된 그대로(36종) 시뮬레이션했다 —
의도한 37번째 항목이 따로 있다면 알려주시면 즉시 반영하겠다.

## 3. 해석 및 권고

- **매칭률(34.28%)이 기존 47종 체계(약 35%대)와 비슷한 수준**이다 — 카테고리 수를 49→36으로
  줄이고 "정보통신"/"전문/자격증" 등을 제외했지만, 새로 추가된 "지역축제/페스티벌"(1,378건)과
  스포츠/전시 시설류를 events에도 적용한 것이 상쇄해 전체 비율은 비슷하게 유지됐다.
- **"보수적 매핑 원칙"이 의도대로 작동함을 확인** — 65.72%(17,354건)가 무리한 추정 없이
  NULL로 남는다. 이 중 상당수는 미매칭 샘플에서 보듯 고유명사(전시명/공연명/기관명)만으로
  구성된 제목이라 원천적으로 키워드 매칭이 어렵다(예: "일무", "OVERGLOW", "튼튼 펫 페스타"류).
- **"공원탐방"/"농장체험" 2종은 현재 0건** — 규칙은 유효하나 데이터가 아직 없다. 정상.
- 신규 정의한 3종(공공키즈카페/어린이실내놀이터/지역축제·페스티벌)의 키워드는 제안 단계다 —
  특히 "경기아이사랑놀이터"는 실제 이 문구가 원본 시설명에 등장하는지 실측 확인이 아직
  안 됐다(0건이 아니길 바라는 추측이 아니라, 다음 실행 후 검증 필요 항목으로 남긴다).
